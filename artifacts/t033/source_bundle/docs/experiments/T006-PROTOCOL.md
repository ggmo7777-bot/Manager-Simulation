# EXP-T006 事前実験計画

登録: 2026-11-05、T006実装・結果観察前。T005は監督の予測学習を選手の経験評価へ接続したが、監督の方法選択は変えなかった。今回は学習と利用を分離する。現実の指導能力のモデルとしての妥当性は、この小さな検査だけでは確定しない。

## 変更と採点の契約

選択肢は(1)旧方法項を維持、(2)予測gainを換算して直接得点化、(3)予測の順位で方法項を置き換える方式。直接加算は予測の大きさによる時間配分まで同時に変えるため、今回は(3)を試す。

`PolicyRules.coach_method_mode`は`legacy`（既定）/`forecast_rank`。予測更新は既存の`BeliefRules.coach_forecast_learning`で独立に設定する。更新OFF・利用ONも正当な設定で、同じ事前予測の知識を判断へ使う負の対照になる。

対象の監督技能推定をs、方法係数をw=0.05、事前の主観的予測をqA/qBとする。

```text
legacy_fit(A) = w * (1 - s)
legacy_fit(B) = w * s
top_fit = w * max(s, 1 - s)

legacy mode OR qA == qB: use legacy_fit
forecast_rank AND qA != qB:
    method_fit(argmax(qA, qB)) = top_fit
    method_fit(other) = 0

proposal_score = 0.12 * (1 - s) + method_fit
```

同点は厳密な浮動小数値の一致として扱い、閾値は新設しない。新しい最適化係数は加えない。w=0では方法の知識を得点へ反映しない。s=0.5でもw>0なら異なる予測の方法を区別できる。

現在の候補生成は、提案可能な対象にA/B両方を必ず提示する。この条件下で、同じ私的状態なら対象ごとの最大提案得点は旧方式と一致する。観察/提案/休息と対象の優先度を直接変えず、選ぶ方法を変える。後の日には選手の経験・監督の評価が変わるため、配分も変わりうる。時間配分の閉ループ効果がゼロという主張ではない。

順位方式は差の大きさを捨て、微小な差でも順位が反転し、両予測が負でも相対的に大きい方法を選びうる。これは今回の限定で、成功するように補正・探索・罰・新しい休息規則を追加しない。

## 情報と履歴

- `decide_coach`は既存のCoachObservation、CoachMind、PolicyRulesだけを受ける。監督の技能推定・固定方法率・個体×方法の補正から既存`coach_forecast`でqを作る。World、真の率/上限/疲労/未来gain、選手の私的Gを渡さない。
- 選択時点のA/B予測、基準・補正、技能評価/方法事前率/補正の根拠ID、旧方式同点fallbackか順位か、採点項と最終候補得点を記録する。未選択の方法にも当時の根拠が残る。
- 日内の順序とT005の夕方更新を維持し、当日選択に夕方の補正を遡って使わない。提案の予測は選択時と同じ知識から作る。
- 利用OFFの候補/記録の意味を維持する。Policyの版識別子を除く全状態・イベントを、凍結T005との同条件比較で照合する。
- 選手の即時採点は変更しない。監督の方法が変わっても、選手は独立に採用/拒否/別方法/休息を選ぶ。

数値対照は各学習設定内のrank−legacy、各利用設定内のlearning−frozen、交互作用`learning_rank - learning_legacy - frozen_rank + frozen_legacy`。対応seed単位bootstrap 2,000回、解析seed6006、95% percentile区間。欠損は0にせず各対照の有効seed数を示す。

行動不一致率は4つの単純対照の実際の列から直接算出し、不一致率の交互作用を作らない。監督の不一致を行動種別・対象・方法に分けて読み、方法以外の変化も報告する。

## 指標

- 監督の対象×方法別の提案/実施/学習数、観察/提案/休息の枠配分。方法ごとの未観察、未提案、学習機会0を欠損として区別する。
- 順位の異なる予測を使った提案数、同点fallback数、同じ選択時点の旧方法式と選定が異なる件数、両予測負の提案数。これは反実仮想の試合/成長結果ではなく同一認識の採点比較。
- 個体の方法/休息選択、助言採用/拒否、信頼、技能gain、方法予測と補正。候補得点と根拠を辿れる履歴を1例抽出する。
- T005と同様、監督の観察した練習に対する事前予測MSEと、選手が採用した助言に対する予測MSEを別に測る。選択によって標本が変わるため、MSE差だけを同じ課題への推定能力の差としない。
- 状態・時間・参照の整合、保存/再開、本体時間、保存量、メモリ。勝率/Eloや技能gainの増加を合格条件にしない。

## 機構検査・対照

| 検査 | 受入条件 |
|---|---|
| 同じ私的状態で順位だけ変える | qA>qB / qA<qBで選ぶ方法が変わり、利用OFFは旧選定。同じ順位なら予測差の大小は得点を変えない |
| 既存優先度の保持 | 複数のs、日付、候補集合で、現在の候補生成に従うと対象ごとの最高提案得点・選んだ行動種別/対象が旧式と同じ |
| 同点・負値・境界 | 同点は旧式、s=0.5でも順位差を使用、負予測を真の負成長と混同しない。w=0でも不正値/非有限値を作らない |
| 固定観察から学習→選定 | 同じ前後信号を学習ON/OFFへ渡すと後の方法選定が分かれる。初期世界を脚本で分岐させるテストにはしない |
| 非漏洩 | 監督の認識を固定して真の率/上限/選手Gを変えても監督判断は不変。根拠は全て選択以前の監督記憶 |
| 独立した選手 | 新方式の提案を受けても同一観測/同一選手心の判断関数は旧式と同じ。採用/拒否の双方を境界fixtureで検証 |
| 利用停止 | T005の4条件×60seedを再現し、版・新設定名を除くsnapshot全体のhashが一致 |
| 継続・保存 | 主4条件84日vs42+42がsnapshot/JSONL一致、未知mode/不正型/欠落設定/旧保存拒否。learning_rank1000日の整合性 |

主比較と別にseed17・84日で、(a)信頼固定、(b)全観測ノイズ0、(c)clipped G、の各4条件を実行する。信頼固定でも方法利用からの行動作用は起こりうる。frozen同士はどの対照でも同点予測のため同じ数値/行動になるはず。ノイズ0対照は一般的効果量ではなく、乱数以外から選択が分かれるかを見る。

T001〜T005成果物を事前hashで保全し、T005の凍結readerから42日保存を再開して旧84日と一致させる。新save6/rule6/Policy2を識別し、移行は今回実装しない。

## 採否と停止点

情報境界、方法選択への知識の作用、独立した選手、比較・継続・根拠の契約が合格なら、研究用モードとして保持する。優位性が不明でも結果をそのまま記録し、既定legacyを維持する。機構が破れていれば修正して再検証し、計画との違いを記録する。

T006-RESULTS/REVIEW、STATUS、設計と次の小タスクを更新して完了する。予測や採点だけの精密化を無期限に続けず、複数監督と関係の分離へ進む判断材料を残す。複数監督、競技、所属/移籍、C、UIは今回は実装しない。
