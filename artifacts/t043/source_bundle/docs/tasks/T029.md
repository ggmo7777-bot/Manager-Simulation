# T029 — 監督の認識(B層): 助言への反応の記録から「選手の受容度」を推定し、提案の判断が最小限それを参照する

2026-11-10、実装前登録(結果を見る前に規則を固定)。状態: 完了(2026-11-10、成功条件1〜9を満たす)。[結果](../experiments/T029-RESULTS.md)。T028(PR #11、未マージ)の上に積む(ブランチt029はt028から)。[事前条件](../experiments/T029-PROTOCOL.md)、判断: D044。担当: Claude Sonnet 5.5。

## 問題

T028の監督は`coach_advice_outcome`(態度・3値の表明理由・従ったか)を受け取るだけで何にも使わない。T028では助言の62.6%が拒否され、主因は信頼<自律(性格より信頼の状態)だった。AGENTS.mdは「Aの状態更新、Bの認識更新、CのPolicy学習を分ける」と定める。観測された結果から監督が選手についての**認識(B)**を更新する経路は未実装。

## 最小の選択

- config任意キー`coach_belief`(`"none"`既定、`"observe_v1"`、`"use_v1"`)。`"none"`以外は`advice_response != "none"`が必須(ValueError)。`"none"`以外のときのみ`to_dict`にキーを出す。
- 認識(B層): 監督×選手ごとの**受容度**の信念。Beta分布の疑似回数`(a, b)`(事前`(1,1)`)、観測数`n`、表明理由の回数。純関数`update_receptiveness_belief(belief, outcome)`は`coach_advice_outcome`イベントのデータだけを入力とし、`response`と`stated_reason`以外のキーを読まない。信号`s`: complied=1.0、partial=0.5、refused=0.0。更新: `a ← 1 + 0.97(a−1) + s`、`b ← 1 + 0.97(b−1) + (1−s)`(古い観測を忘れる。信頼は時間で動くため非定常)、`n+=1`、`reasons[stated_reason]+=1`。平均`a/(a+b)`、標準偏差`sqrt(ab/((a+b)²(a+b+1)))`。全て`round6`。Cの学習(方針の重み更新)ではなく認識の更新だけ。
- 記録: 更新ごとに構造化イベント`coach_belief_update`(actor=監督、`record_class: "coach_belief"`、`coach_id`・`player_id`・`mean`・`sd`・`n`、cause_refs=[該当`coach_advice_outcome`])。信念は`world.coach_beliefs`(有効時のみ)。**信念は`coach_advice_outcome`イベント列の純粋な畳み込みであり**、不変条件でイベントから再計算して一致を要求する。
- 利用(`use_v1`のみ、最小): `decide_coach_training`の任意引数`receptiveness`(選手→平均)。提案(propose)候補の`need_term`と`forecast_term`に`uptake = min(1, mean/0.5)`を掛ける(提案の価値は「受け入れられる確率」に比例する。信念が無い・0.5以上なら1で従来と同じ)。観察・偵察・休養は不変。候補の`components`に`uptake`を追加(利用時のみ)。`observe_v1`は信念を保持・記録するだけで判断は不変。
- 採らない案: 受容度の低い選手への提案の禁止(探索が止まる)、表明理由で提案方法を変える(別のtask)、信念への不確実性の探索ボーナス(係数が増える)、Cの重み学習(CHARTER/AGENTS違反でないが範囲外)、特性を監督へ見せる(CHARTER違反)。

## 互換契約

- 既定(`coach_belief="none"`)のconfig・snapshot・events・summaryは不変(T018・T023基準、およびT028の`advice_response`のみの42セルと完全一致)。`decide_coach_training`の`receptiveness`未指定は従来と1バイトも変わらない。
- `observe_v1`は信念イベント`coach_belief_update`を除き(IDを詰め直すと)`coach_belief="none"`と完全に同じ履歴。`use_v1`は履歴が変わる(意図した変化)。
- 保存形式save17・指紋scopeは不変(`league_economy.py`が対象のためsource hashは変わる)。全再演readerは進行そのものを再演するので新しい読込経路はない。信頼readerは信念をイベントから再計算して検証する。
- T027/T028の静的漏れ検査の許可リストは変えない(信念関数は特性を読まない)。
