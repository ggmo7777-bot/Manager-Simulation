## 定義(研究者のみ。世界には渡さない)

- 新人=T030の`season_youth_joined`で入った選手。「完全な1年度」=入団日+21日が実行期間内にあるもの。
- **観察された**=入団+21日の時点で、入団クラブの監督の評価の`last_seen_day`が入団日より後。
- **先発した**=入団後21日以内の試合で`home_starters`/`away_starters`に1回以上入った。
- **推定誤差**=入団+21日の時点の|入団クラブの監督の技能推定−選手の真のcomposite skill|(研究者のみ真値を使う)。
- 才能の発見(記述): 新人のうち、入団+21日の時点で真のcomposite skillが自クラブのロスターの上位2人だった者の、「先発した」割合。
- 費用の測定(対照との対応差、セルごと、最終日と全期間): 現役の平均技能、平均出場満足度、平均信頼、完了移籍件数、先発の真の平均技能(試合日ごとに最新の`lineup_decision`の先発2人×4クラブの試合日直後のcomposite skillの平均)、監督の枠の使途(propose/observe/scout/rest決定の割合)、イベント数。

3. **純関数**: `decide_coach_training`の観察候補の`score`が、日数0..60×need 3水準×reapeat有無で、独立実装(`0.12+0.018*min(cap,s)+0.22*need-repeat`、cap=10/40)と一致。日数≤10では両capで全候補が同一、日数>10では観察候補以外が不変、観察のスコアは日数に対し非減少。

## 予測(反証され得る。セルの対応差、研究者のみ)

新人が完全な1年度を過ごした者について、84セルをまとめて(新人の人数も記録)。

- **P1 観察される**: 有効の新人の観察された割合が**≥0.90**(対照はT030で0.609。今回の対照の値も記録)。外れたら反証。
- **P2 先発する新人が増える(方向が不確か)**: 先発した割合が、有効−対照で**+0.03以上**。観察で推定が真の技能へ近づくと、定数0.5より弱い新人(アカデミー型の真の技能は約0.47)は推定が下がって先発から遠ざかる可能性がある。外れたら反証(減る場合も結果として記録)。
- **P3 推定誤差が減る**: 新人の推定誤差の平均が、有効<対照で、**セル単位で有効<対照のセルが過半**(新人のいるセルの中)。外れたら反証。
- **P4 費用(方向と大きさの予測)**: 監督の枠は提案・偵察から観察へ移るので、(i)最終日の現役の平均技能の対応差は負、(ii)信頼の対応差は負、(iii)先発の真の平均技能は変わらないか負。**「実質的な費用」の線**: 技能の対応差の平均が−0.005未満、または信頼が−0.010未満(T029の使い方の悪化−0.0017/−0.0090を小さいとした先例の線)。この線を超えたら探索の費用は実質的、として結果に明記する(採用判断は結果の記録とともに行い、費用が線を超えた場合は「小さい費用」と書かない)。符号検定(両側、0.05)を併記。
