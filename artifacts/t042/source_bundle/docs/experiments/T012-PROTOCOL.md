## 仮説と合格条件

1. 記録したB介入を再演できれば、全履歴整合性を維持したまま分岐の保存・再開が可能。親不変、分岐直後保存、途中保存、同じ日で複数介入、再分岐、day0を検査する。
2. 介入記録がない改変、記録内の前値/親hash/対象/順序/未来日/根拠/型/範囲の不整合を拒否。現行の破損検査を弱めない。介入なしの全状態/履歴は版と新しい空メタデータを除き前版と一致する。
3. 個体の認識にだけ介入した後、判断やキャリアが分かれる場合、その最初の行動差と後続の状態差を追える。全seedでの分岐、成長向上、移籍成功を成功条件にしない。無差・不利益も報告する。
4. 同値no-op介入は記録/根拠参照以外の状態、行動、試合、資金、キャリアを変えない。Seedと乱数キーは親から維持する。

## 注意点と延期

介入値は研究者が与える反実仮想で、観測・会話・学習によって自然に獲得された知識とは別物。介入理由は監査用文字列で、Policyへプロンプトとして渡さない。no-opで根拠参照が置き換わることは記録の差として扱い、行動の差と混同しない。

親hashは検査された親状態への参照であり、第三者の認証署名ではない。世界生成条件と全履歴ごと整合的に作り替えた別実験を「改ざん」と判定する目的はない。読込費用は全再演分と介入境界でのhash計算分が増える。今回は直接検証の高速化を同時に行わない。
