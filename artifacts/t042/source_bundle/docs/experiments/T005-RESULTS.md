## 実装した経路

監督は既存の観察1枠を使い、対象の開始/終了を自分の信号で測る。観察予約時に方法A/Bの基準予測と個体別補正を固定する。実施された練習についてだけ、監督の符号付き観測差と事前の基準予測との差をEMA係数0.5で学ぶ。選手の私的信号・G・真の成長・潜在率は更新関数へ渡さない。

補正は個体×方法ごとで初期0。保持範囲[-2,1]、提案の予測は`clip(base+補正,-1,1)`。既存の主観率0.10を更新したわけではない。方法選択の採点は変更せず、予測は選手が助言を実施した後の信頼評価に使われ、後の選択へ作用する。前後観察・予測更新は別設定で、既定はともにOFF。

| 検査 | 確認した結果 |

| H2 費用と実施 | 観察1枠と前後1組が対応。未観察には後信号/学習なし。休息は後信号のみで練習更新なし。拒否して別方法を行った場合は実施方法を学ぶ。 |

| H4 非漏洩 | 監督の入力を固定し真の率/上限と選手の私的信号を変えても、監督のその時点の学習・予測は一致。真の成長と選手Gは異なった。 |
| H5 次の行動 | 固定fixtureで監督の学習により次の予測0.06→0。同じ選手の実施経験で信頼0.448/0.520に分かれ、その後の拒否/採用が分かれた。 |

## 誤差を評価する観測者と標本を分ける

次の値は確認30runのrun内平均をさらに平均したもの。監督側は**観察した練習**の事前予測を監督自身の観測差で評価する。選手側は**採用した助言**の予測を選手自身の観測差で評価する。実施のないrunは選手側の誤差集計から除く。

| 条件 | 監督自身の観測へのMSE p1 / p2 | 選手が経験した助言予測のMSE p1 / p2 |
|---|---:|---:|
| frozen / clipped | 0.003780 / 0.003093 | 0.000918 / 0.000630 |
| learning / clipped | 0.004162 / 0.003770 | 0.001427 / 0.000971 |
| frozen / signed | 0.003399 / 0.003169 | 0.000916 / 0.000591 |
| learning / signed | 0.004109 / 0.003962 | 0.001451 / 0.001057 |

学習による誤差改善は今回の主比較では確認できなかった。監督側のMSE差はclippedのp1が+0.000383で95%区間に0を含み、それ以外の3比較は正の区間だった。選手側の助言予測MSE差はp1でclipped +0.000509 [0.000337, 0.000718]、signed +0.000535 [0.000343, 0.000753]。p2はそれぞれ+0.000345、+0.000456で正の区間だが、比較できる組は22/28seedである。

観察の誤差を学習に取り込むことや、観察/実施する方法の分布の違いが関わりうる。これらの寄与を主比較だけから分解したとは言わない。監督の観測振幅0.065、EMA0.5を結果に合わせて変更していない。

## 独立した対照

- **信頼固定、seed17。** 予測補正を学ぶと提案の予測値は変わったが、G方式が同じON/OFF間で全候補得点・選択・真値の履歴が一致。即時採点へ予測を混入させず、信頼を介する経路を確認した。
- **ノイズ0、seed17。** 学習ON/OFFで選手の行動21.43%、監督32.74%が異なった。p1の監督観測MSEは0.000485→0.000112、助言予測MSEは0.000487→0.000079、信頼0.279→0.681。平均技能gainは0.490810→0.484845と下がった。予測の正確さと良い練習の選定の違いを示す一例であり、一般的な効果量ではない。
- ノイズ0では同じ学習設定内のclipped/signedは、方式名だけを除いたsnapshot全体が一致した。

## 履歴から説明できる例

代表seed17のp1は3日目、真の技能が+0.037012伸びたが、監督の私的な観測差は−0.026393だった。監督は事前予測0.068との差からAの補正を0→−0.047196へ更新した（event77）。

5日目の提案108はこの補正を参照し、基準0.058179を0.010983へ修正して伝えた。選手の実施後の観測差は+0.070540で、自分の予測0.035790のほうが近かった。信頼は0.719351→0.672560へ低下（119）し、次の判断135がこの信頼を参照した。真の成長は研究者ログであり、監督の学習入力には使われていない。[根拠一式](../../artifacts/t005/review/causal-trace.json)
