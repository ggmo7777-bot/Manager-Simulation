- **判定（支持）**:
  1. `match_feedback='prior'`（試合結果を監督認識へ還流しない条件）では、初期評価の低い挑戦者 `p3` は12試合中一度も先発に選ばれず（`p3_appearances = 0.00`, `p3_max_bench_streak = 12.00`）、`p1, p2` が全12試合に固定出場した。
  2. 一方 `match_feedback='feedback'` では、序盤に `p1, p2` が強敵 `away` に敗れて試合評価 $\hat{m}_{c1, i}$ が低下し、練習で急成長した `p3` が中盤から先発枠を奪取した（`p3_appearances = 5.40` 試合、`p3_coach_final_match_rating = 0.4109` vs `coupled_prior` の `0.3000`）。
  3. さらに `coupled_feedback` と `decoupled_feedback` の比較（交互作用 `interaction_coupling_by_feedback`）を見ると、`decoupled_feedback` では誰が出ても試合に負け続けるため先発が毎試合たらい回し（`lineup_switches = 9.30`, `p3_coach_final_match_rating = 0.1431`）になるのに対し、`coupled_feedback` では成長した選手が試合で結果を残して定着するため切替回数が `5.23` 回（差 `-4.07`, `95% CI [-4.77, -3.40]`）に落ち着き、監督の `p3` 最終試合評価が `+0.2678`（`95% CI [+0.1833, +0.3711]`）高まった。これこそ **育成(`A/B`) $\leftrightarrow$ 監督選考 $\leftrightarrow$ 2D競技の双方向結合固有の創発現象** である。

### 3.3 H3: 初期評価バイアス・ローテーション配慮・選手スタイル介入によるキャリア分岐（確認セット `100..129`）

- **判定（支持）**:
  1. **初期評価バイアスによる履歴効果（`fair_prior_p3` vs `coupled_feedback` vs `coupled_prior`）**: `p3` の真の初期能力 `(0.43, 0.43, 0.43)` や学習率 `(0.145, 0.135)` を一切変えず、監督の初期評価だけを `(0.32, 0.30) -> (0.47, 0.53)` に適正化した `fair_prior_p3` では、`p3` の出場試合数が `5.40 -> 7.57` 試合（`+2.17`, `95% CI [+1.07, +3.30]`）へ増え、`p3_skill_gain` が `+0.0050`（対 `coupled_prior` では `+0.0198`）、3人平均 `mean_skill_gain` が `+0.0040`（`95% CI [+0.0015, +0.0066]`）、チームの通算得失点差 `goal_diff` も `+0.87 -> +2.77`（差 `+1.90`, `95% CI [+0.20, +3.80]`）へ有意に向上した。
  2. **ローテーション規則の効果とトレードオフ（`rotation_feedback`）**: ベンチ連続ボーナスを入れた監督は `p3` の最大連続ベンチ数を `3.70 -> 1.33` 試合へ縮め、`p3` の出場数を `7.00` 試合（`+1.60`）に増やした一方、好調な先発（特に `p1`）も頻繁に外すため先発切替が `10.47` 回に達し、`p1` の成長量が `-0.0082` 低下して3人平均成長量は `-0.0033` となった。「機械的ローテーションは出場機会の平準化には効くが、初期認識の是正（`fair_prior_p3`）ほど全体の育成・競技成果を同時に高めない」という示唆的な対比が得られた。
  3. **2D試合スタイルのキャリア波及（`p1_pass_style_plus`）**: `p1` の2D試合スタイルだけをパス偏重（`pass_bias: 0.62 -> 0.84`, `directness: 0.52 -> 0.36`）に変えると、試合での `home_pass_attempts` が `+7.03` 回（`95% CI [+0.90, +13.10]`）増える一方、強敵相手の中盤でのパス失敗からボール保持が `-9.00` ticks 減少し、監督の `p1` 試合評価が下がって `p1` の先発出場が `9.30 -> 6.77` 試合（`-2.53`）へ減少、代わりに `p2`（`+1.37` 試合）と `p3`（`+1.17` 試合）の出場が増えるという「2Dピッチ上のプレースタイル $\to$ 試合評価 $\to$ 出場機会と練習選択」の連鎖が確認された。
