# T015 — 初期集団の分布生成

登録: 2026-11-08（実装前）。状態: 実装・検証完了（未凍結。採否はユーザー判断）。結果: [T015-RESULTS](../experiments/T015-RESULTS.md)。担当: **Claude Sonnet 5.5**。T001〜T014の作成者（Sol 6.1 High / Antigravity Gemini 4 Argon / Codex）とは別の主体。T014はユーザー指示で採用・凍結済み（判断者はユーザー）。T015の採否・凍結の判断は私が行わない。

## 仮説と最小範囲

固定fixture（p3/p9が特定の監督に過小評価される）の結果は、その台本に依存している可能性がある。world seedから、クラブ類型（育成/補強）ごとの範囲で選手プロフィールと各監督の初期印象を生成できるようにし、固定fixtureの結果がどこまで残るかを見る。

- `population_mode`: `fixed`（従来、既定）/ `sampled`。条件名の`_sampled_population`接尾辞で指定。制度（市場・還元）は同名の基底条件と同じ。
- sampled: 特徴3値・成長率A/B・上限・好み・忠誠・野心・自律・自己推定を範囲から`sha256-keyed`で抽出。監督の初期印象は、各選手の水準に独立な±0.06の誤差を足した値。選手IDによる台本（p3/p9の過小評価、満足度0.42）は使わない。
- save16 / rules `t015-sampled-population-v1`。Policy、観測、請求、移籍、通貨は変更しない。

## 検証

- 全unittestと新規`tests/test_t015.py`。
- fixedモードがT014凍結版と同一であること（全7条件×seed100..104×84日、全イベント列とsummary、identity/conditionのみ除外）。
- sampled: 3制度×seed100..129×fixed/sampled。制度効果の対応差（seedごと）を平均/区間/符号数で報告。結果を見て範囲やseedを選び直さない。

## 限界（事前）

範囲は仮説で、現実の選手分布の校正ではない。育成/補強の類型差を範囲で与えるため、類型差は結果の一部ではなく入力。`talents_*`の要約名はスロット名で、samplingでは特別な才能ではない。選手数・クラブ数・移籍窓は固定、世代交代は未実装。
