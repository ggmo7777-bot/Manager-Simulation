# T042 — 練習の選択を状態変数別に分解し、休養率から先発一致までの媒介と、助言への応答との相互作用を測る(研究者のみ)

## 問題

T041は、centered_v1の先発一致の利得(+8.68pt)が、選手の練習の選択(休養か練習か、どの方法か)だけを差し替えれば再現・消去されること(順方向+9.83pt、逆方向+8.10pt、帰属はsingle_route(practice))を示した。練習の選択は3つの自己観察由来の状態(期待利得・疲労知覚・信頼)を同時に読むので、どれが利得を運ぶかは分かっていない。また、(1) 運ばれた利得がどの道筋で先発一致に届くか(休養率→技能の広がり・観察の質→先発一致)、(2) 助言への応答の差し替えが逆方向で先発一致を**上げる**(`harm(response)`、R=−1.74pt)のは練習の選択との相互作用か、が残った。本taskはこの3つを測り、選手の判断が理由を追跡できる形で変数ごとにどう変わるかを記録する。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。** T041の選手側の状態の2本の列(世界の方式`real`と、もう一方の方式`alt`)をそのまま使い、練習の選択が読む3つの状態(期待利得`g`・疲労知覚`f`・信頼`t`)を、**判断の瞬間だけ**、1つずつ・2つずつ・3つともalt側に差し替える(2^3の全組合せ)。助言への応答`R`の差し替えを加え、練習の状態の差し替えと組み合わせて(`R`、`tR`、`gftR`)相互作用を測る。順方向(legacyの世界にcentered_v1の状態)と逆方向(centered_v1の世界にlegacyの状態)で、各11腕、計22腕。移籍は T041で動かなかった(担い手でない)ので対象外(素のまま)。媒介は、腕を休養率の外生的な変動として使い、研究者が真の技能を読んで、先発一致を「真の2番手と3番手の差(広がり)」と「監督の評価の誤差(観察)」に分けた上で、休養率→広がり/観察の誤差→先発一致を腕×セルの差分で統計的に分解する。最後に、centered_v1を既定にする提案の推奨を、登録した規則で書く(推奨のみ。既定は変えない)。

- 対象外: `soccer_sim/`の変更、新しいconfig、既定の変更、幅の調整、水準とばらつきの分離(centered_v1は両方を変える。別task)、状態の更新規則の差し替え、移籍の判断、監督側の判断(T040で測定済み)、CLI/UI。戻し方: `experiments/t042.py`、`tests/test_t042.py`、`artifacts/t042/`、文書の削除のみ。
