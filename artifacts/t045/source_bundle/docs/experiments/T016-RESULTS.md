# T016 結果 — 初期集団の比較と移籍なし集団の記述を分離

実装・実験: 2026-11-08。最終確認・記録: 2026-11-09。実装Sol 6.1 High、設計・独立監査・記録Codex。契約: [T016](../tasks/T016.md)、事前条件: [PROTOCOL](T016-PROTOCOL.md)。

**初期育成6名を固定して追跡する主指標へ修正した。** 旧T015の180世界と全状態・全履歴が一致し、変更は研究者向け評価に限定されている。移籍しなかった選手の平均は別の記述統計として保存する。

## 変更した評価契約

| 用途 | 集団・キー | 取扱い |
|---|---|---|
| 主比較 | `academy_initial_cohort_*` | `initial_players`の初期所属から選ぶ全育成選手。現モデル6名。移籍後も含める。ID/人数/成長を記録する |
| 記述統計 | `academy_never_transferred_*` | 初期育成集団のうち移籍回数0かつ初期クラブにいる者。帰還者・外部加入者は含めない。条件間差を残留者への因果効果と呼ばない |
| 旧値の診断 | `legacy_four_slot_*` | p1,p2,p7,p8の固定スロット。旧数値は再現するが集団名を修正する |

旧キー`academy_retained_skill_gain`は現行summaryから削除。空集団の平均はnull、件数0、ID空。空世界を0成長として平均へ入れない。集団平均は個人成長を6桁丸めた後、`fsum`で加算して6桁丸める。評価器のラベル付替えで結果が変わらないことも検査した。世界全体のラベル不変性を検証した意味ではない。

評価版は`evaluation_version=t016-initial-cohort-v1`。save16、`t015-sampled-population-v1`ルール、T013 Policy、保存状態schemaは維持した。ソース指紋は`b64227f57002046605fe1ac33dd59c63d81ad6a851f3bc7f53f202ba7002e7b4`。旧snapshotは旧ソースで読む。指紋を読み替える移行は行っていない。

## 制度比較の結果

同じ初期個人状態・同じseedの世界を対応付けた。独立単位は各集団モードの30世界。区間は探索的なt区間であり、既知の30seedを再分析した結果。多重比較を調整した確証とはしない。値は内部composite skillの成長差。

| 初期集団 | 初期育成6名への比較 | 平均差 [探索的95%区間] | 正/負/ゼロ |
|---|---|---|---|
| fixed | 開放市場で還元あり − なし | +0.015301 [0.012572, 0.018029] | 30/0/0 |
| sampled | 開放市場で還元あり − なし | +0.007379 [0.005720, 0.009039] | 29/0/1 |
| fixed | 還元なしで開放市場 − 閉鎖市場 | +0.017004 [0.015440, 0.018567] | 30/0/0 |
| sampled | 還元なしで開放市場 − 閉鎖市場 | +0.016175 [0.013832, 0.018517] | 30/0/0 |

還元あり/なしの旧固定4名差はfixed +0.022951、sampled +0.006886で再現した。新主指標ではsampledの効果量はfixedの約48%だが、初期分布と印象等を同時に変更した比較であり、縮小理由の分解は未実施。旧4名の約30%という比率を、残留者への効果の比率として採用しない。

補助指標の全12名平均成長差（還元あり − なし）はfixed +0.007650、sampled +0.003528。制度パッケージの総効果であり、設備だけ、配当だけ、移籍なし選手だけの効果とは言えない。

## 実測と独立検証

- 全190テスト合格、97.032秒。高速ゲート48件合格、2.698秒。新規は集団10件、分析5件。
- fixed/sampled×3制度×30seed×84日、180世界で旧T015とidentity以外の全状態・全イベントが一致。旧8集計もlegacyキーの明示対応後に保存済み値と全件一致。
- 初期/最終traits・所属・移籍イベントから独立に集団・人数・成長を再計算し全180本一致。107,376件の取引、3,344要求、624配当決済を既存の独立整数監査で照合。今回の180本は攻撃専用条件を含まない。
- fixed/sampledの開放・還元あり/なしの4代表で84日と42+42日がsnapshot/events/summaryとも一致。sampledの記録付き信頼介入でも42日checkpointから84日への再開が一致。旧版との分岐比較はidentityと版依存の親checkpoint hashのみ除外し、介入値・理由・順序・原因参照を保持した。
- 旧関数の構文木で変更されたものはidentity、summary、保存manifestの関数だけ。進行/Policy/観測/会計/初期生成は変更していない。
- 旧成果物1,702ファイルはhash不変。T015の修正前ソースを`artifacts/t015/reference_before_t016/`に保管した。これはT015の生成範囲を科学的に採用する判断とは別。
- 比較・再開・監査全体272.320秒、peak RSS約137.3MiB（macOSのbytes値143,949,824）。全テストと並行実行した値であり、単独性能ベンチマークではない。
