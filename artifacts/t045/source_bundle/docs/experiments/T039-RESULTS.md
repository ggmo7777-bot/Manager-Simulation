実施: 2026-11-11。契約: [T039](../tasks/T039.md)、事前条件: [PROTOCOL](T039-PROTOCOL.md)、判断: [D054](../DECISIONS.md)。`soccer_sim/`は凍結T037 source_bundleとバイト一致(config追加なし、既定は`legacy`のまま)。T037/T038と同じ3設定×84セル×168日を`legacy`/`shifted_v1`/`centered_v1`で再演(756実行、`lineup_decision`24,192件/群、選手の行は73,431/群)。実行: `uv run --python 3.13.3 python -B experiments/t039.py --out artifacts/t039/run`(約11分)。

## 結論(平易に)

1. **登録した本命(P5)は反証された。同じ観察の列で雑音の平均(+幅)だけを除いても、先発一致は上がらず、むしろ下がる**(C_all −0.97pt、区間[−1.15, −0.79]。登録した基準は+3.5pt以上)。T037の動的な利得(shifted_v1 +7.0pt、centered_v1 +8.7pt)に対する説明率は負(−14%)。つまり利得は「静的な順位のゆがみの補正」では説明できず、平均を直した世界で**履歴が変わること**(動的な経路)から来る。
2. **出場者と控えは、受ける観察チャネルが完全に分かれている**(構造どおり): 前の試合に出た選手は窓あたり試合の観察がちょうど1回で練習の観察は0回、控えは試合の観察が0回で練習の観察が0.50回(t030は0.08回、t031/t032は0.7回)。偵察は在籍者にほぼ届かない(0.01回)。
3. **平均のずれは、出場者では試合チャネル、控えでは練習チャネルで推定に入り、総合点では出場者の方がわずかに多く上がる**(出場者+0.0070、控え+0.0055、差−0.0015 [−0.0020, −0.0011])。出場者は試合の観察の推定への質量が大きく(技能の約61%、試合評価の約77%)、控えは練習のみ。除くと出場者が相対的に強く見えるので、控えの昇格は減る(控えだけを補正した場合−1.17pt、出場者だけ−0.60pt)。T038が事後に見た「控えの推定の方が大きく上がる」は、静的な伝播ではなく**群の構成の変化を含む実走の差**だった(静的な群差−0.0014 vs 実走の群差+0.0088)。
4. **事後(post hoc)に見た動的な兆候**: 平均を直した世界では、控えで真の上位2人に入る選手が先発に入る率が28.7%→41.4%(+12.7pt)、出場者で上位2人に入らない選手が先発に残る率が73.8%→61.9%(−11.9pt)。控えの練習観察は+8.6%増える(t030は+75%)。これは**どの意思決定が水準のずれを受け取るか**を調べる次のtask(T040候補)の手がかりで、機構の検証ではない。
5. **既定をcentered_v1にする提案の推奨は、登録の規則で「保留」。** 静的な出場/控えの機構では利得を説明できない。ただし結果指標(先発+8.7pt、MAE、最終技能など)の利得はT036/T037のまま。詳細は末尾。

## 正直な注記(解析の自由度を含む)

- **1回目の全実行(`artifacts/t039/run-first/`)の登録指標を見てから**、事後の補助指標(A: 反実仮想と実走の一致診断、B: 観察の配分の実走差、C: 昇格・降格率)を足して再実行した。再実行の登録指標は1回目と**完全に一致**(すべてのスカラーの点推定・区間)。事後の指標は判断規則に使っていない。PROTOCOLの追記にこの経緯を残した。
- **2回目の実行は診断Aの集計で止まった**(履歴の分岐で、片方の実行にしか在籍しない選手がいて`KeyError`)。ログは`run-log-crashed.txt`。診断で「片方にだけ在籍」を不一致として数えるよう直して再実行した。診断Aの最初の試作は、決定後(同じ日の試合の観察の後)の状態を読んでいて誤った不一致を出した。決定時点のコピーを取る形に直した。
- 静的な反実仮想は「同じ観察の値のまま、推定だけ+幅」の再順位付けで、監督の将来の行動(練習の配分・移籍)の変化を含まない。centered_v1のばらつき側の効果は扱えない(T037の分解を参照)。F(説明率)はこの意味での静的な部分の割合で、動的な利得の機構の同定ではない。
- 事後の昇格率・配分の変化は、群間の差が「雑音を変えた世界の値」の比較である点と、群の構成が結果と同時に変わる点で因果の推定ではない。出場者の実走の変化が静的の3分の1以下になる理由は未検証。
- ロスターは3人(先発2人、控え1人)なので、群の対は常に出場者×控えの組。世界は3seedを共有し独立でないので区間は過小の可能性がある。t030は控えの練習観察が0.08回/窓と少なく、設定間の構造が異なる(C_allはt030で最小−0.26pt)。
- 疲労の反実仮想は`observe_fatigue`を同じ引数・同じキーで`centered/shifted`にして呼んだ値(クランプ込み)で、疲労は0付近で下限にクランプされる効果も入る。

## 既定を`centered_v1`にする提案の推奨(提案のみ。既定は変えない)

登録の判断規則: 「推奨」はC_all ≥ +3.5ptで区間の下限>0かつP4またはP8が支持、「条件つき」はC_allが+1.5〜+3.5ptで下限>0、またはP4とP8がともに支持、それ以外は「保留」。C_all = −0.97pt、P4・P8とも反証なので、**規則では「保留」**。

読み方: 「保留」は「centered_v1が悪い」ではない。T036/T037の結果の指標(先発一致+8.7pt、技能推定MAE、最終技能+0.0057、信頼+0.0050)の利得と、新人以外の試合評価推定の偏りの小さな悪化(+0.0030)のみ、という事実は変わらない。本taskが示したのは、利得の説明が「静的な出場/控えの順位のゆがみ」ではなく、平均を直した世界で履歴が変わる**動的な経路**にあること。静的な再順位付けでは先発一致が下がるのに、実走では控えの真の上位選手の昇格が増え(28.7%→41.4%)、出場者の誤った残留が減る。したがって、既定の移行提案は、**この動的な経路(どの意思決定が水準のずれを受け取るか)を介入で分解するT040の後**に行うのが妥当。移行には凍結成果物(T018以降の基準)の置換・再基準化が伴う。

## 次の候補(実装ではない。別task、未着手)

**T040(候補): どの意思決定が推定の水準のずれを受け取って利得になるか(介入による分解、研究者のみ)。** legacyの世界を走らせながら、研究者が本taskの反実仮想推定(`all`、同じ観察列に+幅)を、決定関数が読む推定の代わりに**1つの意思決定だけ**に渡す(コーチの練習の配分/先発/移籍の入札・売却)。`soccer_sim/`は変えず、呼び出しの間だけ評価値を差し替える研究者側のラッパーで行う。4条件(それぞれ+全部)×252セルで、先発一致・昇格率・最終技能を測り、動的な利得(+7.0pt)のうち各意思決定が運ぶ割合を出す。結果次第で既定移行の提案を判断する。
