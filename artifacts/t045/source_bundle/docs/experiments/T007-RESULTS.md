## 経験の偏りと帰属

learning/adaptiveでp1が受け取った提案数0/1/2の日は平均52.53/11.57/19.90日。p2は76.23/6.87/0.90日で、feedbackはc1に0.27回、c2に0.30回にとどまる。p2では各相手について確認30run中23runで評価経験が0。信頼終値が初期0.28付近に残ることを、精度が互角・信頼が安定している証拠とはしない。受領予測MSEも欠損を0で埋めず、有効run数とともに保存した。

各監督は約54枠を観察、約30枠を提案に使い、休息はほぼない。同対象への重複観察はlearning/adaptiveで45.40日/run。各自が費用を払い別信号を取得する。人数を増やせば情報が効率よく集まるという保証はなく、通信や観察分担は未実装。

同方法を2人から勧められても助言得点は加算しない。一方、実施経験と照合できる予測はそれぞれ評価する。learning/adaptiveではp1について得点の出所でない相手へのfeedbackがc1に2.50回、c2に2.67回/run発生した。

固定代表seed17ではこの同方法二重評価が発生しなかったため、主比較の探索seedを昇順に見て該当する最初のseed0を説明例として再生成した。集計や成功条件の差替えではない。[55日目の記録](../../artifacts/t007/review/attribution_example/causal-trace.json)では、p2がAを実施し得点の出所はc1。観測差−0.000714に対しc1予測0.065897、c2予測0.028086を別々に評価し、信頼は0.234602→0.184602、0.226914→0.216433となった。両方が下がる結果もそのまま記録した。方法の一致から「c1に服従した」と動機を断定しない。

## ノイズ0と機構検査

ノイズ0・seed17では信頼適応化でp1の8/84日の行動が変わり、2選手平均の不一致率は4.76%。監督の行動は不変。両監督の事前信念が異なるため、乱数がなくても相手別評価は分かれた。

この対照では監督予測の学習ON/OFFによる行動差は0で、各監督の観察した練習標本も2件だけだった。主比較の学習効果を全環境に一般化しない。固定fixtureではc1だけの記憶変更、提案受領順と実際の監督計算順の反転、ノイズ0で監督プロフィールの割当交換を検査した。同方法の二つの予測で信頼を0.75→0.80/0.70へ別方向に更新する手計算も合格した。

### 1. 監督予測学習の誤差悪化原因と残差学習率 $\alpha_{\text{res}}$ の感度

`multi_learning_adaptive` で観察練習上の監督予測MSEが悪化した主因は、前後2回の私的観測差 `after - before` が持つ合成ノイズ分散（$2 \times 0.065^2 / 3 \approx 0.002817$）に対し、`COACH_RESIDUAL_ALPHA = 0.50` が1標本の誤差の半分を定常補正として取り込む過適合にあった。確認30seed・84日で残差学習率を変えた実測は以下のとおり。

|---|---:|---:|---:|---:|---:|---:|---:|

| `0.05` | 0.502049 | 0.003266 | 0.003191 | 0.000943 / 0.001786 | 0.650 / 0.585 | −0.000005 [−0.000080, +0.000068] | −0.000080 [−0.000163, −0.000010] |
| `0.10` | 0.501356 | 0.003214 | 0.003109 | 0.000941 / 0.001607 | 0.648 / 0.587 | −0.000057 [−0.000204, +0.000085] | −0.000162 [−0.000334, −0.000019] |

### 2. 低信頼時の「負の助言項（反発）」と「助言無視（非負クリップ）」の比較

現行式 `advice_term = 0.055 * (trust - autonomy)` は `trust < autonomy`（`p2`: 初期 `0.28 < 0.58`）のとき負値となり、提案された方法自体を減点して避ける（反発）。これを `0.055 * max(0.0, trust - autonomy)`（信頼が自律性未満なら助言ボーナスを0にして無視し、本人の期待gainと好みで自主判断）へ変更した対照では、確認30seed・84日で以下を確認した。

- `p2` の行動は `21.43%`、`p1` は `5.79%` 変化し、`p2` のfeedback回数（1run平均）は `c1: 0.27 → 1.43` 回、`c2: 0.30 → 1.73` 回へ約5倍に増加した。
- `p2` で評価経験が一度もないrun数は `c1: 23/30 → 12/30`、`c2: 23/30 → 8/30` へ半減以下となり、平均技能gainは `0.500987 → 0.500574`（対応差 `−0.000413 [−0.001955, +0.000807]`）と維持された。

### 3. 両予測が負のときの提案抑制ガード（T006 / T007）

`forecast_rank` で $\max(q_A, q_B) \le 0$ の場合に提案候補のボーナスを抑制するガードを入れると、両予測が負の提案は T006 `learning_rank` で `27.97 → 0.00` 件/run、T007 `multi_learning_adaptive` で `5.67 → 0.00` 件/run（2監督合計）へ完全に解消した。T006では観察が `55.00 → 67.33`、監督休息が `0.00 → 3.13` 枠へ増え、`p1` 信頼終値が `0.390 → 0.469`（`+0.079126 [+0.019685, +0.136756]`）へ改善した一方、平均技能gainは T006で `−0.001050 [−0.004132, +0.001688]`、T007で `−0.000990 [−0.001983, −0.000128]` となった。

### 4. 同点 `score_source` 順序と重複観察（初期観察位相の非対称化）

- **同点出所順序**: `score_source` の同点選択を `c1` 優先から `c2` 優先へ反転しても、確認30seedの `multi_learning_fixed`・`multi_learning_adaptive` ともに行動不一致率 `0.0000%`・技能gain差 `0` であった。`multi_learning_fixed`（終始同信頼）では `p1` の非出所feedback（`non_dominating_feedback`）が `c1/c2 = 0.00/4.93 → 4.93/0.00` と対称に反転し、`multi_learning_adaptive` では初日以降に信頼が分岐するため `2.50/2.67` のまま不変だった。
- **重複観察の緩和**: 両監督が84日中平均 `45.40` 日も同対象を重複観察する主因は、初期技能評価（`p1=0.32, p2=0.46`）と初期 `last_seen=0` が完全同一であるためである。初期 `last_seen` に1日の相補的位相差（`c1` は `p2`、`c2` は `p1` を `−1`）を与えると、2人とも観察を行う日数（`49.70 → 49.83` 日）を保ったまま、**同対象の重複観察日数が `45.40 → 4.17` 日（90.8%減）**へ激減した（平均gain差 `+0.000471 [−0.001634, +0.002599]`）。
