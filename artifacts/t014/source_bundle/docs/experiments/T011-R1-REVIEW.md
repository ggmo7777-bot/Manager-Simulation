## 根拠と検証範囲

1. **成長経路**: 削除されたボーナスの設定を受け付けず、受領履歴だけを変えた固定状態介入で無差、設備費の支払いを変えた対照で差が出る。旧実装上の2要因分離120runにより、ボーナス削除と移籍先選択変更を区別した。新版330runの制度比較は配当単独の効果とは表現しない。
2. **保存契約**: 型を変換して丸める前のJSON全体を、検証済みseed/configの再演結果と比較する。余分/欠けたフィールド、boolとint、NaN/Infinity、重複JSONキー、終状態と全履歴の不一致を拒否。書込は検査完了後に開始する。4主条件の84日再開と1000+14日を確認した。
3. **情報境界**: 選手Policyの署名にはWorldやCoachMindを含めず、本人のMindと不変オファーだけを渡す。元の漏洩再現条件、オファー順序反転、相手別信頼、受信撤回、別人宛/重複/送信者不一致をテスト。複合判断は世界側の監査記録とし、受信イベントと本人判断を分けた。
4. **独立した会計照合**: シミュレーターの台帳関数を使わず、イベントの金額を整数micro-unitで積算。4主条件84日と1000日の各取引時点で世界資金を照合し、クラブごとの終残高・費目別累計・選手受取給与・外部流出入を照合した。これはイベントからの会計再計算であり、取引の政策的妥当性そのものの証明ではない。

旧T011の「独立監査100%」はログ内の得点成分の再加算が中心で、私的知識の生成まで独立に再構成しているわけではなかった。今回も再演検査と独立会計検査、情報境界の介入テストを区別する。
