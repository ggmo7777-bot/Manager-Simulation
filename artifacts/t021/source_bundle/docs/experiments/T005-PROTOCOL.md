# EXP-T005 事前実験計画

登録: 2026-11-05、実装/結果観察前。監督の方法予測の更新と、その知識を得る観察経路を追加する。前後観察を伴う1枠は抽象的な1セッションの費用であり、現実の時間や測定機器の再現ではない。

## 情報と時点の契約

1. 監督は従来の採点で対象を観察すると決め、既存の2枠/日から1枠を消費する。前後観察モードではその選手の練習セッションを追跡する。費用を払わない個体は対象にできない。
2. 朝の監督観測は既存の`coach-skill`信号を使用する。夕方は別の`coach-skill-post`キー、同じ観測振幅0.065で監督自身の信号を生成する。選手の`self-pre/post`信号や真のgainは使わない。
3. 観察予約時点で、監督が持つ技能推定・方法別主観率・個体×方法の補正からA/B両方の予測を固定し、その根拠IDを残す。今日の朝の測定による技能評価は従来どおり夕方に反映する。
4. 実施後、観察中だった個体の実際の方法を認識し、前後信号の差を作る。実施方法のラベルは観察者に分かるという仮定。選手が助言を拒否して別方法を行ったなら、その実施方法だけを学ぶ。休息は練習方法の失敗標本にしない。
5. 夕方に更新する。自己G・選手の信頼・監督の技能評価とは独立した更新とし、当日の提案を書き換えない。次の提案へ補正を使う。

新設定は「前後観察の取得」と「予測補正の更新」を別々に制御する。更新ONかつ取得OFFは無効設定。既定は両方OFFで旧動作を維持。取得ON・更新OFFでも同じ私的な前後観測と事前予測誤差を記録する。

## 更新するもの

個体i・方法mごとに補正rと根拠eventを保持し、初期値r=0を明示する。方法別主観率0.10そのものを更新しない。

```text
base_before = subjective_rate[m] * (1 - perceived_skill_before)
forecast_before = clip(base_before + residual_before, -1, 1)
y_coach = paid_post_signal - paid_pre_signal
target_residual = y_coach - base_before
residual_after = residual_before + 0.5 * (target_residual - residual_before)
```

yは[-1,1]、baseは[0,1]なのでrは[-2,1]の範囲で保持できる。最終予測は[-1,1]。負の主観的予測を真の技能低下と混同しない。補正0では旧予測をそのまま保つ。観測の後に更新した技能評価や補正で事前の誤差を採点し直さない。固定率と個人補正を学習済みNN重みとは呼ばない。

個人補正を使うのは提案に添える予想gainと、次の観察時の予測だけ。監督の方法選択の得点は変えない。選手も受け取った予測を即時の得点へ直接入れず、実施後の既存の信頼更新へ使用する。

数値は各G設定内の学習ON−OFF、各学習設定内のsigned−clipped、交互作用 `learning_signed - frozen_signed - learning_clipped + frozen_clipped`。対応seed単位bootstrap 2,000回、解析seed5005、95% percentile区間。欠損を0にせず、比較に使える組数を示す。

行動不一致率は上記4つの単純比較ごとに2条件の実際の行動列から算出。異なる基準への距離の差を条件間の不一致と呼ばず、不一致率のfactorial交互作用は定義しない。

## 指標

- 監督の観察枠数、前後観察数、学習適格数、休息により学習しなかった数、個体×方法の更新回数と補正の推移/終値。
- **観察した練習**での事前base/補正予測と監督自身の符号付き観測差の誤差。更新後の当てはまりを将来予測精度として使わない。
- **採用された助言**について、選手の私的信号に対する監督予測誤差/自己予測誤差、信頼/採用/経験機会。監督観測に対する誤差とは観測者も標本も異なる。
- 学習補正を使った提案数、個体別の選択/休息/技能gain、監督配分、信頼の変化。正確な予測と有用な方法の選定を同一視しない。
- 時間予算/状態/原因参照の整合、保存・再開、本体時間、出力サイズ、メモリ。実験ログの量とシミュレーション本体の費用を区別する。

## 機構と負の対照

| ID | 検査 | 受入 |
|---|---|---|
| H1 同じ主観入力 | 同じ前後信号・基準予測から補正を手計算、正/負/0の差 | 対象の個体×実施方法だけ更新、OFFは0のまま、値と根拠を追える |
| H2 有料観察 | 予算消費と前後観測を照合、未観察/休息/助言拒否 | 未観察の個体に後信号/補正更新なし、休息で練習更新なし、拒否後は実施方法を学ぶ |
| H3 事前予測 | 当日技能評価の更新と補正更新がある日 | 予約時点のbase/r/根拠を誤差に使用。当日提案は旧補正、後日の提案は更新根拠を参照 |
| H4 非漏洩 | 世界の率/上限/選手私的信号を変え、監督の私的入力を固定 | その時点の監督学習と予測が不変。更新関数にWorld/真のgainを渡さない |
| H5 作用の経路 | 同じ観察経験による学習補正を後の提案へ使うfixture | 予測が変わり、同じ選手側の実施経験で信頼評価が変わる。必要な境界fixtureで次の選択への接続を確認 |
| H6 記録だけの対照 | 前後観察ON・補正OFFを旧T004と比較 | 情報を記録するだけで数値/選択/信頼の推移を変えない |
| H7 保存 | 4条件84日vs42+42、learning_signed1000日 | snapshot/JSONL一致、補正と根拠が保存される。不正/欠落config、範囲外/非有限値、参照不整合を拒否 |

主比較と別に、**信頼固定**で上の4条件をseed17・84日実行する。予測補正が変わっても、その設定内の学習ON/OFFで選手と監督の選択・真の状態は一致するはず。選手の即時採点や監督の採点へ予測を混入させていないことを検査する。

**ノイズ0**でも上の4条件をseed17・84日実行する。学習の作用が残るかはそのまま報告し、差を作るために調整しない。対応する学習設定内のG方式間は非負成長のため一致するはず。主比較の標本数へ含めない。

固定観測の小さなprobeで更新の直接効果を確認し、閉ループの監督/選手双方の反応を含む総効果と区別する。旧T001〜T004のartifactを保全し、旧readerによる再現を維持する。save/rule版を上げ、新readerで黙って旧保存を解釈しない。

## 採否と限界

成功条件は情報と費用の境界、経験から知識への更新、次の提案への利用、履歴と再現性。予測精度やgainの向上を必須条件にしない。監督が得る経験は観察対象の選択と選手の選択に偏り、疲労/潜在上限を知らない小さなモデルである。残差の学習だけで指導能力全体を実装したとは言わない。
