# T012結果 — 記録付き認識介入と分岐世界

2026-11-08。基礎実装Sol 6.1 High、利用上限後のレビュー/補修/実験はCodex。D027で登録し、外部レビューを受けD028でT013修正後に比較を実施するよう変更した。

## 実装したもの

日境界の `fork_league_world` と `branch` CLI。監督1人の1選手に対する技能推定、または選手1人の1監督への信頼だけを変更する。親を検査・複製し、親checkpoint hash、対象、前後値、理由、日/順序、前の観測参照を記録する。研究介入は通常の観察/自律学習と区別する。

全再演readerを維持し、同日複数介入・後日の再分岐・通常resumeに対応した。親は不変。介入直後のA状態・所属・資金を変えない。不正な対象/範囲/型、親hash/前値/根拠/順序の破損、記録外の状態変更を拒否する。

修正前save13は10テストと無介入24runのR1との全履歴一致のみを確認した（identity/新しい空メタデータを除外）。`artifacts/t012/precorrection/`に凍結。以下はT013最終save14/source `f05e4b33…592ad`での結果であり、旧ルールの結果と混同しない。

## 200系列の結果

day14の同じ親から、無介入、同値介入、c1のp3技能推定0.90、p3→c1信頼0.95、同信頼0.05の5系列をday84まで進めた。探索10seed/確認30seed、計200系列。確認seed100..129の対応差を示す。

| 介入 | 行動差の出たseed | p3出場数差（day14以降） | p3移籍数差 | p3技能gain差 [95%区間] | p3練習行動不一致率 |
|---|---:|---:|---:|---:|---:|
| 同値 | 0/30 | 0 | 0 | 0 | 0% |
| 監督技能推定0.90 | 30/30 | +2 | −1 | −0.048870 [−0.054503, −0.043407] | 25.83% |
| 信頼0.95 | 30/30 | 0 | 0 | +0.002136 [−0.001507, +0.007616] | 17.39% |
| 信頼0.05 | 27/30 | 0 | 0 | +0.001056 [−0.001668, +0.005022] | 7.22% |

同値介入は探索も含む40seedで、参照と研究メタデータを除く全状態・通常イベントが無介入と一致した。親と介入直後のA/所属/資金不変も全系列で確認した。

この固定集団では、監督評価を上げた系列でp3が残留し出場を増やす一方、成長は小さくなった。これは同じ過去からの認識差が選択・経験を変える機構の例であり、「高評価は成長を妨げる」という一般的結論ではない。信頼差は練習を変えたが、確認30seedでは移籍・出場数の差を生まなかった。ドラマが必ず起こるよう調整していない。

## 根拠参照と再現性

初回の低信頼系列では、行動差27seedのうち5seedで介入への参照経路が途切れた。試合後の疲労観測に前の認識参照を残す補修後、30/30・30/30・27/27の全行動差から介入へ戻れる。探索側も全例を確認した。これらは閉ループ介入比較と根拠追跡であり、参照グラフだけで原因の一意性を主張しない。

- 最終全153テスト合格（T012は11件）。
- 代表seed100の5系列でday14保存、day42保存/再開、day84連続とのsnapshot/JSONLバイト一致。
- seed17のday14分岐を1000日まで進め、保存読込後+14日が連続実行と一致。
- day1014で再介入、同日さらに介入、保存読込後+7日も一致。
- 1000日/1014日の独立会計・受付監査が一致。旧808ファイル不変。

1000日分岐の実測: 進行5.449秒、保存9.835秒、読込7.451秒。snapshot72,254,527 bytes、JSONL37,265,835 bytes。プロセス全体のpeak RSSは約1036.6MiB（複数世界の保持を含む）。同時に他の実験も動いていたため、専用ベンチマークではない。
