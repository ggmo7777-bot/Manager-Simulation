# T006: 学んだ予測を監督の方法選択に使う

状態: **実装・検証完了**。2026-11-05、T005完了後の「進めて」により着手。[事前計画](../experiments/T006-PROTOCOL.md)に沿って71テスト、240runと独立対照、旧版240本の全履歴照合、保存再開を確認。[結果](../experiments/T006-RESULTS.md) / [主担当レビュー](../experiments/T006-REVIEW.md)。

## 問題

T005の監督は個体×方法の成長予測を学ぶが、方法A/Bの選定は従来の技能推定に基づく固定した適合式のままである。ノイズ0の対照では予測精度と選手の信頼が改善しても、成長は増えなかった。正確に予測することと、その知識を使って方法を選ぶことを次に分離する。

## 最小範囲

1. 1監督2選手のまま、監督の提案候補の方法選択項に、自分の事前予測を使う方式を追加する。観察枠・A・選手の判断/学習・監督の予測更新則を同時に変えない。
2. 同じ学習済みの主観状態を旧/新の採点へ渡し、どの予測がどの候補得点に影響したかを記録する。真の率/上限/未来のgainを参照しない。
3. 予測の学習OFF/ONと、選択への利用OFF/ONを分ける。まず固定した観測/状態の機構検査、次に両者が経験を変える閉ループを比較する。
4. 得点項の単位と重み、比較する自己G方式、観測ノイズの対照を着手前に定め、Protocolへ登録する。T005の結果に合うように重みを調整しない。

予測値を直接加算する方式は、単位の換算と観察/提案/休息間の得点を同時に変える。今回は予測の順位を使い、各対象の最高提案得点を旧方式と同じに保つ方式を選ぶ。予測同点は旧方式へ戻す。これにより補正更新OFFでは旧軌跡を保ち、更新によって順位が変わる作用を検査できる。予測の大きさや不確実性を使わない限界は残る。

`PolicyRules.coach_method_mode`を`legacy`（既定）/`forecast_rank`で切り替える。`forecast_rank`では対象のA/B予測が異なる場合、予測が大きい方法の方法項を`coach_method_fit * max(skill_estimate, 1 - skill_estimate)`、小さい方法の方法項を0にする。同点時は従来式。発達必要度・観察・休息の項、選手の判断/学習、観察費用、予測更新式は変えない。方法ごとの予測・補正・根拠を候補の記録に添える。

主比較は符号保持G・適応信頼・前後観察を共通とし、`frozen_legacy` / `frozen_rank` / `learning_legacy` / `learning_rank`を84日×60seed実行する。clipped G、信頼固定、ノイズ0はseed17の独立対照とし、主比較の集団効果と混同しない。

## 成功・失敗条件

- 同じ真値でも異なる主観予測で監督の方法選定が変わり、理由を追える。利用OFFは旧選択を保つ。
- 予測を改善しただけの効果と、その予測を判断へ使う効果を区別する。
- 選手は引き続き指示を独立に採用/拒否する。監督が技能/行動を直接操作しない。
- 誤った予測の反復、未知方法を試さない状態、観察機会や選手の休息が変わることも測る。gain最大化だけを合格にしない。
- 情報境界、時間予算、保存再開、版と過去成果物を維持する。採点を変える場合はPolicy版も更新する。

観察費用や学習係数の最適化、複数監督、選考/移籍、競技、C、UIは今回候補と同時に追加しない。監督が知識を判断へ使う経路を確認した後、M2の複数監督・相手別の関係、M3の競技、M4のキャリアへ接続する。
