# T033 結果 — 新人が先発しない理由の分解(分析のみ、simは不変)

実施: 2026-11-10。契約: [T033](../tasks/T033.md)、事前条件: [PROTOCOL](T033-PROTOCOL.md)、判断: [D048](../DECISIONS.md)。方法・定義・予測は実装前にコミットし、結果後に変えていない。Python 3.13.3(uv)。**規則・config・イベント・乱数の追加はなく、`soccer_sim/`はT032と1バイトも違わない。** 3設定(T030/T031/T032の有効設定)×84セル、新人は各1,008人(完全な1年度)、行=新人×試合日×クラブで合計9,070行(`artifacts/t033/run/rows.json`)。

## 結論(平易に)

1. **新人が先発しない行の主因は、そもそも真の技能が低いこと。** 先発しなかった行の順位差(平均 −0.080)のうち、真の技能差が約6割(−0.049)、試合評価の推定誤差が約15%、疲労項が約18%、技能推定の誤差は約6%。選考に「先発の継続(居座り)」の項は存在せず(P6)、順位表は技能項・試合評価項・疲労項の3つだけ。
2. **だが「真に上位2人なのに先発しなかった」新人(見逃し行、463〜543行)は別の姿。** 真の技能差は有利(+0.034)なのに、技能推定の誤差(−0.035)と試合評価推定の誤差(−0.036)が**同じ大きさで**不利に働き、疲労項(−0.018)も加わって順位差は −0.056。つまり推定の遅れが、才能の見逃しの中心。技能推定と試合評価推定は両方が同程度に遅れる。
3. **遅れは時間とともに広がる。** 新人の推定誤差(自分の推定−真値)は入団後1〜7日で −0.023、8〜14日で −0.053、15〜21日で −0.100(T031設定)。一方、新人の真の技能差(対カットオフ)は −0.027 → −0.019 → **+0.022** と逆転するのに、先発率は0.39前後のまま上がらない(0.386→0.385→0.402)。新人の成長に監督の推定が追いつかない。
4. **T032の失敗と整合する。** 試合評価推定だけを練習日の観察で更新しても、技能推定も同じだけ遅れていて、両方を真値に置き換えて初めて見逃し行の約72%が先発に反転する(片方だけなら38〜44%)。試合評価の項だけに手を入れても足りなかった。T032の「推定が正しくなるほど先発しない」仮説は、この分解では支持されない(見逃し行は推定が低すぎる側に偏っており、推定が正しくなれば先発は増える方向。ただしT032の機構は新人の推定をあまり動かさなかった)。
5. 疲労項は主因ではないが無視できない: 新人の疲労推定は事前値0.10から未更新に近く(0.13)、休んでいる控えの他者(0.065)より高く見える。疲労項を0にすると見逃し行の21〜24%が反転する(非先発の行全体では14〜15%)。

**次の一手の候補(実装ではない)**: 新人(控え)の推定が成長に追いつかない原因の分解。具体的には、窓内の新人ごとの観察回数(練習日の観察・偵察・試合)を数え、推定誤差の拡大が「観察の頻度不足」か「1回あたりの更新量(`coach_skill_alpha`)」かを切り分ける(分析のみ)。規則を足すのはその後。

## 限界・正直な注記

- **事後に追加した記述**: 1回目の実行(2026-11-10)は、新人単位の集計で新人ID(`p13`…)が世界間で衝突する実装の誤りがあり(新人単位の行が12人に集約された)、結果の全体の集計(行ごと)には影響しなかったが、その実行を破棄し修正して再実行した(ログ`run-log-first-pass-newcomer-id-collision.txt`)。1回目の結果を見たうえで、事前条件の**記述(合否外)**として、疲労推定の水準・新人自身の推定誤差・入団後の日数別(表4)を追加した。これらは探索的で、予測の判定には使っていない。
- 真の技能は試合日直後(その日の訓練後)の値で、選考時点とずれる(小さい)。試合評価は試合の加点を含み、真の技能と同じ尺度ではない(先発者の試合評価推定は技能より高く出るのが自然)ので、「試合評価推定の誤差」は技能推定ほど素直に読めない。
- 行は新人×試合日×クラブで、同じ新人の行は独立ではない。3seedも独立でない。分解は記述で因果の証明ではない。反実仮想は1項の差し替えで、選考を変えれば履歴が変わる(再シミュレーションではない)。
- ロスターは通常3人で、先発2枠の競争は新人と他の2人だけ。「カットオフ=他の2番目」はこの構造に依存する。
- 観察の頻度(窓内の新人ごとの観察回数)は今回計測していない。表4の推定の遅れが「観察頻度」か「更新量」かは切り分けていない(次の候補)。
