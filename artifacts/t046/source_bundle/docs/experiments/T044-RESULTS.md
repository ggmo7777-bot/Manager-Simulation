## 結論(平易に)

1. **U字の機構: 先発選びの誤差`err`は休養率の中間(72〜78%)で最大になり、先発一致はそのちょうど鏡像になる**(`corr(先発一致, err)` = −0.975(順方向)・−0.967(逆方向))。2つの枝(中間 → 低休養端36%、中間 → 高休養端90%)で`err`の減少を運ぶのは、どちらの方向でも**監督の推定の古さ(遅れ)**:
   - 低休養端−谷(`LO`): `err` −0.0380 [−0.0427, −0.0337](順方向)・−0.0332 [−0.0372, −0.0294](逆方向)のうち、古さ(`stale`)が −0.0404(106%)・−0.0333(100%)。定義の差(`def`)が −0.0156(41%)・−0.0128(39%)。観察雑音は +0.0014・−0.0003(−4%・1%)で**関与しない**。他の項(選び方`sel`など)は逆向き(+0.0166、−44%)で、減少の一部を打ち消す。登録の分類は両方向とも **`single(stale)`**。
   - 高休養端−谷(`HI`): `err` −0.0227(順方向)・−0.0149(逆方向)のうち、古さが −0.0285(125%)・−0.0210(141%)、定義の差が −0.0077(34%)・−0.0035(24%)、雑音は0。分類は両方向とも **`single(stale)`**。
   - 古さの中身は、初期印象の残り(`prior`、−11%・−6%。むしろ逆向き)ではなく**遅れ**(`lag`、118%・106%): 観察が来たあとに真の技能が動いた分。遅れ自体が休養率に対してU字(順方向: 90%で0.0308、78%で0.0628、36%で0.0181)。試合評価の推定の遅れが最大(順方向`LO`の遅れの減少 −0.0447のうち、試合評価の推定 −0.0307、技能の推定 −0.0140)。
2. **なぜ遅れがU字か(事後プローブ、探索的)**: 境界の2人(真の上位2人の弱い方と、それ以外で最もスコアの高い選手)の真の技能の直近14日の変化の差(`het_pair`)は、遅れの休養率の曲線と相関する(順方向0.84、逆方向0.89)。谷から両端へ向けて小さくなる(`LO` −0.0054 [−0.0059, −0.0048]・−0.0039、`HI` −0.0062・−0.0040)。休養率が中間だと「練習する選手」と「休む選手」が混ざり、2人の成長の差が最大になる、という説明と整合する。**ただし落差は小さい**(`het_pair`は0.0348 → 0.0290で約17%減。遅れは0.0628 → 0.0181で約71%減)ので、成長の差だけでは遅れの落差の大きさを説明しきれない(残りは未解明)。
3. **休養が少なすぎると損、という経路は、掃引の範囲(休養率36〜45%)では支持されなかった。** 膝(休養率およそ42〜45%)の下(`KN`)で、先発一致は下がらず、むしろ小さく上がる(順方向 +1.15pt [+0.32, +2.05]、逆方向 +1.20pt [+0.45, +1.96]。`helps`)。最終技能は変わらない(`flat`、両方向)。疲労の経路そのものは存在する: 疲労が1上がると試合評価の観察に入る出来の加点(平均0.06〜0.075)が下がる(傾き −0.03〜−0.125、20腕すべてで区間の上限<0)。ただしその効果は**先発選びの害でなく助け**になる: 先発だけが受ける加点(控えには来ない)が小さくなると、先発の試合評価の推定が真の技能より上に乗る分(定義の差)が小さくなり、控えが評価されやすくなる(`def`の寄与は休養率90%で+0.0035、78%で+0.0112、67%で+0.0068、45%で−0.0013、36%で−0.0044と減り、符号も変わる)。疲労は休養率45%以下で急増する(0.095 → 0.164)が、simの式では訓練の伸びは最大約9%減(`1−0.55×疲労`)、試合の走力は約3%減(`1−0.18×疲労`)にとどまり、168日・この範囲では先発一致・最終技能を損なわない。sim内の話で、現実の疲労の害や、168日を超える長期は測っていない。
4. **既定は変えない。** T042・T043の推奨も変更しない。本taskが出した証拠: (i) 先発一致のU字は、監督の推定の古さが休養率の中間で最大になることを映している(雑音ではない)、(ii) 休養率を下げて先発一致が上がる効果は、膝より下でも悪化しない、(iii) ただし疲労は急増し、個性に基づく休養の多様性(憲章1・2)と長期の疲労の害は未測定。**望ましい休養率の価値判断と、作者に既定の変更を提案するかは、あなたの決定**(下の要約)。

### 3. 疲労の経路(試合の観察ごと。1回の試合で先発2人が両クラブの監督から観察される)

- **傾き**(試合前疲労が1上がるとき、出来の加点の変化): 20腕すべてで区間の上限<0。順方向 −0.058〜−0.125、逆方向 −0.028〜−0.121。例: 順方向`base` −0.0908 [−0.0981, −0.0840]、δ+0.030 −0.0612 [−0.0702, −0.0520]。

## 限界・正直な注記

- 影の推定`A`・`I`・`Z`は、実際に起きた観察の列を保ったまま入力だけを置き換えた反事実の再構成で、置き換えた入力に応じて監督が別の判断をした世界ではない。項の分担は更新式を通した恒等式で、独立な効果の加法分解ではなく、因果の確定でもない。『遅れが主因』は「遅れの項が`err`の変化の100%を占める」という会計上の主張で、遅れを取り除けば先発一致のU字が消える、という介入の確認ではない(T045の候補)。
- 『定義』は出来の加点の系統的な平均と試合ごとの運を区別せず、『雑音』は平均と散らばりを区別しない(境界の2人の差を取るので共通の平均は打ち消される)。『遅れ』は、真の技能の動きを、観察が来る頻度(情報の古さ)とどの選手が観察されるか(先発の顔ぶれ)の両方を通して受けるので、「古さ」の原因が観察の頻度か選手間の成長の差かは分けていない(プローブは成長の差の寄与の一部を示したにとどまる)。
- 真の技能はT043と同じく、その日の終わりの値で、試合日の先発の試合経験の成長(約0.03×伸びしろ)が遅れの項に入る。端に張り付いた入力(約2.9%)は雑音の範囲検査から外した(推定の更新には正しく使っている)。
- 掃引δは期待利得への一様な加算で、個性や価値観の違いを表さず、simのconfigを変えた実験ではない。休養率は36%付近で飽和し、それより低い休養率は掃引の範囲外。『休養が少なすぎる』は36〜45%の範囲の判定。疲労の害は、simの式(訓練の伸び`1−0.55×疲労`、試合の能力`1−0.18×疲労`、`0.10×疲労`の疲労の項)では小さく、怪我の仕組みはsimに見当たらない。現実の疲労の害・168日を超える長期は測っていない。
- 休養率は各方向の腕の平均の実現値で、選手ごとの最適休養率を測らない。望ましさの基準の重みは決めていない。個性に基づく休養の多様性は測らない。
- 区間はセルの再標本で、世界は3seedを共有し独立でないため過小の可能性がある。単一の主指標(先発一致)。ロスターは3人。3設定は`coach_belief='none'`で、他の設定には一般化しない。設定によって主因が異なる(t032は定義の差が主になる場合がある)。
- 事後のプローブは、主結果を見た後に登録した探索で、判定表の予測とは分けた。コードは`experiments/t044_growth.py`(T044の水準を最大差0.0で再現)。実装中の動作確認で1世界・1腕のスモークの値を見た(PROTOCOLに開示)。
