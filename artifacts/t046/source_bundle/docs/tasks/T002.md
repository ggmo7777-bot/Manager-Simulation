# T002: 選手の経験効果と監督の配分効果を分ける

状態: **実装・検証完了**。2026-11-04に着手、11-05に主担当の確認を確定。[事前条件](../experiments/T002-PROTOCOL.md) / [結果](../experiments/T002-RESULTS.md) / [主担当確認](../experiments/T002-REVIEW.md)。T001成果物は凍結し変更していない。

## 問題と仮説

全B更新停止は選手の方法別予想利得だけでなく、監督の能力評価と最後の観察日の記憶も止める。そのため監督の提案数が変わり、技能gain差から選手の学習の寄与を読み取れない。

仮説: 監督の更新ルールを維持し、選手の方法別予想利得だけを凍結しても、経験による行動・成長への影響を測定できる。影響が小さい/ない場合も有効な結果。選手の行動が変われば監督の実際の配分も反応して変わりうるため、閉ループ比較はその反応を含む総効果とする。配分そのものを固定する比較は別の介入である。

## 範囲

1. Bの更新を「選手の方法期待」「自己能力推定」「監督の能力評価」「観察したという時点の記憶」に分ける。未使用の状態を増やす目的ではなく介入箇所を明確にする。
2. baseline、選手の方法期待のみ固定、監督の能力評価のみ固定（時点記憶は維持）、両方固定（時点維持）、旧全B停止を比較。
3. 同じ外生ノイズキー・同じ初期集団、探索seed0..29と確認seed100..129。介入後の監督の反応は総効果に含まれることを明記。必要なら記録した提案を再生する固定露出probeで直接効果を分ける。
4. 観測gainの負値を0へ切り詰める現方式と、符号付き誤差を保持する案を独立probeで比較。実成長0の条件で期待gainが正に偏るかを測る。世界へ採用するかは別判断。
5. ノイズ0・同条件の同点fixtureで候補順/ロスター順を反転し、恣意的な順序の優先がどこにあるかを記録する。解消が必要なら公平な決定論的tie規則の候補を比較する。

着手時の具体化: 上記5条件に、自己能力推定のみ固定する負の対照と、観察時点記憶のみ固定する条件を追加する。7条件×2セット×30seed、計420run。世界の成長式、Policy採点、同点規則、観測ノイズ、初期プロフィールは変更しない。偏り/tieの改善候補は独立probeに留める。

## 成功・失敗

成功: 別々の介入の変更箇所と不変箇所がテストでき、各個体の行動/成長/監督配分の結果を区別して報告できる。旧結果は旧コードで再現可能。保存/再開の完全一致は維持。

失敗: 学習を凍結するために未観測の真値を与える、観察費用を無くす、良い結果になるよう初期値を調整する、複数要因の差を個別の因果効果と呼ぶ。
