# プロジェクト憲章 v0.1

作成日: 2026-11-04（日本時間）。ユーザー要求に基づく原則。実装方法と係数は変更可能な研究仮説。

## 目的

独立した選手・監督の経験、選択、学習、人間関係、競争、世代交代から、再現可能で理由を追跡できるサッカー界の歴史を生む。競技能力の最大化は従属目標であり、失敗・誤解・才能の浪費も排除しない。

## 優先順位

1. 個体の独立判断と長期的な人生・キャリアの分岐。
2. 経験・学習・育成による、理由を追跡できる変化。
3. 知識差、価値観、信頼、利害。
4. 戦術、育成、競争、経済の相互作用。
5. 世代交代による世界の自律的変化。
6. 妥当性、継続性、検証可能性、効率。
7. 競技能力。
8. ビジュアル。

## 必須原則

- 世界の真の状態、個体の認識、判断の内部表現、表示用評価を区別する。
- 行動には時間・資源の機会費用がある。監督の指示は選手への入力であり直接操作ではない。
- 個体差は潜在特性・経験・状態・選択によって行動と成長に影響する。乱数や個体IDだけで代用しない。
- A: 身体・技能の状態更新、B: 知識・記憶・信念の更新、C: Policyや重みの学習を別々に記述・測定する。
- 神経回路の一時活性を無条件に永続的個性としない。再帰モデルの実行状態を保存する場合は目的とリセット条件を明示する。
- 脚本による移籍・覚醒・対立・黄金期の発生保証を作らない。例示された物語は受入テストの固定イベント列にしない。
- 事実、観測、本人の理由、研究者による因果推定、LLMによる文章化を分ける。
- Seed、乱数方式・状態、実験条件、ルール・モデル・保存形式・ソースの版を記録する。
- 小さく実装し、仮説 → 実装 → 比較実験 → 分析 → 維持/修正を繰り返す。否定的な結果も残す。
- モデルを交換しやすくするために、誤りうる仮説の境界を分ける。使う根拠のない汎用フレームワークは先に作らない。
- 最上位目的を変える判断はユーザーに確認する。原則を保つ局所的な実装改善は根拠を残して進められる。

## 避ける方向

全員に同じ正解を与える中央制御、真の潜在能力の無条件共有、全員を同じ最強Policyへ同期、勝率だけの評価、語りの魅力を事実とみなす評価、長期履歴を持たない使い捨てデモ、早期の3D・巨大経済・大規模RL。

## 今回の承認済み範囲

ユーザーの追加回答により、設計だけでなく **最小実装と検証まで** 含む。初期環境は手元のMac、CPU中心、外部課金なし。Sol 6.1 Highを実装担当とする。今回実装するT001は育成・認識・選択・保存の基盤であり、サッカーの試合・移籍・数シーズンのキャリアの完成を意味しない。
