## 機構と保存

私的な朝夕の技能信号の差を `y` とし、標的を丸め方式では `max(0, y)`、符号付き方式では `y` とした。両方式とも学習率0.5でGを更新する。信頼評価は従来どおり符号付きの観測差と行動前の予測を使う。技能と潜在率の範囲、Policyの得点式、監督予測、ノイズ、同点処理、プロフィールは同じ。研究ログの `player_gain_belief` は観測差、選んだ標的、更新前後のG、朝夕観測と行動の根拠を残す。4条件すべてでGを更新するので、練習1回につき1件の予測評価を記録した。

| 検査 | 結果 |
|---|---|
| H1 同じ観測列 | 正の差と0では両方式が一致。負の差を繰り返すと丸め方式は0、符号保持は負のGへ収束した。 |
| H2 次の選択 | Aに同じ負の観測差−0.10を経験すると、AのGは0.05から0.025または−0.025へ更新された。同じ次の観測で丸め方式はA、符号保持はBを選んだ。 |
| H3 信頼の順序 | 負の事前Gを持つ実施例でも、信頼評価が当日のG更新に先行し、前回のGを参照した。 |

| H6 旧方式 | 主担当が凍結T003の固定/適応信頼、60seed、28/84日で計240本を照合し、最終数値・全候補得点・選択・信頼と真値の推移が一致した。 |

## 信頼と助言を実施した機会

確認セットの各行は1本当たり平均。二乗誤差は採用して実施した助言のみで、経験があるrun内の平均をさらにrun間で平均した。実施なしのrunはこの誤差集計から除外した。固定信頼条件も予測の比較を記録し、信頼の増減は0。

| --- | --- | --- | --- | --- | --- | --- |
| clipped_fixed | p1 | 0.750 | 74.93 / 57.93 | 0.00 / 0.00 | 0.000550 / 0.000930 | 0/30 |

適応信頼では、符号保持でp1の信頼終値が0.381から0.499へ上がった（対応差 +0.11777 [0.07874, 0.15687]）。p1の実施は50.80から42.77件/runに減り、p2は1.27から3.10件/runに増えた。全体の助言採用率は適応信頼で−5.49ポイント [−8.88, −2.36]、固定信頼で−2.21ポイント [−4.54, +0.18]。p1は適応・符号付きで全練習の自己予測の二乗誤差が増えた一方、採用した助言内では監督の二乗誤差が引き続き自己より大きい。信頼終値には相対誤差の列と実施機会の両方が関わる。

p2の採用助言に限定した符号保持−丸めの誤差差は、確認セットの固定・適応とも対応22本で推定した。実施の有無で対象seedが変わるため、全練習の30本と分けて読む。拒否された助言の結果は観測されない。

## 追加対照

- **ノイズ0。** seed17・84日で自己技能、疲労、監督観察の振幅を0にした。固定・適応のそれぞれで、方式名のフィールドだけを除いたsnapshot全体が一致した。選手・監督の不一致はともに0。Aの非負成長を観測がそのまま捉える場合に標的が一致することを確認した。
- **真の成長0、同じ観測列。** 真の技能0.5、振幅0.025、初期G0、学習率0.5、1000seed×64回。終値平均は丸め方式0.008640、符号保持0.000342。終値の経験分布の中央95%は丸め方式 [0.000212, 0.025406]、符号保持 [−0.023422, 0.022879]。標準偏差は0.006839と0.011947。観測が同じでも丸め方式はGを上へずらし、符号保持は負側も含むため終値の分布が広がった。

## 実行と費用

```sh
python3 -m unittest discover -s tests -v
python3 -m soccer_sim experiment --suite t004 --out artifacts/t004/experiments
python3 -m soccer_sim run --condition signed_adaptive --seed 17 --days 84 --out artifacts/t004/representative/full
python3 -m soccer_sim run --condition signed_adaptive --seed 17 --days 42 --out artifacts/t004/representative/first_half
```
