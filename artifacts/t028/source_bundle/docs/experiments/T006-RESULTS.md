## 実装と仮説の判定

`PolicyRules.coach_method_mode`に`legacy`/`forecast_rank`を追加した。監督が持つ事前のA/B予測が異なる場合、予測の大きい方法に対象の旧最大方法得点を割り当て、他方法を0にする。同点なら旧式を使う。各対象の最大提案得点を保持し、同じ認識なら観察/提案/休息の優先度を直接変えない。学習・観察費用・選手の採点は維持した。

| 仮説/契約 | 実測・判定 |
|---|---|
| 主観予測が方法を変える | 支持。固定状態で順位の反転に応じて選定が変わり、同順位の差の大きさには不変。同点/負値/s=0.5/w=0/微小差を検査 |
| 学習と利用を分ける | 支持。同じ私的な観測経験の学習ON/OFFで方法選定が分岐。主比較のfrozen同士は全60組で行動・選手終値・監督学習記録が一致 |
| 同じ認識の時間配分 | 支持。rank条件の全20,160判断で同時点の旧式と行動種別/対象が一致。後日の経験変化を含む配分は別に変化した |
| 真値の非漏洩・独立選手 | 契約を確認。監督入力を固定して真の率/上限/選手Gを変えても判断不変。選手は同じ提案を受けて採用/拒否を独立に選ぶ |
| 原因の記録 | 支持。選択前の両方法予測と根拠、候補得点を保存。代表168判断/608提案候補をPolicy関数を呼ばず再計算し一致 |
| 旧動作と継続 | 支持。T005の4条件240本と版/新設定を除くsnapshot全体が一致。主4条件84日vs42+42日がsnapshot/JSONL一致。旧196ファイル不変 |
| 普遍的な精度/育成力 | 判定不能。この比較は固定2プロフィールの選択と経験の総効果であり、現実の指導力や他集団へ一般化しない |

実装担当71テスト（6.119秒）、主担当も71テスト合格（6.204秒）。[独立検証](../../artifacts/t006/review/verification.json) / [判断監査](../../artifacts/t006/review/choice-audit.json)

## 主比較の結果

全条件で前後観察ON、適応信頼ON、自己Gはsigned。他B更新と初期プロフィールは共通。`frozen`/`learning`は監督の予測更新、`legacy`/`rank`は方法選択への利用。各行30run、技能gainは2選手の平均。助言採用は各行合計、提案数は3,390件。

| セット | 条件 | 休息割合 | 助言採用数 | 平均技能gain |
|---|---|---:|---:|---:|
| 探索 | frozen_legacy | 35.77% | 1,380 | 0.495106 |
| 探索 | frozen_rank | 35.77% | 1,380 | 0.495106 |
| 探索 | learning_legacy | 37.06% | 1,273 | 0.496381 |
| 探索 | learning_rank | 38.37% | 1,232 | 0.502533 |
| 確認 | frozen_legacy | 37.52% | 1,376 | 0.494327 |
| 確認 | frozen_rank | 37.52% | 1,376 | 0.494327 |
| 確認 | learning_legacy | 39.78% | 1,255 | 0.494529 |
| 確認 | learning_rank | 38.85% | 1,243 | 0.500572 |

frozenではA/Bの事前率が等しく補正0のままなので、予測同点のfallbackが毎回働く。この負の対照は設計上予想されたもので、利用という設定がどの知識でも無意味だという結果ではない。

確認セットのlearning内でrank−legacyを比較する。対応seed単位bootstrap 2,000回、解析seed6006、95% percentile区間。

| 指標 | 対応差 [95%区間] |
|---|---:|
| 平均技能gain | +0.006043 [0.004043, 0.008105] |
| p1の信頼終値 | +0.06519 [−0.01877, 0.14774] |
| p2の信頼終値 | −0.00472 [−0.02309, 0.01476] |
| 助言採用率 | −0.35pt [−4.31, 3.69] |

探索のgain差は+0.006152 [0.004307, 0.007923]。frozen同士が同じため、gainの交互作用もlearning内の利用効果と同じ値になる。これは独立した2つの発見ではない。

確認セットの行動不一致はp1 50.04%、p2 35.24%、選手平均42.64% [39.44,45.95]。監督全体43.77%で、成分は行動種別8.10%、対象15.46%、方法36.61%。成分は重複し、足して全体にはならない。固定状態では優先度を保っても、方法が変わると選手の経験・技能評価が変わり、後の配分に影響する。

## 機会と限界

全240runで監督の配分合計は観察55・提案113・休息0枠だった。順序と対象/方法は異なる。確認learning_rankの1run平均は、順位を使う提案106.83、同点fallback 6.17、同時点の旧式と方法が異なる提案51.60。

**両予測が負の提案も平均27.97回あった。** この方式は方法の相対順位だけを使い、予測gainの大きさで提案自体の価値を下げない。そのため「悪いと思う2方法のうち、少しましと思う方法を勧める」行動も生じる。結果を良くするために今回の途中で休息や探索の規則を足していない。

| 確認learning_rank・1run平均 | p1 A | p1 B | p2 A | p2 B |
|---|---:|---:|---:|---:|
| 提案数 | 37.33 | 34.90 | 18.47 | 22.30 |
| 実施された助言 | 19.83 | 18.87 | 0.97 | 1.77 |
| 観察した練習/更新数 | 7.77 | 8.90 | 8.70 | 6.70 |

p2は提案されても実施する機会が少なく、監督が観察した自主練習とは異なる標本になる。確認セットでは全条件・全個体×方法に少なくとも1回の練習観察があったが、助言の実施がないrunは存在する。精度の欠損を0として埋めない。

## 精度と信頼を成長量から分ける

確認30runの平均。監督MSEは「自分が観察した練習」の私的観測差、選手側MSEは「採用して実施した助言」の本人の私的観測差を標的とする。

| 条件 | p1 / p2 信頼終値 | 監督観測MSE p1 / p2 | 選手側助言MSE p1 / p2 |
|---|---:|---:|---:|
| frozen_legacy / frozen_rank | 0.499 / 0.287 | 0.003399 / 0.003169 | 0.000916 / 0.000591 |
| learning_legacy | 0.325 / 0.257 | 0.004109 / 0.003962 | 0.001451 / 0.001057 |
| learning_rank | 0.390 / 0.252 | 0.004192 / 0.003816 | 0.001177 / 0.001357 |

learning内のrank利用による監督MSE差はp1 +0.000083、p2 −0.000146で、両区間とも0を含む。選手側はp1 −0.000274 [−0.000482, −0.000060]、p2 +0.000358 [−0.000104, 0.000882]（比較可能25組）。p2の対応差は同じ25組だけから計算するため、上表の各条件の平均同士の単純差とは一致しない。

成長量の増加があっても、信頼や予測精度の改善は一貫していない。経験した方法や採用した助言の分布も変わるため、同じ予測課題に対する能力の差と説明しない。

## 独立対照（各seed17の1例）

| 対照 | learning内のlegacy→rank 平均gain | 選手の行動不一致 |
|---|---:|---:|
| 信頼固定 | 0.496221→0.505446 | 52.38% |
| ノイズ0 | 0.484845→0.508643 | 73.21% |
| clipped G | 0.487999→0.508623 | 59.52% |

信頼固定でも方法選択への利用が行動に作用した。T005の「予測→信頼」だけとは異なる経路である。ノイズ0でも作用が残り、今回の分岐は乱数だけではない。一方、ノイズ0のp1助言MSEは0.000079→0.000123、信頼0.681→0.670で、ここでも成長の増加と同義ではない。全対照でfrozen同士の行動/真値履歴は一致。各1例を主比較の効果量へ混ぜない。

## 履歴から追える例

代表seed17のp1。3日目の監督経験77では、Aの前後観測差−0.026393を受け、補正が0→−0.047196になった。4日目の判断88はこの記憶と未学習Bの事前記憶を比較し、qA=0.010983、qB=0.058179からBを提案89として選んだ。同じ時点の旧方法式ならAを選ぶ。

選手の判断90は自分の予測・好み・疲労・信頼からBを採用し、行動92と状態更新94へつながった。実際のgainは+0.006632。選手は直接操作されていない。同時点の旧式との比較は方法選定の説明であり、別の世界の最終キャリアを推定したものではない。[根拠一式](../../artifacts/t006/review/causal-trace.json)
