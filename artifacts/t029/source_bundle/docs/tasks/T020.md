# T020 — 初期分布の範囲の感度掃引と校正目標の定義

2026-11-10、実装前登録。状態: 完了(2026-11-10、成功条件3は16/19セルの部分充足)。[結果](../experiments/T020-RESULTS.md)。条件1・2・4を満たし、条件3は事前登録の範囲検査で3摂動(cap_w15, psych_w15, cap_cp)が拒否され未実行のため部分的。H1は実行分で支持、H2は点推定で支持、H3は判定不能。[事前条件](../experiments/T020-PROTOCOL.md)。担当: Claude Sonnet 5.5。着手は継続指示に基づく。T015で初期範囲は「仮説で現実の選手分布の校正ではない」、T019で「範囲は校正していない」と記録済み。

## 「校正」の範囲(最初に決めること)

校正は「外部の基準に範囲を合わせる」操作である。本プロジェクトには実世界データ源がなく、RESEARCH.mdも「現実選手データでの校正は行っていない」と明記する。基準なしに範囲を動かすと、望む結果に向けた調整(CHARTERの禁止方向)になる。よってT020は範囲を変更せず、次の2つだけを行う。

1. 校正目標の定義: 各範囲パラメータについて「何に照らして校正するか」を、実データ不要の内部基準(構造的妥当性)と、実データが要る外部基準(未充足)に分けて表にする。外部基準の充足は本taskの対象外で、データ源の選択はユーザー判断(未決)。
2. 感度掃引: 各範囲群を1つずつ動かし、育成還元効果(T016の初期育成6名指標)と初期集団の記述統計がどれだけ動くかを測る。どの範囲が結論に効き、どれが効かないかを知れば、将来の校正で優先すべき範囲が分かる。

## 仮説(確認前に固定、反証され得る)

- H1 還元効果の符号は、すべての単独摂動(18種)でbaseline sampledと同じ(正)に保たれる。
- H2 最も効く範囲群は成長率(rate)の中心・幅である(T019でF1の寄与が大きかった入力のうち、成長率が直接の成長項であるため)。
- H3 初期印象の誤差幅(±0.06)を0〜±0.09で動かした変化は、T019のF2対比(−0.003551)より小さい。

## 最小実装(承認後)

`LeagueEconomyConfig`に範囲摂動の名前付き文字列フィールド(既定は摂動なし=現行と同じ値、既定ではconfigキーを出さない)を1つ追加し、`_sample_profiles`/`_sample_impressions`が名前から範囲を引く。摂動の定義は表(コード内の固定辞書)に置き、実行時の任意数値は受けない。条件名接尾辞を追加する。進行・Policy・観測・移籍・通貨・評価・保存schemaは変更しない。既定14条件のworldとT019の8セルは不変。

## 成功条件と失敗条件

1. 回帰: 摂動なしの既定条件(14条件、seed100、35日)がT019/T018とsnapshot/events/summaryまで一致。摂動名を明示した「null摂動」はbaseline sampledとバイト一致。
2. 妥当性: 全摂動後の範囲が下限<上限、値域[0.05,0.95]、cap≥max(trait)+0.05の生成規則を維持し、preflightで範囲違反を拒否する。
3. 報告: 19セル(baseline+18摂動)×3制度×seed30の対応差を、平均差・探索的区間・正負ゼロ数・非空世界数で報告。摂動ごとのbaselineとの差を並べる。単一の「感度得点」や順位付けの総合点にはしない。
4. 校正目標表を完成させ、各行に「内部基準で検査可/外部データ要」を記す。外部データ要の行を無理に埋めない。
5. 失敗条件: 既定worldが変わる、null摂動が一致しない、範囲違反を拒否しない、全unittest/高速ゲート失敗、凍結成果物の変更。効果の大小・符号はH1〜H3の判定に使うが採否の条件にしない。

## 対象外・戻し方

範囲の変更(既定の更新を含む)、実データによる校正、新しい要因、世代交代、C、1000日、評価器の変更、多摂動の同時掃引は対象外。掃引の結果を見て範囲やseedを選び直さない。校正そのもの(範囲の更新)はユーザーが実データ源を選んだ後の別task(T021候補)として事前登録する。新成果物は`artifacts/t020/`のみ。戻し方: 摂動フィールドの既定で現行と同じworld。`league_economy.py`が指紋対象なのでsource hashは変わり、T019以前のsaveは旧ソースで読む。
