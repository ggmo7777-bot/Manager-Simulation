# T016 — 初期育成集団の比較と残留者の記述統計を分離

2026-11-08、実装前登録。状態: 実装・検証完了（最終確認2026-11-09）。ユーザーの「進めてください」に基づく最小修正。設計/独立分析Codex、実装Sol 6.1 High。

## 問題と範囲

T015の`academy_retained_skill_gain`はp1,p2,p7,p8の固定4名。sampledの市場開放条件それぞれ30本中27本で移籍済み選手を含む。固定4名の数値を実際の残留者の効果と呼べない。[現状確認](../reviews/2026-11-08-T015-STATUS-REVIEW.md)。

変更は研究者向けsummaryと評価・分析だけ。生成分布、Policy、観測、A/B更新、試合、会計、保存状態のschemaは変更しない。通常CLIへのsampled接続や世代交代などは別タスク。

## 評価契約

- 主比較: 初期状態で育成クラブに属した全選手（現モデルでは6名）。`initial_players`の初期所属からIDを求め、移籍後も追跡。条件間で同一seed/集団/IDを対応付ける。各世界の平均成長の対応差をseed30個で評価する。
- 記述統計: 初期育成選手のうち、その時点まで移籍回数0で初期クラブにいる者。`never_transferred`と明記する。現在所属だけでは帰還者を区別できないため、将来帰還した者も除外。条件ごとにID・人数・平均を保存し、条件間の差をその集団への因果効果と呼ばない。
- 空集団の平均は`null`、人数0、ID空。0成長として代入しない。集計時は非空世界数と対象人数を必ず表示する。
- 旧固定4名の数値は`legacy_four_slot_skill_gain`/`legacy_four_slot_ids`に改名して診断用に残す。誤解を招く旧キー`academy_retained_skill_gain`は現行summaryから削除する。旧結果は変えない。既存`talents_*`も旧スロット指標であり、新集団の才能や評価対象を定義しない。
- 新キー: `evaluation_version=t016-initial-cohort-v1`、`academy_initial_cohort_ids/count/skill_gain`、`academy_never_transferred_ids/count/skill_gain`、上記legacy。成長は従来どおり各選手のcomposite skill差を6桁丸め、集団平均を6桁丸める。
- save16/rules/Policyを維持し、評価版をsummaryへ明示。source hashは変わるため旧snapshotを新readerで読めるとは扱わない。旧T015は`artifacts/t015/reference_before_t016/source_bundle`に保管済み（採用判断とは別）。

## 完了条件

1. 移籍者/残留者/帰還者/外部からの加入/空集団/ID付替え/非破壊を検査。初期集団はIDの固定リストから選ばない。
2. 旧summaryの該当キーを参照する現行テスト・実験を更新。旧プロトコルは明示的に拒否するか旧版を使う案内を出し、同名で新意味へ黙って置換しない。
3. fixed/sampled×3制度×seed100..129×84日の180本を旧T015と比較。identity以外の全状態/全履歴が一致し、旧8集計はlegacyの明示換算後に保存済み値と一致する。
4. 初期/最終状態と移籍履歴から別実装でメンバー/人数/成長を照合。初期6名の主比較を報告し、残留者は記述統計とする。既存の会計監査も通す。
5. 代表4条件の42+42日再開とsampledの記録付き認識分岐を確認。全unittest、適切な高速ゲート、旧成果物inventoryを検証。
6. 事前条件・結果・限界・変更理由・戻し方を記録し、別run/manifest/ソースを保存。

数値の符号や効果量を成功条件にしない。負・ゼロの結果も保持する。

結果: [T016-RESULTS](../experiments/T016-RESULTS.md)。190テスト、180世界の全状態/履歴一致、初期集団/移籍なし集団の独立照合、4代表と分岐の保存再開、旧1,702ファイル保全を確認。
