# EXP-T003 事前実験計画

登録: 2026-11-05、実装前。T003の信頼は、選手が受け取った予測の相対的な信頼性に限定する。T002の固定信頼が対照。

## 条件と実験単位

| 条件 | 方法期待G | 信頼更新 | 目的 |
|---|---|---|---|
| fixed_trust | ON | OFF | T002標準の維持 |
| adaptive_trust | ON | ON | 信頼の経験更新の総効果 |
| fixed_trust_gain_frozen | OFF | OFF | G停止の対照 |
| adaptive_trust_gain_frozen | OFF | ON | 信頼と方法学習の相互作用 |

自己推定、監督評価、観察時点は全条件で更新する。Aの式、観測、初期プロフィール、行動得点、Gの切り詰め、同点規則、監督予測の事前信念は条件間で固定。

- 主比較は84日、探索seed0..29・確認seed100..129、4条件×60seed = 240run。セット間で係数を調整しない。
- 比較単位は対応seed。固定2プロフィールにおける観測ノイズの違いだけで、集団への一般化ではない。
- 予測は新しく追加するが、固定信頼条件では行動得点に新しい予測値を入れない。旧T002の28日baseline/G停止と数値・選択を照合する。
- 追加の相互作用は `adaptive_gain_frozen - fixed_gain_frozen - adaptive + fixed`。複数の更新を「学習」と一括りにしない。
- 主指標: 個人別の信頼軌跡/終値/更新回数/上昇と低下、助言採用率、行動の不一致、方法割合、gain、監督の配分、私的観測に対する自己/監督予測誤差。技能gainの最大化を合格条件にしない。
- 平均対応差とseed単位bootstrap 2,000回の95% percentile区間（解析seed3003）を記録する。少数の物語向きの例だけで合否を決めない。

## 機構と境界のテスト

| ID | 検査 | 成功条件 |
|---|---|---|
| H1 相対誤差 | 同じ信号で監督予測が自己予測より近い/遠いfixture | それぞれ信頼増/減、同じ予測では全く変わらない |
| H2 実施経験のみ | 拒否・助言なし・休息 | 信頼は不変。未実施練習の結果を使わない |
| H3 事前予測 | G更新のある日とG停止の日を使い、参照を検査 | 当日の学習後のGではなく行動前のGが記録/計算される |
| H4 情報境界 | 真のrate/capを変え、同じ主観入力を与える | その時点の監督予測と信頼更新は同じ。将来の観測差から変化してよい |
| H5 信頼の作用 | 実際の正負フィードバックで信頼を変えた後、同じ次の観測を提示 | 境界fixtureで次の採用/拒否が変わる。単に初期信頼を変えたテストだけでは済ませない |
| H6 無効対照 | 信頼更新OFFでT002版と比較 | 数値/行動/採点一致。新しい予測・event IDは比較対象外 |
| H7 継続と履歴 | 4条件の84日連続vs42+42、1000日、旧artifact検査 | 新snapshot/event一致、状態/予算/参照整合、旧T001/T002成果物不変、版不一致拒否 |

合格は独立した更新経路と説明/保存の成立。主比較で行動差が小さい場合はそのまま報告し、差を出すために係数を調整しない。主比較で改善しても一般的に良い監督/より人間的な信頼が完成したとは言わない。

## 解釈の限界

- 行動が変われば監督の反応や将来の経験も変わる。主比較はこれらを含む総効果。
- 助言を実施した事例だけで評価するため選択バイアスがある。拒否した方法の潜在的な有効性は分からない。
- 相対予測精度は、その方法の選択が最善だったことを意味しない。低い成長を正しく予測しても、他方法より有用とは限らない。
- 監督予測は固定の主観的な率と本人の能力評価から作り、疲労/個人適性/真の上限を無視する。不十分な知識として明示する。
- Gの切り詰めの偏りが比較相手の自己予測に残る。信頼更新の観測差には切り詰めを使わないが、この影響まで除いた実験ではない。

結果は `T003-RESULTS.md`、全条件/個体/seedは `artifacts/t003/experiments/`。run/resumeの代表例と凍結ソースを保存する。次の実装は結果分析と設計判断の後に定める。
