# T034 結果 — 新人の推定の遅れは観察の頻度か更新量か(分析のみ、simは不変)

実施: 2026-11-10〜11。契約: [T034](../tasks/T034.md)、事前条件: [PROTOCOL](T034-PROTOCOL.md)、判断: [D049](../DECISIONS.md)。方法・定義・予測は実装前にコミットし、結果後に変えていない。Python 3.13.3(uv)。**規則・config・イベント・乱数の追加はなく、`soccer_sim/`はT032/T033と1バイトも違わない。** T033と同じ3設定(T030/T031/T032)×84セル、新人は各1,008人(完全な1年度)、行は9,070(T033と同数・同じ先発行・同じ見逃し行)。`artifacts/t034/run/{summary,rows,newcomers}.json`。

## 結論(平易に)

1. **遅れの主因は「新人の推定が事前値0.5からほとんど動かない」こと(観察の頻度、特に最初の観察)で、1回あたりの更新量ではない。** 入団後15〜21日の技能推定の誤差(−0.099〜−0.103)の内訳は、事前値の残りが66〜87%(−0.066〜−0.090)、真の成長への遅れが12〜26%、観察値のずれが2〜8%。最初の選考(入団後7日)では、T030で行の65%、T031/T032で33%が、新人についての観察が一つもない。
2. **新人は少ししか見られない。** 窓(3週間)内の自クラブの監督の観察は、新人1.3回(T030)/2.0回(T031)/2.0回(T032)に対し、新人以外は2.9/3.2/3.1回。差は試合の観察(新人1.1回 対 新人以外2.8回)で、試合の観察は先発したときだけ生じる。窓内に一度も先発しなかった新人(359/363/384人)は、T030で観察が**ゼロ**(新人全体の35.6%)、T031/T032でも1.0回(練習日だけ)。先発しない→見られない→推定が上がらない→先発しない、の閉じた輪になっている。(窓内に先発した新人は2.2〜2.6回。)
3. **ただし「少し増やす」だけでは効かない。** 同じ名目の追加量(技能側の更新率の合計+1.08)で比べると、毎週1回の練習日観察を足す(F+)は15〜21日区間で遅れの5%しか縮めず、最初の2週間はむしろ悪化させる(−67%、−14%)。更新率を約3倍にする(U+)は遅れの19〜20%を縮める。毎日観察する(F-max、新人あたり約20回)でも54〜56%、更新率を1にしても28〜33%にとどまる。
4. **先発への効き(新人だけの再順位)も小さい。** 見逃し行(463〜543行)で反転するのは、F+が4〜9%、U+が8〜15%、F-maxが26〜32%。観察が足りないことは遅れの最大の部分だが、数回の追加では先発は変わらない。
5. **途中で見つかった事実(未確認の記述)**: simの観察雑音は`(uniform_from_key(…)−0.5)×2×noise`で、`uniform_from_key`の既定範囲が[−1,+1]のため、雑音は[−3,+1]×noiseに分布し平均が−noise(練習日では約−0.024)になる(テストで範囲を確認)。観察はすべて平均で低めに出る。F-maxでも遅れが約半分残る(−0.046)理由の一部と推測されるが、本分析では雑音を中心化した反実仮想を行っておらず、**検証していない**。設計か不具合かの判断は別task。

**次の一手の候補(実装ではない)**: 「初見の観察」規則 — 監督のB層だけを見て、選手の評価が入団(または移籍)後に一度も観察で更新されていない間、その選手の練習日観察の候補に固定の加点を与え、最初の数回(3回まで)が1年度の最初の試合日前に入るようにする。比較はT031と同じ形(既定"none"対有効、84セル)。着手の前に、観察雑音の中心のずれ(上の5.)が推定の遅れに占める大きさを分析(記述のみ)で確かめる。

## 限界・正直な注記

- **事後に追加した記述・修正**: (a)1回目の全実行(2026-11-10)は、新人以外の在籍選手がいないクラブで比較の平均がNoneになり、全84セル×1設定(T030)のゲート2・3を通過した後の集計で停止した(ログ`run-log-first-pass-no-incumbent-crash.txt`)。比較から外すだけの修正で再実行した(方法・定義は不変)。(b)2回目の実行の後、結果を見て記述`share_zero_obs`・`share_3plus_obs`と`newcomers.json`の保存を追加して3回目に再実行し、集計値は2回目と同一(追加項目を除き一致を確認し、2回目の出力は削除)。これらは探索的で、予測の判定には使っていない。(c)実装後・全実行前に、1セルの短い実行(84日)で値を確認したが、方法・予測・閾値は変えていない。
- 反実仮想は新人自身の推定だけを入れ替える。観察を増やせば監督の2枠のうち他の選手の観察が減るはずだが、それは含まない。追加観察の値はsimの式どおりだが、その日の終わりの真の技能を使う(練習直後との差は試合の経験成長ぶん)。F+は最初の週の観察でむしろ推定を下げる(真の技能が事前値0.5を下回る日と、雑音の平均が−noiseであることが原因と推測。未検証)。
- 「F+とU+は同じ名目の更新量」は技能側のΣαで揃えた定義で、試合評価推定側や効果の同一性は保証しない。F+は3回に固定、F-maxは約20回で、用量の応答曲線は測っていない。
- 窓内に先発しない新人の観察が少ないのは結果で絡んでいる(試合の観察は先発のとき)。先発の因果ではなく、閉じた輪の記述。行は新人×試合日で独立でなく、3seedも独立でない。ロスターは通常3人で、新人以外はいつも1〜2人。
- 観察雑音の中心のずれ(結論5.)は計算上の事実(式とテストの範囲)で、効果の大きさは未測定。
