# T035 事前実験条件

2026-11-11、実装前登録(結果を見る前)。契約: [T035](../tasks/T035.md)。結果を見て方法・定義・閾値・予測を変えない。外れた予測は結果として記録する。**分析のみ**で世界は変えず、研究者だけが真の技能を使う。

## 固定する条件

Python 3.13.3(uv)。T034と同じ84セル(14世界×seed{100,101,102}×開始年齢{29,33}、168日、`season_length_days=21`)を3設定(T030/T031/T032の有効設定。`t033.SETTINGS`)で再実行。1日ずつ進め、各日の後に(世界の状態は読むだけ)そのイベントを記録順に処理する。観察の雑音の幅Nは各世界の`world.config`の`coach_noise`(練習日)・`scout_noise`(偵察)・`match_obs_noise`(試合)。

## 方法

1. **コード監査(静的)**: `soccer_sim/*.py`をASTで走査し、`uniform_from_key`の全呼び出しを列挙する。`low`/`high`を明示せず既定の[−1,1]のままのものと、`(…−0.5)×2×幅`または`(2×…−1)×幅`の形で包まれているものを区別して記録し、`low=−幅, high=幅`と明示する旧モジュール(selection_loop・transfer_loop)と対比する。設計意図の証拠として`docs/DESIGN.md`・`docs/DECISIONS.md`・`docs/OPEN-QUESTIONS.md`・コードコメントの「雑音」「偏り」「bias」の記述、および`git log -S`での導入コミットを記録する。
2. **実現した中心(記録から)**: 記録された`coach_session_observation`・`coach_scout_observation`・`coach_match_observation`の全イベントについて、simと同じキー(seed, 日, "coach_obs"|"scout_obs"|"match_obs", `f"{監督}:{選手}"`)から実現した雑音 ν=(u−0.5)×2×N を再計算し、種類別に ν/N の平均・標準偏差・clamp(下限0.10/0.15・上限0.98)に当たった割合を報告する。**キーの検証**: 練習日(と偵察)で、clampされていない観察について `obs_skill−ν` がその日の終わりの真のcomposite skillと|差|≤2e-6で一致する割合を報告し、練習日の不一致は0件を要する。中心化した版の雑音 ν'=u×N(u∈[−1,1]は同じ引き、つまり[−N,N]の対称一様)との差は ν'−ν=N(1−u)で、平均はN。
3. **推定への伝播(線形、全選手)**: 同じ(監督, 選手)ごとに、世界の開始から、観察イベントを記録順に処理し、推定のずれ d_s・d_m(中心化した世界の推定−実際の推定)を `d←(1−a)d+a(ṽ−v)` で更新する(a=その観察の更新率。`t034.alphas`と同じ表。ṽ=`round6(clamp(v−ν+ν', 下限, 0.98))`、vは記録された観察値)。更新は線形でclampと丸めの非線形は無視する(新人については`t034.replay`で中心化した観察値から再生した推定と|差|≤2e-4を検査する)。`lineup_decision`ごとに、順位表の全選手(技能推定=`skill_term/w_skill`、試合評価推定=`match_term/w_match`)について、推定誤差 e=推定−その日の終わりの真のcomposite skill と d を記録する。
4. **誤差の説明量**: 行を**新人行**(T034と同じ窓=入団翌日〜+21日の新人)と**新人以外の行**(同じ`lineup_decision`で順位表に載る、そのセルで`season_youth_joined`した選手でない選手)に分け、それぞれで: 平均誤差 ē、ずれの平均 d̄、**説明率 d̄/(−ē)**、MAE(平均|e|)と中心化後MAE(|e+d|)、RMSE。新人行は窓の3区間(1〜7、8〜14、15〜21日)別にも。**差**: 新人と新人以外の平均誤差の差 Δ=ē_新人−ē_新人以外 のうちずれで説明される割合 (d̄_新人−d̄_新人以外)/(−Δ)(Δが負のとき)。
5. **先発への効き(オフライン、記録した他の項は固定)**: 各`lineup_decision`で、全選手の技能項・試合評価項に d の分(`w×d`)を足して得点を再計算し、Top2(同点は選手id)が記録と変わる割合、および新人行の先発割合の変化(T033と同じ規則)を報告する。
6. 補助(記述): 世界別・設定別・開始年齢別の中心、疲労の観察(`(2u−1)×noise`の同形、`league_observation.observe_fatigue`)は静的に同じ形であることだけを監査に記録し、本taskでは効果を測らない。

## 予測(反証され得る。事前の信頼を併記)

- **P1(大きさ)**: 3種類・3設定とも実現した平均ν/Nは−1.00±0.03、標準偏差は1.155±0.03、中心化版ν'/Nの平均は0±0.03。信頼約95%(コードから決まる)。
- **P2(キー検証)**: 練習日の再計算した雑音が真の技能と整合し、不一致0件。信頼約90%。
- **P3(設計か不具合か)**: 意図ではなく不具合(移植時に`uniform_from_key`の範囲を[0,1]と取り違えた)と分類される: DESIGN・DECISIONS・コードコメントに偏りを意図する記述が無く、旧モジュールは`low=−幅, high=幅`の対称で、導入は最初のコミットのみ。信頼約90%。
- **P4(新人以外)**: 新人以外の行の技能推定の平均誤差は負で、ずれで50%以上が説明される。信頼約60%。
- **P5(新人)**: 新人行の15〜21日の技能推定では、ずれの説明率は15%以上50%未満(残りは成長への遅れと事前値)。信頼約55%。
- **P6(差)**: 新人と新人以外の平均誤差の差のうち、ずれで説明される割合は25%未満(ずれは両方に共通で、観察回数の少ない新人はむしろ小さく受ける)。信頼約65%。
- **P7(先発)**: 全推定を中心化してもTop2が変わる割合は10%未満、新人行の先発割合の変化は±3pt以内。信頼約55%(ずれはほぼ全選手に共通)。
- **P8(精度)**: 中心化するとMAEは新人・新人以外とも下がる(分散も1.155N→0.577Nに減る)。信頼約80%。
- **P9(構造)**: 再生・伝播・説明の整合ゲートの不一致は0件。信頼約95%。
