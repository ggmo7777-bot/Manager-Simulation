## 分解の方法(行=新人×試合日×クラブ。`lineup_decision`の順位表から)

1. 行ごとに、順位表から新人nを除いた他の選手の**2番目に高い**cをカットオフ(nが先発=nがcに勝つ、同点はplayer_id順)とする。nの順位差 margin = 合計(n) − 合計(c)。
2. **項への加法分解**(正確): margin = Δskill_term + Δmatch_term + Δfatigue_penalty(各項はn−c、記録値)。丸めのため |margin − Σ| ≤ 3e-6 を全行で検査。
3. **真との分解**(研究者のみ): T = その試合日直後の真のcomposite skill、技能推定 e_s = skill_term/w_s − T、試合評価推定 e_m = match_term/w_m − T として margin = (w_s+w_m)·ΔT + w_s·Δe_s + w_m·Δe_m + Δfatigue_penalty。真の差の項・技能推定の誤差の項・試合評価推定の誤差の項・疲労の項の4つ(正確)。
4. **反実仮想の再順位付け**(オフライン、他の項は記録値で固定): 先発2人を選び直し、nが先発かどうかを見る。(CF-a)疲労項を0、(CF-b)試合評価項を0、(CF-c)技能項を0、(CF-d)全員の技能推定を真のTに置換、(CF-e)全員の試合評価推定をTに置換、(CF-f)技能・試合評価の両方をTに置換、(CF-g)**真値を使わない**: 全員の試合評価推定をその選手自身の技能推定に置換(試合の加点・先発の履歴が積んだ差を除く)、(CF-h)Tだけで並べる(基準)。指標=実際に先発しなかった行のうち反実仮想でnが先発する割合(反転率)。
5. 層別: (i)実際の先発/非先発の行、(ii)**真に上位2人**(その試合日のロスター内でT上位2人)なのに非先発の行=見逃し行、(iii)nの過去の先発数が0の行/1以上の行(先発の履歴と先発確率)、(iv)設定別・開始年齢別。
6. 先発の連続性(継続項)の有無: 順位表の項のキー集合が`{skill_term, match_term, fatigue_penalty}`だけであること、選考関数が他の入力を持たないことを静的に確認する。連続性の効果は試合評価推定を通る(先発は試合の観察で更新される)かを、nとcの試合評価推定と技能推定の差(match−skill)で記述する。

集計の主な単位は行(平均を設定ごとに)。補助として新人単位(その新人の行の平均→新人の平均)と、T031/T032の定義による新人の先発割合・真に上位2人の見逃し(入団+21日時点のロスター内T上位2人で窓内に先発なし)の再現。

## 予測(反証され得る。事前の信頼を併記)

- **P1(支配項)**: 先発しなかった行のnの順位差で、**試合評価項の差Δmatch_termが3項で絶対値最大**(平均)。3設定とも。根拠: 新人の事前0.5に対し、先発の選手は試合の観察で試合評価推定が積み上がる。信頼約50%(代案: 技能項が最大)。
- **P2(疲労は原因でない)**: 非先発の行で平均Δfatigue_penaltyは**正**(新人の疲労推定が低く、新人に有利)で、CF-aの反転率は10%未満。信頼約75%。
- **P3(見逃し行の構造)**: 見逃し行では真の差の項は正(真に上位)だが、推定誤差の項(w_sΔe_s+w_mΔe_m)が負で大きさがそれ以上となり、margin<0。推定誤差の項は試合評価側が大きい。信頼約60%。
- **P4(どの差し替えが効くか)**: 実際の非先発の行で、反転率は CF-e(試合評価推定を真に)>CF-d(技能推定を真に)。かつ真値を使わない CF-g の反転率が CF-d を上回る(試合評価推定が先発の履歴で技能推定からずれていることが、順位を決める)。信頼約50%。
- **P5(先発の履歴)**: 過去の先発数0の行の先発確率は、1以上の行より**15pt以上低い**(3設定とも)。注: 才能との交絡を含む記述(履歴が原因とは書かない)。信頼約70%。
- **P6(継続項は無い)**: 順位表の項は3種だけ。信頼約99%(構造)。
- **P7(T031→T032)**: 非先発の行のΔmatch_termの平均は、T032がT031より**負**(混合が新人の試合評価推定を技能の観察へ引き下げる、T032の解釈)。信頼約55%。

## 限界

真の技能は試合日直後(その日の訓練後)の値で、選考時点(訓練前)とずれる(差は小さい)。試合評価は試合の加点を含み、真の技能と同じ尺度ではない(試合評価推定の誤差eは、先発者では正にずれるのが自然)。ロスターは通常3人で、先発2枠は新人のほか2人との比較に尽きる(cは2位の他者)。3seedは独立でない。分解は記述で因果の証明ではない(反実仮想は1項差し替えで、全体の相互作用の再シミュレーションではない: 選考を変えると履歴が変わる)。次の一手は候補で実装しない。
