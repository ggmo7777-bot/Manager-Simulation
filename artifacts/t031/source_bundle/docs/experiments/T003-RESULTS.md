# EXP-T003 助言への信頼の検証結果

2026-11-05。CPython 3.13.3、macOS arm64、標準ライブラリのみ。事前登録どおり4条件×84日、探索seed 0〜29・確認seed 100〜129の計240本。セット間で係数は調整していない。

## 実装と機構

監督は自分の技能推定と、方法A/Bそれぞれの固定の主観率0.10から `q_coach = subjective_rate × (1 − perceived_skill)` を求める。助言には予測値を付け、推定技能と主観率の記憶への参照を残す。選手は従来の採点で採用・拒否を決める。受け取った予測値が作用するのは、実施後に信頼を更新するときである。

助言の方法を実施したときだけ、私的な朝夕の観測差 `y` を行動前の自己予測と監督予測に照合する。更新は `trust_next = clip(trust + 0.05 × clip(((y−q_self)²−(y−q_coach)²)/0.05², −1, 1), 0, 1)`。信頼には符号付きの `y` を使い、方法期待Gには従来の切り詰めを適用する。固定信頼条件でも適格な実施経験の両予測誤差を記録し、信頼値と信頼の記憶を維持する。

| 検査 | 結果 |
|---|---|
| H1 相対誤差 | 監督予測が近いと信頼増、遠いと信頼減。同一の予測では負の観測差でも変化なし。上下限を確認。 |
| H2 実施経験 | 拒否・助言なし・休息に対するフィードバックイベントは0。採用して実施した助言ごとに1件のイベント。 |
| H3 事前の自己予測 | Gを更新する日も停止する日も、事前の方法別G、受け取った予測、以前の信頼、実施、朝夕観測をIDで参照。 |
| H4 情報境界 | p1の真のrate・上限を変え、主観的な入力を揃えた初日で、監督予測、採点、信頼更新が一致。真の成長は変化した。 |
| H5 次の選択 | 初期信頼0.47、両履歴で同じBを実施。監督の予測に近い観測の後は信頼0.52でBを採用。自己予測に近い観測の後は0.42でAを選びBを拒否。次の観測・助言・Gは共通。 |
| H6 固定信頼 | seed 17の28日で、T002凍結版のbaseline/G停止と数値・全候補得点・選択が一致。T001/T002の実験CLIも完走。 |
| H7 継続と保全 | 4条件すべてで84日連続と42+42日のsnapshot/JSONLがバイト一致。適応信頼1000日の予算超過・参照不整合0。T001/T002の旧artifact全34/32ファイルは事前inventoryと一致。 |

代表例の14日目、p1の信頼イベント323には、以前の信頼277、自己G 278、監督の提案315、選択316、実施318、朝夕観測308/322への参照がある。観測差は−0.00664で、自己予測0.02301のほうが監督予測0.03591より近く、信頼が0.73608から0.71745に下がった。同日のG更新324はその後に0.01151を記録。17日目の判断384は、信頼323と更新後のG 324を別々に参照した。研究ログ上の真の成長は+0.00649だった。 [代表JSONL](../../artifacts/t003/representative/full/events.jsonl)

### 信頼の変化と経験機会

確認セットの1run当たりの平均。二乗誤差は助言を実施した各runで平均し、その平均をrun間で集計した。実施のないrunは予測誤差の平均から除外した。

| 条件 | 選手 | 提案 / 実施 | 信頼の増加 / 低下回数 | 自己 / 監督の予測二乗誤差 |
|---|---|---:|---:|---:|
| 固定・G更新 | p1 | 74.93 / 57.93 | 0 / 0 | 0.000550 / 0.000930 |
| 固定・G更新 | p2 | 38.07 / 1.20 | 0 / 0 | 0.000961 / 0.000644 |
| 適応・G更新 | p1 | 74.13 / 50.80 | 15.30 / 35.50 | 0.000543 / 0.000918 |
| 適応・G更新 | p2 | 38.87 / 1.27 | 0.97 / 0.30 | 0.000965 / 0.000630 |
| 固定・G停止 | p1 | 64.63 / 55.17 | 0 / 0 | 0.002158 / 0.000956 |
| 固定・G停止 | p2 | 48.37 / 0 | 0 / 0 | 実施なし |
| 適応・G停止 | p1 | 65.00 / 55.70 | 18.40 / 8.37 | 0.002172 / 0.000967 |
| 適応・G停止 | p2 | 48.00 / 0 | 0 / 0 | 実施なし |

- G更新ありでは、p1は実施経験で平均すると自己予測の誤差が小さく、適応信頼が低下した。確認セットの終値差は−0.36903 [−0.40325, −0.33413]。p2の実施経験は1.27件/runで、30本中8本には一度もなかった。探索セットでは30本中13本で実施なし。
- G停止では自己予測が初期値0.046に固定される。p1は監督予測の誤差が小さい経験が多く、60本中58本で信頼終値が上限1に達した。p2はG停止の両信頼条件で一度も助言を実施せず、信頼は0.28のまま。信頼が不変でも、助言の予測精度が互角だったとは判断できない。
- 監督の総配分は全条件で1run当たり観察55・提案113。G更新ありの適応化で監督の行動列は6.6〜7.6%が不一致であり、総枠数だけでは差を表せない。確認セットの助言採用率差は−6.25ポイント [−7.73, −4.66]。

### 技能gainの対応差

区間は固定2プロフィールへの観測ノイズを変えたseed単位の対応差を、解析seed 3003のMT19937で2,000回再標本化した95% percentile区間。交互作用は `適応・G停止 − 固定・G停止 − 適応・G更新 + 固定・G更新`。

| 比較 | 探索 平均gain差 [95%区間] | 確認 平均gain差 [95%区間] |
|---|---:|---:|
| 適応−固定、G更新 | +0.00211 [+0.00095, +0.00336] | +0.00346 [+0.00219, +0.00483] |
| 適応−固定、G停止 | −0.00149 [−0.00173, −0.00126] | −0.00141 [−0.00167, −0.00117] |
| G停止−G更新、固定信頼 | −0.01036 [−0.01199, −0.00873] | −0.01164 [−0.01295, −0.01044] |
| 信頼×Gの交互作用 | −0.00359 [−0.00480, −0.00248] | −0.00488 [−0.00626, −0.00362] |

確認セットでG更新を維持したときの個体別gain差はp1 +0.00669、p2 +0.00023。G停止時はp1 −0.00283、p2 0。信頼の増減と技能gainは別の指標で、予測が当たることから助言された方法の有用性は推定できない。ここでの差は監督の反応や将来の経験も含む総効果。

助言を採用して実施した経験に限定したため、誤差比較には選択バイアスがある。拒否した方法の結果は観測していない。監督の主観率は固定で、疲労・個人適性・真の上限を反映しない。自己予測Gには切り詰めの偏りが残る。結果の範囲は固定2プロフィールと今回のPolicy・係数・ノイズに限られる。
