# T009: 育成・監督選考・2D競技を接続した最小の出場機会閉ループ

状態: **実装・検証完了**。2026-11-07。T008完了後の継続指示に基づき、[事前計画](../experiments/T009-PROTOCOL.md)を実装前に登録し、[実験結果](../experiments/T009-RESULTS.md)および[監査レビュー](../experiments/T009-REVIEW.md)まで完了した。T001〜T007（育成・認識・信頼）およびT008（最小2D競技核）の既存環境と凍結成果物（421ファイル）は一切作り直さず完全保持した。

> **作成者に関する明記**: T001〜T007の作成者（`Sol 6.1 High` および当時の主担当）とは**別の作成者である Antigravity（Gemini 4 Argon）** が、T008に引き続き本T009の事前計画策定・実装・実験・独立監査を担当する。

## 問題と目的

T007までに育成・認識更新・相手別信頼の境界を確認し、T008で連続2Dピッチ上の少人数競技核（`match_2d`）を独立に構築した。しかし両者はまだ切り離されており、以下のM4核心の連鎖が検証されていない。

`監督の観察/提案 → 選手の受諾/代替行動/休息 → A/Bの更新 → 監督の先発選考 → 2D少人数競技 → 試合観察による監督評価・選手の出場機会認識の更新 → 次の学習機会と選考`

移籍交渉や複数クラブの経済まで同時に足すと、「能力成長が競技を変えたのか」「試合結果が監督選考を変えたのか」「初期評価バイアスが出場機会を固定したのか」を分離できなくなる。そのためT009では、**1クラブ（監督1人 `c1`・選手3人 `p1, p2, p3` が先発2枠 `slot 0, slot 1` と控え1枠 `bench` を争う）＋固定対戦相手（`a1, a2`）の84日（週1試合×12試合＋練習72日）閉ループ**を最小単位として実装・検証する。

## 実装前に決めることと今回の選択（Antigravity / Gemini 4 Argon）

1. **育成能力と競技3能力の対応付け (`A`)**:
   - 各選手は真の競技3能力 `MatchTraits(pace, passing, shooting)`（および平均技能 $\bar{s} = (\text{pace}+\text{passing}+\text{shooting})/3$）、上限 `cap`、方法別学習率 `rates=(r_A, r_B)`、疲労 `fatigue` を持つ。
   - 練習方法 `A`（技術・配球重点）は実現成長量 $\Delta s$ を `(pace, passing, shooting)` へ重み `(0.45, 1.45, 1.10)`（平均1.0）で配分し、方法 `B`（機動・突破重点）は重み `(1.45, 0.45, 1.10)` で配分する。休息 `rest` は疲労を回復させる。
   - `training_match_coupling='coupled'` では練習で成長した現在能力（および当日の疲労による実効減衰）が2D試合エンジンへ渡り、`decoupled` では初期能力固定で試合を行うことで「育成 $\to$ 2D競技」の順方向効果を分離する。
2. **監督の先発選考と試合観察境界 (`B` / `Policy`)**:
   - 試合日（7日ごと: Day `7, 14, ..., 84`）の朝、監督 `c1` は真の能力や真の疲労を一切見ず、自身の私的認識（推定技能 $\hat{s}_{c1, i}$、推定試合評価 $\hat{m}_{c1, i}$、推定疲労 $\hat{f}_{c1, i}$、認知ベンチ連続数 $\text{bench\_streak}_{c1, i}$）のみから先発2名（`slot 0`, `slot 1`）と控え1名（`bench`）を選考する。
   - 試合では先発2名のみが40 tickの2D試合（`match_2d`）に出場する。`match_feedback='feedback'` では、監督は**出場した先発2名の試合統計（得点・シュート・成功パス・奪取・保持tick）のみを観測**して $\hat{m}_{c1, i}$ と $\hat{s}_{c1, i}$ を更新し、控え選手の試合評価は更新されない（出場機会による情報非対称性）。`prior` では試合結果による評価・選考・選手自律性へのフィードバックを閉じる。
3. **選手の出場機会認識と練習選択への還流 (`B` $\to$ `Policy`)**:
   - 各選手は自身の出場回数 `appearances`・連続ベンチ数 `bench_streak`・出場満足度 `playing_time_satisfaction`・自己試合評価 `self_match_rating` を記憶する。
   - `match_feedback='feedback'` では、ベンチが続き満足度が低下した選手は自己主導の危機感（練習動機の増分と自律性シフト）を高め、監督の提案が他選手へ偏る中でも自主練習で先発奪取を図る一方、疲労とのトレードオフに直面する。
4. **保存・版・過去成果物の保全**:
   - `world_kind='selection_loop'`, `save=9`, `rules='t009-selection-loop-v1'`, `policy='t009-selection-score-v1'`, `author='Antigravity (Gemini 4 Argon)'` として独立保存する。
   - 全履歴再演に頼らない1パス線形整合監査readerを実装し、T001〜T008の凍結成果物（421ファイル）を完全保持する。

## 主比較と追加対照

- **主比較（$2 \times 2$ 要因計画、4条件×60seed×84日＝240run）**:
  1. `decoupled_prior`: 育成能力の試合反映OFF（初期能力で試合）× 試合評価フィードバックOFF（事前・練習評価のみで選考）。
  2. `coupled_prior`: 育成能力の試合反映ON × 試合評価フィードバックOFF（「育成 $\to$ 2D競技」の順方向効果を分離）。
  3. `decoupled_feedback`: 育成能力の試合反映OFF × 試合評価フィードバックON（「2D競技 $\to$ 監督選考・選手行動」の逆方向効果を分離）。
  4. `coupled_feedback`: 育成能力の試合反映ON × 試合評価フィードバックON（M4の最小閉ループ）。
- **追加対照（確認30seed `100..129`）**:
  - `rotation_feedback`: ベンチ連続選手への機会配慮項 $w_{\text{opp}}$ を有効化し、短期の得失点差と挑戦者 `p3` の出場機会・長期成長のトレードオフを測る。
  - `fair_prior_p3`: 高い潜在学習率を持つ `p3` の真の能力・学習率は変えず、監督 `c1` の初期評価だけを過小評価（技能 `0.32`・試合評価 `0.30`）から適正（技能 `0.47`・試合評価 `0.53`）へ変え、**初期評価バイアスによる出場機会の固定化とキャリア分岐**を検証する。
  - `p1_pass_style_plus`: `p1` の2D試合スタイル（`pass_bias`）のみを変更し、戦術スタイルの違いが試合内容・監督の試合評価・選考へ波及するかを確認する。

## 成功・失敗条件

- 監督の先発選考・練習提案、選手の練習選択・2D試合行動のすべてで世界の真値がPolicyへ漏れないこと。
- `coupled_prior - decoupled_prior` で練習による3能力成長が2D試合の保持・パス・シュート・得失点差を有意に改善すること。
- `coupled_feedback - coupled_prior` で試合観察フィードバックが監督の先発選考（`p1, p2, p3` の出場配分）と選手の練習行動を有意に変えること。
- `fair_prior_p3 - coupled_feedback` で、同じ真の能力・潜在学習率でも監督の初期評価1つで `p3` の出場試合数と最終能力が追跡可能な理由をもって分岐すること。
- 84日連続と42+42日保存再開で `snapshot.json` / `events.jsonl` がバイト完全一致し、1000日＋14日再開でも予算・境界・イベント参照が破綻しないこと。
- Policy関数を呼ばない独立監査スクリプトで練習判断・監督提案・先発選考を再計算して100%一致し、T001〜T008の凍結421ファイルが不変であること。
