## 問題と目的

T010では2クラブ・6選手で「育成（`A/B`）$\leftrightarrow$ 先発選考 $\leftrightarrow$ 2D競技 $\leftrightarrow$ 3者合意移籍」の最小キャリア閉ループ（M4 / VS1）を実証したが、[ROADMAP.md](../ROADMAP.md) のM5（小規模世界）および [DESIGN.md](../DESIGN.md) 第9節が求める以下の構造：

1. **4クラブ以上の総当たり日程・順位表と複数移籍先候補の競合**
2. **厳密な資金保存則を満たす有限予算台帳（`WorldFinanceLedger`）**:
   $$\text{世界資金}(t+1) = \text{世界資金}(t) + \text{明示した外部流入} - \text{明示した外部流出}$$
3. **育成クラブへの成果帰属（移籍金・連帯貢献金・移籍後の出場活躍配当）と育成設備への再投資閉ループ**
4. **無限金策・二重所属・二重報酬請求・循環移籍・単一方針による永続独占の排除**

がまだ検証されていない。T011では4クラブ・4監督・12選手の最小リーグ経済世界を構築し、これらを定量実験と独立監査で検証する。

## 実装前に決めることと今回の選択（Antigravity / Gemini 4 Argon）

1. **4クラブ・4監督・12選手のリーグ構成と運営方針**:
   - **育成重視クラブ（Academy / Developer）**:
     - `club_a`（監督 `c1`, 初期所属 `p1, p2, p3`, 初期資金 `22.0`）: `p3` は高い潜在成長率を持つが初期評価が低く控えスタート。全員の育成元は `origin_club_id = "club_a"`。
     - `club_c`（監督 `c3`, 初期所属 `p7, p8, p9`, 初期資金 `22.0`）: `p9` は高い潜在成長率を持つが初期評価が低く控えスタート。全員の育成元は `origin_club_id = "club_c"`。
   - **補強重視クラブ（Buyer / Contender）**:
     - `club_b`（監督 `c2`, 初期所属 `p4, p5, p6`, 初期資金 `58.0`）: 豊富な初期資金と高い獲得意欲を持ち、先発2番手（`p5, p6`）の戦力補強を狙う。
     - `club_d`（監督 `c4`, 初期所属 `p10, p11, p12`, 初期資金 `58.0`）: 豊富な初期資金と高い獲得意欲を持ち、先発2番手（`p11, p12`）の戦力補強を狙う。
   - 初期クラブ資金合計は `22.0 + 58.0 + 22.0 + 58.0 = 160.0`。所属人数は常に `2 <= len(roster) <= 4` を満たす。
2. **総当たりリーグ日程と順位表（84日＝12節×各節2試合＝24試合）**:
   - 試合日（Day `7, 14, ..., 84`）ごとに4クラブ総当たりカード（1節2試合×3節で1巡、84日で4巡＝計24試合、ホーム/アウェイ交互）を40 tickの連続2D試合で実施し、勝点（勝3・分1・負0）・得失点差・総得点でリーグ順位表を更新する。
3. **有限資金台帳と育成設備再投資・育成還元配当**:
   - すべての金銭移動を貸借一致の原子的トランザクション（`LedgerTransaction`）として記録し、どの時点でもクラブ現金残高は `cash >= 0.0`、かつ
     $$\sum_{k} \text{club\_cash}_k + \sum_{i} \text{player\_wages}_i + \text{external\_outflow} = \text{initial\_cash} + \text{external\_inflow}$$
     を厳密に満たす。
   - **育成日の設備投資 (`facility_active`)**: 各クラブは育成日の朝、現金残高が安全準備金（`facility_reserve_floor = 16.5`）以上あれば設備維持費 `0.30` を `external_outflow` へ支出し、その日の所属選手の練習成長率を `+18%`（`1.18` 倍）高める。
   - **移籍決済と育成還元配当 (`solidarity_mode`)**:
     - `no_solidarity`: 移籍成立時の基本補償金のみ（`2.0`）で、育成連帯金・移籍後の出場活躍配当は `0.0`。そのため選手を放出した育成クラブ（`club_a, club_c`）は給与支出により中盤以降に安全準備金を割り込み、設備稼働が停止して残った選手の成長も鈍化する。
     - `solidarity`（育成還元ON）: 移籍成立時に獲得クラブから放出/育成クラブへ適正移籍金（`11.0`）＋育成連帯貢献金（`3.0`、計 `14.0`）が支払われ、さらに移籍した育成出身選手が新クラブで試合に先発出場するたびに1試合あたり `1.50`（最大6試合、`(transfer_id, match_id)` で一意管理し二重請求を完全拒否）の**育成活躍配当（Development Dividend）**が獲得クラブから育成元クラブ（`origin_club_id`）へ支払われる。これにより育成クラブはシーズンを通して高水準の育成設備を稼働し続けられる。

## 主比較と単一要因・攻撃的対照

- **主比較（$2 \times 2$ 要因計画、4条件×60seed×84日＝240run）**:
  1. `closed_no_solidarity`: 移籍市場OFF × 育成還元OFF
  2. `closed_solidarity`: 移籍市場OFF × 育成還元ON
  3. `open_no_solidarity`: 移籍市場ON × 育成還元OFF
  4. `open_solidarity`: 移籍市場ON × 育成還元ON（M5の完全リーグ経済閉ループ）
- **単一要因・攻撃的対照（確認30seed `100..129`、計90run）**:
  5. `fixed_budget_no_inflow`: 外部興行収入（試合日流入）を `0.0` に固定し、初期資金 `160.0` のみで保存則・破綻ゼロ（`insolvency_events == 0`）・支出抑制が機能するかを検証。
  6. `hoarder_buyer_policy`: 資金力のある `club_b, club_d` が低い閾値で選手買占めを試みる攻撃的Policy対照。人数上限 `MAX_CLUB_ROSTER = 4`・資金制約・出場機会不満によって単一クラブの永続独占が防がれるかを検証。
  7. `exploit_churn_guard`: 同一シーズン内の循環移籍（`A -> B -> A`）と育成配当の二重請求を試みる敵対的モード。台帳・契約ガードが全件を阻止（`blocked_circular_transfers > 0`, `blocked_duplicate_claims > 0`, `actual_duplicate_claims == 0`）し資金保存則が破られないことを検証。
