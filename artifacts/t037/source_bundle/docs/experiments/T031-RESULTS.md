# T031 結果 — 監督の観察候補の未観察日数の上限を10日から40日に広げる(控え若手の発見の最小機構)

実装・実験: 2026-11-10。契約: [T031](../tasks/T031.md)、事前条件: [PROTOCOL](T031-PROTOCOL.md)、判断: [D046](../DECISIONS.md)。規則・上限(40日)・条件・閾値は実装前にコミットし、結果後に変えていない(補正なし)。Python 3.13.3(uv)、macOS arm64。**40日と係数は未校正の仮説。**

## 結論

- `LeagueEconomyConfig.coach_exploration`(`"none"`既定、`"unseen_bonus_v1"`)を追加した。有効時のみ、`decide_coach_training`の観察候補の「未観察日数の項」が`0.018*min(40, 日数)`(従来`min(10, 日数)`)になる。入力は監督のB層(各選手の`last_seen_day`と現在日)だけで、真の技能・特性・年齢・乱数は使わない。新しいworldフィールド・イベントはない。
- **P1(新人は観察される)は支持**: 完全な1年度を過ごした新人1,008人(S=29と33で各504)のうち、入団クラブの監督に観察された割合は対照0.644 → 有効**1.000**(予測≥0.90)。
- **P2(先発する新人が増える)は反証**: 先発した割合は対照0.644 → 有効0.640(差−0.004、予測は+0.03以上)。観察は増えたが、先発には結びつかなかった。
- **P3(推定誤差が減る)は支持だが小さい**: 入団後1年度の|推定−真の技能|の平均は0.0977 → 0.0935。新人のいる84セルのうち69セルで有効のほうが小さい。
- **P4(費用)**: 事前登録した「実質的な費用」の線(技能−0.005未満、信頼−0.010未満)は**超えなかった**。ただし予測の向きは半分外れた。技能は−0.0016(有意でない)だが、信頼は予測と逆に+0.0049、先発の真の平均技能も+0.0024で、有意に増えた(下の表)。監督の練習日の枠は提案から観察と偵察へ移った。
- 注目点: 対照では「観察された」と「先発した」の割合が一致する(0.644)。つまり対照の新人は先発した場合にしか観察されない。有効側は観察を100%にしたが、先発の選考規則(技能推定0.55・試合評価推定0.48・疲労推定)は変えていないので、発見が先発に結びつくかはこの機構の外にある。

## 解釈(仮説。分解は未実施)

- 事前登録の費用の予測のうち、技能が負(方向は一致、有意でない)、実質的な線を超えない、は当たり。信頼が負、先発の技能が正でない、は**外れた**: 信頼・満足度・先発の技能はむしろ有意に増え、移籍は減った。原因は分解していない。観察の増加で先発の推定が真値に近づき、先発の質が上がったことが、満足度や信頼に波及した可能性があるが、検証していない。
- 先発率が変わらない理由の仮説: 先発の選考は技能推定(重み0.55)に加えて試合評価推定(重み0.48)を使い、試合評価推定を更新するのは試合の観察と偵察だけで、練習日の観察(session observation)は技能推定・疲労推定・方法の残差しか更新しない(コード`_step_training_day`)。控えの試合評価推定は観察されても定数0.5のままなので、技能推定が変わっても選考の順位が動きにくい。この仮説は検証していない(T032の候補)。
- 「発見」を保証する仕組みはない。観察は推定を真に近づけるだけで、新人の約64%は対照でも先発している。

## 限界

- 40日と係数は未校正。対象は新人に限らず長く見ていない控え全員で、新人以外の分離は枠の使途の集計(観察の選択の約72%が10日超の未観察を対象)に限る。
- 観察に経済的な費用はなく、枠の消費だけ。偵察が増えた(+5pt)理由は未分解(偵察は他クラブの選手の観察で、費用は別に払う)。
- 3seedはセル間で独立ではなく、符号検定は参考値。8年度は現実の期間ではない。S=29と33の新人は入団時期が違う。
- 才能の発見の測定は研究者のみが真値で定義した記述で、合否に使っていない。ランクの定義(入団1年後の自クラブ上位2人)は事前登録のとおり。
- 信頼readerは監督の決定を再演しないので、`coach_exploration`の改ざんを受理する(T022の既知の限界)。
