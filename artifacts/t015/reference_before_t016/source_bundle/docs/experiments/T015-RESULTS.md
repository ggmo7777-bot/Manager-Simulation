## 解釈（確認できた範囲）

- 育成還元による残留側成長の増加は、符号はsampledでも残った（負は0）。**大きさは約30%に縮小した**。固定fixtureの数値をそのまま一般化できない。
- 市場開放による成長差は、fixedとsampledでほぼ同じ大きさだった。
- sampledでは育成クラブが補強クラブより成長率が高いことを範囲で入力している。そのため、成長・勝点の類型差は結果ではなく入力に由来する部分を含む。
- 初期水準の標準偏差はfixed 0.081、sampled 0.035。**sampledの方が狭い**。補強側の範囲を広く取っても、育成側の狭い範囲と合わせると全体の散らばりは固定fixtureより小さくなった。多様性の拡大とは言えない。
- 還元の効果が縮んだ理由（p3/p9の台本、成長率の分布、監督の印象誤差のどれか）は切り分けていない。要因分解は未実施。
