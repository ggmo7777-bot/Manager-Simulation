# T033 — 新人が先発しない理由の分解(規則を足さない分析。T030/T031/T032の`lineup_decision`の順位表)

2026-11-10、実装前登録(結果を見る前に方法・予測・失敗条件を固定)、2026-11-10完了。状態: 完了(結果: docs/experiments/T033-RESULTS.md)。ブランチt033はt032から積む(PR #15が先にマージされる)。[事前条件](../experiments/T033-PROTOCOL.md)、判断: D048。担当: Claude Sonnet 5.5。

## 問題

T031は新人の観察率を64.4%→100%に上げたが先発は変わらず(P2反証)、T032は試合評価推定を練習日の観察で更新しても先発が増えず、真に上位2人の新人の見逃しが143→163人に増えた(P3反証)。T032の解釈(推定が正しくなるほど先発しない、先発の入れ替わりが増えた)は仮説のままで、**分解は未実施**。選考は`select_skill_weight`×技能推定+`select_match_weight`×試合評価推定−`select_fatigue_weight`×疲労推定だけで、新規の規則を足す前に「どの項が新人の非先発を説明するか」を測る。

## 最小の選択

**シミュレーションは変えない。** 各`lineup_decision`のイベントに既に記録されている順位表(各選手の`skill_term`・`match_term`・`fatigue_penalty`・合計)を、新人について(a)先発した試合日/しなかった試合日、(b)真に上位2人なのに先発しなかった試合日、で項ごとの差(順位差の加法分解)に分け、研究者だけが真の技能(後付けの評価用)で推定誤差と真の差に分け、反実仮想の再順位付け(他の項を固定して1項だけ差し替え)をイベントとその日の真の技能から**オフラインで再計算**する。結果は世界へ戻さない。

- 新規の規則・config・イベント・worldフィールド・乱数は無い。`soccer_sim/`は1バイトも変えない(source hashがT032と一致することを検査)。
- 対象は T030(`generations`有効)・T031(+`coach_exploration`)・T032(+`coach_practice_rating`)の各84セル(同一世界・seed・開始年齢)。セルは既存の`cfg`関数で再実行し、最終値とイベント数が各taskの保存済みsummaryと一致することを検査する(再実行は決定的)。
- 新規コードは`experiments/t033.py`(分析)と`tests/test_t033.py`のみ。新成果物は`artifacts/t033/`のみ。
