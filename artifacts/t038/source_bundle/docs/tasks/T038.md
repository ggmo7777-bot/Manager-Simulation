# T038 — なぜ平均の補正が先発の的確さを動かすか(観察の新しさ別の推定誤差、分析のみ)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件を固定)。状態: 完了(結果: docs/experiments/T038-RESULTS.md)。ブランチt038はt037から積む(PR #20が先にマージされる前提)。[事前条件](../experiments/T038-PROTOCOL.md)、判断: D053。担当: Claude Sonnet 5.5。

## 問題

T037は、T036のcentered_v1の効果(先発が真の上位2人と一致 62.3%→70.9%、+8.7pt)の約81%(+7.0pt)が、ばらつきを変えない`shifted_v1`(平均だけ補正)で既に得られることを示した。しかし「なぜ平均を直すと先発の並びが正しくなるか」は検証していない。T037の仮説: `legacy`では観察された選手の推定だけが約−幅下がり、観察されない(古い)選手との相対順位がゆがむ。既定を`centered_v1`へ移す判断(別task)の前に、この機構を確かめる。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。** 凍結T030/T031/T032設定×84セル×168日を、既存の`legacy`/`shifted_v1`/`centered_v1`の3群で再演する(756実行、T037と同一)。`decide_club_lineup`の呼び出しの直前に、各選手の技能推定・試合評価推定・`last_seen_day`を読むだけの記録(読み取り専用)を足し、研究者だけが真の技能を使って次を測る:

1. 最後の観察からの経過日数(推定の新しさ)別の技能・試合評価推定の誤差(新人以外/新人別)
2. 対の順位の正答率(真に上の選手が、新しい観察を持つか古い観察を持つか別)
3. 先発の取り違え(真の上位2人なのに先発から漏れた選手/先発に入った上位2人でない選手)の経過日数
4. 同じ状態での反実仮想: 新しさ別の差だけを引いたら先発の一致は戻るか(別の設定で推定した補正を使う)

最後に、centered_v1を既定にする提案をするかの証拠に基づく推奨を書く(推奨のみ。既定は変えない)。

- 対象外: `soccer_sim/`の変更、新しいconfig、既定の変更、幅の調整、初見の観察の規則(別task)、第4の隅の実行、CLI/UI。戻し方: `experiments/t038.py`、`tests/test_t038.py`、`artifacts/t038/`、文書の削除のみ。
