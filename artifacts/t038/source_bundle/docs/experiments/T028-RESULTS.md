# T028 結果 — 助言への態度(従う/部分従順/拒否)を性格と本人の状態から決める

実装・実験: 2026-11-10。契約: [T028](../tasks/T028.md)、事前条件: [PROTOCOL](T028-PROTOCOL.md)、判断: [D043](../DECISIONS.md)。式・係数・閾値・条件・検定は実装前にコミット(d3f74c0)し、結果後に変えていない。Python 3.13.3(uv)、macOS arm64。**係数・閾値・式は未校正の仮説。**

## 結論

- `LeagueEconomyConfig.advice_response`(`"none"`既定、`"personality_v1"`、`personality`必須)を追加。助言を受けた日の練習判断の直前に、選手は `score=(trust−autonomy)+0.25(discipline−0.5)−0.40(1−emotional_stability)·dissatisfaction` から 従う(≥0)/部分従順(≥−0.20)/拒否 を決める(純関数`decide_advice_response`、乱数なし)。部分従順は従来の「助言を加点として混ぜる」判断そのまま、拒否は助言なしの判断と同一、従うは提案方法を選ぶ。**特性が初めて行動を変えた。**
- 本人の理由は構造化イベント`player_advice_response`(項の値・`reason_codes`・`primary_reason`)、監督が見るのは別イベント`coach_advice_outcome`(態度・3値の`stated_reason`・実際に従ったか)だけ。真の特性・項の数値は監督側に出ない。監督はまだこれを使わない。
- 成功条件1〜8をすべて満たした(下表)。予測P1・P2・P3は支持。P4は機構効果(mid−off)と特性効果(on−mid)がどちらも技能で有意。P5(特性と成長の相関)は支持されない。

## 測定(42セル、168日、onの全応答28,402件)

- 応答の割合(プール): complied 6.7%、partial 30.8%、refused 62.6%。**P3(各5%以上)は満たしたが、拒否が多数。** 主な理由(`primary_reason`)は`trust_below_autonomy`が21,292件、`self_lax`3,305、`trust_above_autonomy`1,816、`irritated_by_low_playing_time`1,585、`self_disciplined`184、`no_dominant_term`220。つまり多くの拒否は「信頼が自律を下回る」(信頼は既存の更新式で床付近まで下がる)が理由で、性格より信頼の状態が主因。
- **P1(支持)**: 従う割合は規律性の低/中/高三分位で 5.6% / 6.6% / 8.7% と単調。セル内の高−低の差は35セル中26セルで正(平均+9.2ポイント)。ただし部分従順の割合は 34.4% / 23.5% / 39.1% で非単調(中位で拒否が最大)。
- **P2(支持)**: 不満足(dissatisfaction>0.10、17,218件)の拒否割合は感情安定性の低/中/高で 92.5% / 86.4% / 72.0%。
- **P4 技能・満足・信頼(168日、対応差、符号検定)**: 

| 指標 | on−mid(特性の効果) | mid−off(機構の効果) |
|---|---|---|
| 平均真の技能 | +0.0024、正38/負4、p<0.0001(有意) | −0.0030、正9/負33、p=0.0003(有意) |
| 平均満足度 | −0.0001、41セルは差0(無差) | +0.0001、41セルは差0(無差) |
| 平均trust | −0.0017、正18/負24、p=0.44(無差) | −0.0059、正6/負36、p<0.0001(有意) |

  有意水準0.0083(6本)。84日時点も同じ向き(技能 on−mid +0.0029・mid−off −0.0041、trust mid−off −0.0083)。**解釈の限界**: 機構を入れる(off→mid)と、助言の多くを拒否するため技能・信頼がわずかに下がる。同じ機構で特性を個体差にする(mid→on)と技能が上がるが、その理由(従う割合の違い、拒否の対象の違いなど)は分解しておらず、特性が「良い性格」だから成長が良いとは言えない。差は小さい(平均技能0.72に対し0.002〜0.003)。満足度は出場時間で決まり、態度では動かなかった。
- **P5(記述のみ)**: セル内の規律性と技能増加のSpearman相関の中央値は−0.09(正のセル17/42)で、規律性が高い選手ほど伸びるという関係は見えない。感情安定性と最終満足度は中央値+0.13(正24/42)で弱い。
- 記述: 168日の平均イベント数 off 7,955 / mid 9,321 / on 9,328(応答イベントを含む)。完了移籍は平均 off 1.64 / mid 1.71 / on 1.79。

## 実装中の確認事項(規則・閾値は不変)

- 動的漏れ検査で特性を1e-9ずらすと、`player_advice_response`の項の6桁目が1だけ変わる事例があった(丸め境界)。応答は同一で、監督側・世界状態は完全一致。プロトコルの「全イベント一致」は本人の理由記録(trait由来の数値を持つ)を除く形に実装した(項と合計を比較から除外)。規則・閾値の変更ではない。
- ゲート6の「同じ状況」は連続値なので、許容0.01の近傍対で実装し、特性を差し替える反事実と併記した。
- テスト実行で既存の`experiments/t027.py`の許可リストに`_player_advice_response`を1つ追加した(T027の静的検査が、T028の唯一の特性読込関数を許すため)。T027の結論(T027時点で未使用)は変えていない。

## 限界

- 係数(0.25、0.40)・閾値(0、−0.20)・式の形は未校正。拒否が62.6%と多いのは、信頼が既存の更新式で低く推移するため(無効時のtrust−autonomy四分位が−0.30〜+0.02)。係数を結果で調整していない。
- 対象は最も信頼する監督の提案1件のみ。態度は同日の練習判断にだけ効き、満足度・信頼への反応の大きさは既存の更新式のまま。監督は結果を観測するが使わない。
- 3seedはセル間で独立でなく、符号検定は参考値。on−midの技能差の理由は分解していない。
- 信頼readerはイベント内容の改ざんを(manifestを偽造されると)見逃す。認証は全再演readerのみ。
