# T034 事前実験条件

2026-11-10、実装前登録(結果を見る前)。契約: [T034](../tasks/T034.md)。結果を見て方法・定義・閾値・予測を変えない。外れた予測は結果として記録する。**分析のみ**で世界は変えず、研究者だけが真の技能を使う。

## 固定する条件

Python 3.13.3(uv)。T033と同じ84セル(14世界×seed{100,101,102}×開始年齢{29,33}、168日、`season_length_days=21`)を3設定(T030/T031/T032の有効設定。`t033.SETTINGS`)で再実行。1日ずつ進め、各日の後に(世界の状態は読むだけ)新人の真のcomposite skillを記録し、毎試合日の後に全選手の真のcomposite skillを記録する。新人=`season_youth_joined`で入った選手、窓=入団日の翌日〜+21日(完全な1年度を持つ新人のみ)、行=窓内の自クラブの`lineup_decision`のうち新人が順位表に載るもの(T033と同じ行・同じ新人)。以下「監督」は新人の所属クラブの監督(`CLUB_COACH_MAP`)、「観察」はその監督が新人について記録した次の3種のイベント。

| 種類 | イベント | 技能推定の更新 | 試合評価推定の更新 |
|---|---|---|---|
| 練習日(session) | `coach_session_observation` | α=`coach_skill_alpha`(0.36)、値=`obs_skill` | `coach_practice_rating`有効時のみ 0.70旧+0.30 `obs_skill`(T032設定) |
| 偵察(scout) | `coach_scout_observation` | α=`coach_scout_alpha`(0.32)、値=`obs_skill` | 0.70旧+0.30 `obs_skill` |
| 試合(match) | `coach_match_observation`(新人が先発した試合のみ) | 混合率`coach_match_skill_blend`(0.18)、値=`rating_obs` | α=`coach_match_alpha`(0.35)、値=`rating_obs` |

初期値は`YOUTH_PRIOR`(0.5, 0.5)。更新は`clamp(…, 0.10, 0.98)`と`round6`(simと同じ)。

## 方法

1. **頻度(数える)**: 新人ごとに、窓内および窓の3区間(1〜7、8〜14、15〜21日)の観察数を種類別に数える。比較対象=同じクラブ・同じ窓の**新人以外の在籍選手**(入団日にロスターにいた他の選手)の1人あたり平均の観察数。さらに、窓内に一度でも先発した新人と一度も先発しなかった新人に分ける(試合の観察は先発の結果として生じる)。
2. **再生(オフライン)**: 新人の技能推定・試合評価推定を、記録された観察値(上表)と初期値から、イベントの記録順に再生する。各`lineup_decision`で、再生値から`round6(select_weight×推定)`が記録された`skill_term`・`match_term`と**完全一致**することを検査する(違えば失格)。また`coach_session_observation`・`coach_scout_observation`に記録された更新後の技能推定とも一致を検査する。
3. **誤差の3項分解(正確。各行・各推定で)**: 行の日Lの再生推定 ê と真の技能 T_L(日Lの終わり)の差 e=ê−T_L を、 e = P(ê_0−T_L) + Σ w_i(T_i−T_L) + Σ w_i(o_i−T_i) + r とする。ここで ê_0=0.5(事前値)、i はL以前の観察、a_i はその観察の更新率、P=Π(1−a_i)、w_i=a_i Π_{j>i}(1−a_j)、o_i は観察値、T_i は観察日の終わりの真の技能。3項= **事前値の残り**(P(ê_0−T_L))、**成長への遅れ**(Σw_i(T_i−T_L)、観察後に真の技能が動いた分)、**観察値のずれ**(Σw_i(o_i−T_i)、雑音と、試合ではほぼ加点)。r=丸めとclampの残差で、|r|≤1e-4を全行で検査(定義上 e=3項+r は恒等)。区間(1〜7、8〜14、15〜21日)別の平均を報告する。
4. **反実仮想の再生(新人自身の推定のみ入れ替え。他の選手の記録値と疲労は固定)**: 窓内の観察の「回数」と「1回あたりの更新量」を別々に動かす。追加観察の値は、simが実際に観察したなら出したはずの値 `clamp(T_d + (uniform_from_key(seed,d,"coach_obs",f"{coach}:{pid}")−0.5)×2×coach_noise, 0.10, 0.98)`(T_dはその日の終わりの真の技能)。追加は練習日の観察の扱い(上表)で、記録順では当日の`lineup_decision`より前に置く。
   - **F+(頻度を足す)**: 窓の3区間のそれぞれで、記録された練習日観察のない最初の日に1回ずつ観察を追加(最大+3回、区間に空き日がなければ追加しない)。追加回数をn_addとする。
   - **U+(更新量を上げる、同じ追加量)**: 記録された観察の回数・値は変えず、全観察の更新率(技能・試合評価とも)をs倍(上限1)。s = 1 + n_add×0.36 / Σ(窓内の記録された観察の技能側の更新率)。つまりF+と**同じ名目の更新量(技能側のΣα)**を足す。n_add=0または観察ゼロの新人は両方とも変更なし。
   - **F-max(頻度の上限)**: 窓の全日(記録された練習日観察のない日)に練習日観察を追加。
   - **U-max(更新量の上限)**: 全観察の更新率を1(推定=直近の観察値)。
   指標: 行ごとの推定誤差(再生 ê−T_L)を区間別に平均し、記録された誤差に対する**遅れの縮小率**(反実仮想の平均誤差−記録の平均誤差)/(−記録の平均誤差)、および先発の反転率(新人の得点だけを再計算し、他の選手の記録された得点でTop2を選び直す。T033と同じ同点規則)を、実際に先発しなかった行と見逃し行(その日ロスター内で真に上位2人)で報告する。技能推定と試合評価推定は別々に報告する。
5. 補助(記述): 窓内の観察の合計数と新人の最終推定誤差の関係、設定別・開始年齢別。

## 予測(反証され得る。事前の信頼を併記)

- **P1a(頻度の差)**: 窓内の自クラブの監督の観察の合計数は、新人のほうが新人以外の1人あたりより少ない(3設定とも)。信頼約85%(新人以外は先発が多く、試合の観察が多い)。
- **P1b(差の出どころ)**: 練習日観察の1人あたり回数は新人と新人以外で近く(新人/新人以外が0.8〜1.25)、差は試合の観察から来る。信頼約50%。
- **P2(新人の観察の構造)**: 窓内に一度も先発しなかった新人は、先発した新人より窓内の観察の合計が3割以上少ない(3設定とも)。信頼約85%(試合の観察は先発のときだけ)。
- **P3(誤差の出どころ)**: 15〜21日区間の技能推定の誤差で、3項のうち絶対値が最大なのは**成長への遅れ**(事前値の残りより大きい)。1〜7日区間では事前値の残りのほうが成長への遅れより大きい。3設定とも。信頼約50%。
- **P4(頻度か更新量か。同じ追加量で比較)**: 15〜21日区間の技能推定の遅れの縮小率で、F+がU+を上回る(3設定とも)。信頼約55%(観察を足すと新しい値が入り、更新量を上げるだけでは古い値の重みが増える)。
- **P5(上限)**: F-max(毎日の練習日観察)は15〜21日区間の技能推定の遅れの70%以上を縮小する(3設定とも)。信頼約60%(遅れが観察不足のせいなら、毎日見れば消える)。
- **P6(先発への効き)**: 見逃し行で、F+とU+のうち反転率の高いほうが15%以上(3設定とも)。F-maxは40%以上。信頼約55%。
- **P7(構造)**: 再生ゲート(3)の不一致は0件。信頼約99%。

## 限界

反実仮想の追加観察は「simが同じ式でその日に観察したなら出す値」で、実際には監督の2枠は他の行動(提案・偵察・休み)と競合するため、観察を増やすと他の選手の観察が減る(本分析は新人自身の推定だけを見て、他の選手の推定は記録値のまま。選考を変えれば履歴が変わる=再シミュレーションではない)。追加観察の真値T_dは日の終わりの値(練習直後との差は試合の経験成長ぶんだけ)。試合の観察値には加点が入り、技能推定・試合評価推定は同じ尺度でない。窓の終わりまで先発しない新人は試合の観察がなく、頻度と先発は結果で絡む。行は新人×試合日で、同じ新人の行は独立ではなく、3seedも独立でない。次の一手は候補で実装しない。
