# T038 結果 — 平均の補正が先発の的確さを動かす機構(観察の新しさ別、分析のみ)

実施: 2026-11-11。契約: [T038](../tasks/T038.md)、事前条件: [PROTOCOL](T038-PROTOCOL.md)、判断: [D053](../DECISIONS.md)。`soccer_sim/`は凍結T037 source_bundleとバイト一致(config追加なし、既定は`legacy`のまま)。T037と同じ3設定×84セル×168日を`legacy`/`shifted_v1`/`centered_v1`で再演(756実行、`lineup_decision`24,192件/群)。実行: `uv run --python 3.13.3 python -B experiments/t038.py --out artifacts/t038/run`(約10分)。

## 結論(平易に)

1. **仮説「観察された(新しい)選手だけが下がり、古い選手との順位がゆがむ」は支持されなかった。** 登録した予測P2〜P6は5つとも反証。平均を直しても、経過日数別の誤差の勾配はほとんど変わらない(古い−新しい: legacy −0.0789、shifted −0.0780)。
2. **経過日数の効果の大半は「選抜の産物」。** 古い(14日以上観察されていない)選手は、監督が低く見て先発から外し続けた選手で、推定は真の技能より約0.07〜0.08低い(「控えの罠」: 外すので観察が増えず、低い推定が残る)。真に上なのに古い側の対の順位は、legacyで15%しか正しくない。これは3群とも同じで、平均の補正はほぼ変えない。
3. **平均の補正が変えるのは別の所。** 技能推定の誤差の変化(shifted−legacy)は、前の試合に出ていない選手(a≤6: +0.0103、a=8〜13: +0.0124)で大きく、前の試合に出た選手(a=7)では+0.0021しかない。試合評価の観察は更新の重みが違うため、出ている選手の推定は雑音の平均の影響を受けにくい。結果として控えの選手の推定が出場者より相対的に約+0.01上がり、真に上の控えの選手の順位が15.1%→21.8%正しくなる(+6.7pt、95%区間+5.4〜+8.3)。これは**事後に見た観察パターンで、機構の検証ではない**。
4. **同じ状態で経過日数別の差を引く反実仮想(P5)は悪化した(−7.8pt)。** 経過日数別の誤差は、推定そのものを使った選抜で作られるので、補正に使うと逆効果になる。静的な順位のゆがみの補正では利得を再現できない。
5. **推奨(登録の判断規則)は「保留」。** 機構が経過日数では説明できない。ただし結果の指標(先発+8.7pt、MAE、最終技能)の利得はT036/T037のまま。詳細は末尾。

## 正直な注記(解析の自由度を含む)

- **1回目の実行は評価の集計で例外で止まった。** 原因は、設定別の評価で古い区分が空(t031・t032)だったこと。私はこの時点で「古い区分が実質空」とPROTOCOLの追記に書いたが、これは**誤りだった**(プールではt030の2,471行がある)。そのため「P2〜P4は判定不能」という追記の方針は取り下げ、プールの結果で登録どおりに判定した(上の表)。追記と1回目のログ(`artifacts/t038/run-log-attempt1.txt`)は残してある。結果の数値は2回目の実行まで見ていない。
- **事後(post hoc)の指標を足した**: 前の試合で控え(a 8〜13)−出た(a=7)の誤差差と、1日以上の差の対の正答率の差。1回目の失敗後、結果を見る前に追加したが、解析の自由度が増えている。判断規則には使っていない。上の結論3は事後のパターンの観察であり、因果の検証ではない。
- 群の履歴は雑音の違いで分岐するので、群間の差は「雑音を変えた世界の値」の比較で因果の推定ではない。反実仮想は同じ状態の再順位付けで、監督の将来の行動の変化を含まない。
- 経過日数別の誤差は、推定そのものを使った選抜(出場/控え)の結果として作られるので、母集団の違いと誤差の違いが混ざる(経過日数が「原因」とは言えない)。
- ロスターは3人で、「先発2人」の判定は実質1人を除く問題。世界は3seedを共有し独立でないので区間は過小の可能性がある。t030が古い区分を支配する。
- 補正は区分平均(5区分)のみ。選手個別・時間依存の補正は試していない。

## 既定を`centered_v1`にする提案の推奨(提案のみ。既定は変えない)

登録の判断規則: 「推奨」はP5支持かつP2〜P4のうち2つ以上、「条件つき」はP5が+1.5〜+3.5ptまたはP2〜P4の2つ以上、それ以外は「保留」。P5は−7.8pt、P2〜P4は0/3支持なので、**規則では「保留」**。

読み方: 「保留」は「centered_v1が悪い」ではない。T036/T037の結果の指標(先発の一致+8.7pt、技能推定MAE、最終技能+0.0057、信頼+0.0050)の利得と、新人以外の試合評価推定の偏りの小さな悪化(+0.0030)のみという事実は変わらない。足りないのは**利得の機構の説明**。本taskは「新しさの偏り」を機構の候補から外し、代わりに「出場者は試合評価の観察で推定がほぼ固定され、控えは練習の観察の雑音の平均に直接動かされる」という事後の観察を得た。これが利得の主因かは未検証。したがって: **既定の移行提案は、この出場/控えの機構の検証(T039)の後に行うのが妥当**。移行には凍結成果物(T018以降の基準)の置換・再基準化が伴う。
