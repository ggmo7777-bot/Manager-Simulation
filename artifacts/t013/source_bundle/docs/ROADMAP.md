## 最小環境を2段階に分ける

**今回のT001:** 選手2人・監督1人・28日。真値と推定、時間予算、練習/休息の選択、指示への反応、A/B、ログ、保存再開を確認する。試合・キャリア・動的信頼は未対象。この段階だけで最終構想の成立を宣言しない。

**最初のVertical Slice（VS1）の提案:** 監督2人、選手8人、2クラブ、各クラブ3人出場＋1人控え、3シーズン相当。試験用カレンダーは1シーズン120日を仮置きする。現実のサッカーの年間日程/人体の成熟速度ではなく、比較のためのゲーム内単位である。

VS1は次の循環を通す。

`監督の観察/提案 → 選手の受諾/代替行動/休息 → A/Bの更新 → 小規模競技 → 監督の評価/選考 → 次の学習機会 → 希望/交渉/成立した場合の所属変更`

全員が同じ回数練習する条件、同じ能力のまま経験だけ違う条件、監督を交換する条件を作れるようにする。個人別に選択・経験・評価・出場・所属を記録する。移籍や対立の発生数を成功基準にせず、成立した/しなかった理由と条件への感度を検証する。

リーグ全体、昇降格、複雑な通貨、世代交代、NNをVS1の前提にしない。2D競技はM3で独立に検査してからM4で育成へ接続する。初期の能力課題だけで空間戦術の効果を証明したことにしない。

## 段階と順序の理由

| 段階 | 最小追加 | 順序の理由 | 次へ進む成功条件 | 停止・修正する失敗条件 |
|---|---|---|---|---|
| M0 調査/設計 | 憲章、仮説、境界、プロトコル | 目的と実装の都合を混同しない | 既存状態と未決点が明記、最小タスクが検証可能 | 不明な前提を事実として固定 |
| M1/T001 育成核 | 1監督2選手、A/B、予算、履歴、保存 | 全拡張がこの因果と継続性に依存 | 非漏洩、個体差/経験介入、連続/再開一致、不正状態0 | 真値をPolicyが読む、ノイズしか差を生まない、再開で結果変化 |
| M1補足/T002 認識の効果を分離 | 方法期待/自己推定/監督評価/観察時点を独立に固定する比較 | T001で全B停止が監督配分まで変えると判明したため | 更新の独立性、旧基準維持、負の対照、対応差、偏り/順序の測定 | 複数更新の停止を個人学習の直接効果と呼ぶ、比較に別ルール変更を混ぜる |
| M2 認識と関係 | 有向信頼の更新、観察の不確実性/鮮度、限られた指導枠、2監督 | 評価/機会の差を競技の複雑さから分離 | 同じ成績でも異なる根拠/価値で評価が変わり、更新理由を追跡 | 拒否→罰が固定、信頼の効果が常に支配、永久の誤認しかない |
| M3 競技核 | 2D少人数、局所観測、パス/移動/シュート、headless | 能力と独立判断が実際の結果に作用するか先に検査 | 技能・位置取り・指示理解に測定可能な効果、ルール不変条件合格 | 試合結果が事前能力の抽選だけ、監督が全操作、単一動作の悪用 |
| M4/VS1 閉ループ | M2とM3統合、選考、簡単な合意契約、3試験シーズン | 学習→出場→評価→経験→選択の連鎖を検査 | 介入で出場/成長/所属経路に影響、全重要遷移に根拠、resume一致 | 原因不明な分岐、固定イベント移籍、勝敗だけで人格/技能が変化 |
| M5 小規模世界 | 4–8クラブ、日程、順位、育成組織、有限台帳 | VS1が成立した後に競争と供給を拡張 | 資金保存、契約/枠整合、育成側の成果帰属、複数方針を比較可能 | 無限金策、二重所属/二重報酬、単一方針が資源と成果を永続独占 |
| M6 世代と知識伝播 | 成熟/衰退/引退/新人、育成方法研究、知識の移動 | 長期変化の機構を一つずつ追加 | 複数世代でも人口/資金/履歴整合、方針の環境依存性を測れる | 新人枯渇/爆増、永遠の最強世代、全員への瞬間知識共有 |
| M7 Cの比較 | bandit、小型NN、Adapter、独立Policy | A/B基準と競技/人生指標がないとCの価値を判定できない | 同等計算予算で独立性/説明/適応に増分、保存可能 | 勝率だけ上がり個体差/追跡性が消える、費用超過、経験漏洩 |
| M8 高精度化/表示 | 必要部分の3D、リプレイ、記事/系譜表示 | 既存履歴を観察する価値が生じてから | 旧結果を監査でき、追加精度の価値が測れる | 表示変更で世界が変わる、生成記事が事実化、再現性の破壊 |

M7は固定した末尾順序ではない。M3/M4のPolicy表現が不足すると実験で分かれば、小型Cの比較を先に行う。世界全体への導入はA/B baselineとの対照を維持して判断する。

## 段階別の比較実験

| 段階 | 比較・介入 | 主な測定 |
|---|---|---|
| M1 | 同じ素材/時間、rateのみ交換、均質化、B停止、ノイズ0、信頼だけ変更、潜在値だけ変更、14+14再開 | gain、行動、助言採用、推定誤差、参照の完全性、時間/サイズ |
| M2 | 観察予算少/多、古い/新しい報告、誤った助言、能力信頼/約束信頼の分離、信頼更新なし | 評価誤差、回復時間、指導配分、信頼と行動の感度 |
| M3 | 位置/技能/Policyを別々に交換、監督指示あり/なし、局所観測/oracle、固定相手/相互適応、side反転 | 成功パス、位置取り、期待得点等の競技量、行動様式、命令採用、違反/費用 |
| M4 | 同じ初期集団で監督/教材/信頼/選考機会を変更、契約交渉無効、記憶無効 | 出場機会、経験量、技能軌跡、所属期間、キャリア距離、本人の満足と監督評価 |
| M5 | 固定資金/明示流入、育成報酬なし/あり、独占的/協調的/攻略Policy | 資金収支、破綻、集中度、出場/育成機会、取引循環、方針の優位の持続 |
| M6 | 世代交代なし/あり、知識伝播なし/費用あり/完全共有、成熟曲線の候補 | 年齢構成、選手供給、戦術分布、方針の興隆/衰退、世代間転移 |
| M7 | 共有＋個人状態、Adapter、独立小型Policy、必要ならHypernetwork、学習停止 | 勝率以外のM1–M6指標、適応、忘却、個体の同質化、学習費用 |
| M8 | 同じ履歴の描画有/無、2D/高精度競技、LLM記述/機械的事実一覧 | 状態一致、再生整合、記事の根拠率、追加精度の説明力と費用 |

oracleは情報差の効果を見る研究者用対照であり、通常エージェントに真値を渡す許可ではない。

## 評価を1つのスコアに潰さない

| 軸 | 最初に使う指標 | 誤解を避ける対照 |
|---|---|---|
| 選択の多様性 | 状態条件付き行動割合、個体間の行動差 | ノイズのみ、価値/記憶均質化、ID交換 |
| 成長の個人差 | 同条件の学習gain、技能軌跡の距離 | rateのみ交換、同方法/時間、初期能力固定 |
| 経験の効果 | 同じ過去snapshotから履歴/情報を分岐した後の行動差 | B停止、記憶入替、Policy固定 |
| キャリア | 出場、役割、所属、経験機会の系列 | 能力固定、監督/環境交換、情報条件固定 |
| 関係と認識 | 介入に対する選考/交渉の変化、推定の校正 | 真値は固定、信頼/観測だけ変更 |
| 戦術の進化 | 行動様式の分布、対抗策の出現、優位性の持続 | 固定相手、学習/伝播停止、構成員交換 |
| 世界の安定 | 人口/資金/所属の不変条件、吸収状態、世代更新 | 外部流入なし、攻略Policy、係数の感度 |
| 説明と再現 | 重要遷移の根拠参照率、非漏洩、snapshot再開一致 | 保存頻度、ログ有無、異なる順序の比較 |
| 費用 | agent-day/秒、match-step/秒、bytes/日、メモリ/学習時間 | 描画なし、ログ粒度、同等CPU予算 |

高い行動entropyだけでは、ランダムな選択と意味のある独立判断を区別できない。高い多様性を直接報酬にして珍奇行動を量産することもしない。

同一の完全な初期状態・Seed・入力なら同じ結果になるのが正しい。同じ「観測された能力」から異なる結果になる場合、隠れた特性か途中の経験/選択/外生事象のどれが違ったかを示す。

## 実験の運用

探索seedと確認seedを分ける。比較は同じ初期集団と外生乱数キーを用い、変更した変数をmanifestに記録する。多くの試合を同一世界から得ても、独立標本数を試合数とみなさない。世界seed/初期集団を独立な単位として対応差と区間を報告する。

最初は機構確認の不変条件と小さな介入を優先する。一般化は、初期集団、価値分布、教材、費用、相手Policyを変えた確認セットで検査する。計算時間や通貨等の具体的な上限は実測基準が得られた段階で設定する。未測定の「数百万選手まで対応」を掲げない。

各段階の最後に、仮説ごとに「支持/反証/判定不能/未実施」を記録し、設計維持または修正を選ぶ。次段階の開始は前段階の全機能の完成ではなく、次の実験に必要な境界が検査済みかで決める。
