## メモリ・保存の補測

新しいPythonプロセスで1000日を実行し、snapshotの保存/読み込みを測定した。元世界と読み込んだ世界の状態・eventが一致した。

| 項目 | 実測 |
|---|---:|
| シミュレーション本体 | 0.24764秒 |
| snapshot書込み（fsync/置換を含む） | 0.13917秒 |
| snapshot読込み/検証 | 0.26998秒 |
| プロセス最大RSS | 131,661,824 bytes（約125.6 MiB） |

最大RSSにはPython、import、全履歴、JSON変換、元と復元後の世界の同時保持を含む。シミュレーターの常駐状態だけを測った数値ではない。単一端末/1試行の測定で、速度保証や大人数への外挿をしない。C未実装のためNN学習費用は対象外。チップ/物理メモリ容量は未取得。

[実測の条件と数値](../../artifacts/t001/review/performance.json)。一時的な計測用snapshotは削除し、同じ条件の正式な1000日成果物を保管している。

## 判定

T001の機構確認と保存再開の受入条件は満たした。ただし、全B停止の作用は複合的、監督休息は発生せず、同点処理は候補順依存、観測gainの切り詰めは偏りの候補である。これを隠して世界全体の妥当性としない。
