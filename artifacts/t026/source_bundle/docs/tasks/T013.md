# T013 — 疲労観測と実際の請求・オファー受付の修正

登録: 2026-11-08。状態: 実装・検証完了。担当: Codex（Solの利用上限後の引継ぎ）。ユーザーの外部レビューへの対応。

## 最小範囲

1. 疲労の真値を自己・監督・スカウトの認識へ直結しない。観測者/対象/日/場面別の測定を生成し、観測記録からBを更新する。観測しない控え選手の監督評価は保持する。
2. 通常と攻撃的な再送が同じ配当請求処理を通る。受理/拒否の根拠、請求、支払を記録し、実支払履歴から重複の有無を独立監査する。循環移籍も実オファー受付で拒否する。
3. 放出/獲得/移籍希望のPolicyを本人のMindだけを受け取る純粋関数に分離する。世界側の合意調整には複数主体の結果が集まるが、他者のMindを各Policyへ渡さない。

## 受入条件

- 通常ノイズ設定で全観測経路を検査。観測を固定して真値を変えたPolicy不変性、控え監督の評価保持、日/観測者別再現性。
- 同じ請求を実際に2回送信し、支払1回・上限消費1回・2回目拒否。残高不足/上限/偽の試合/別の請求者を拒否。攻撃実験の拒否数は要求/解決イベントから再計算。
- 主体別Policyの入力境界と独立性。無効な台帳入力は残高変更前に拒否。
- 全既存テスト、7経済条件×確認30seed×84日、独立整数監査、4主条件保存再開を実行。
- 修正済みルール上でT012の5分岐×40seed（200系列）、no-op、1000日+再開を検証する。過去版と数値一致を成功条件にしない。
