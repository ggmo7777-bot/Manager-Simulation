# T039 — 出場者と控えで観察雑音の平均はどう効くか(チャネル別の伝播と先発一致の分解、分析のみ)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件を固定)。状態: 完了(結果: docs/experiments/T039-RESULTS.md)。ブランチt039はt038から積む(PR #20、#22が先にマージされる前提)。[事前条件](../experiments/T039-PROTOCOL.md)、判断: D054。担当: Claude Sonnet 5.5。

## 問題

T038は、T037の仮説「観察された(新しい)選手だけが下がる」を反証した。ただし事後に、平均の補正が前の試合に出ていない選手の技能推定を+0.010〜+0.012、出場者を+0.002しか動かさず、真に上の控えの対の正答率が15.1%→21.8%になることを見た。これは機構の検証ではなく、群の構成(誰が出場者になるか)が群間で変わる影響も混ざる。出場者と控えでは、推定を動かす観察チャネル(試合・練習・偵察)が違う。本taskはこれを事前登録の下で調べ、centered_v1の先発一致の利得のうち「同じ観察の列で雑音の平均だけを除いた静的な効果」がどれだけかを分解する。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。** 凍結T030/T031/T032設定×84セル×168日を、既存の`legacy`/`shifted_v1`/`centered_v1`の3群で再演する(756実行、T037/T038と同一)。記録済みの観察イベントから各監督の各選手の技能・試合評価・疲労の推定を研究者が再生し(sim結果と一致をゲートで確認)、`legacy`の履歴について、同じ観察の列のまま観察雑音の平均だけを除いた推定(shifted_v1と同じ+幅のオフセット)を、チャネル別(練習/試合/偵察)に並行して持つ。`lineup_decision`ごとに、前の試合の出場者/控え/新規在籍の群別に測る:

1. 各群が受けた観察チャネルの件数
2. 平均のずれがチャネル別に推定へどう伝わるか(技能・試合評価・疲労・総合点)
3. 同じ状態でオフセットを除いて再順位付けした先発一致の変化(チャネル別・成分別・群別の分解、区間つき)
4. 動的な利得(shifted/centeredの実走)に対する静的な効果の割合

最後に、centered_v1を既定にする提案の推奨を、登録した規則で書く(推奨のみ。既定は変えない)。

- 対象外: `soccer_sim/`の変更、新しいconfig、既定の変更、幅の調整、観察の配分や移籍判断の変更、第4の隅の実行、CLI/UI。戻し方: `experiments/t039.py`、`tests/test_t039.py`、`artifacts/t039/`、文書の削除のみ。
