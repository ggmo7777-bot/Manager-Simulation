# T017 — sampled集団を通常CLIへ接続

2026-11-09、実装前登録。状態: 実装・検証完了。ユーザーの「次に進んでください」に基づく最小タスク。実装Sol 6.1 High、設計・独立検証Codex。

## 契約

`python3 -B -m soccer_sim run --condition league_open_solidarity_sampled_population ...`で、既存の生成集団を起動できるようにする。現在はPython API/専用実験だけが受け付ける。

- 既存リーグ7条件それぞれへ`_sampled_population`を付けた7条件をCLIに追加する。`league_`接頭辞を含め既存の命名を維持。
- CLI内のリーグ条件辞書で登録し、choicesと実行先の判定が同じ辞書を使う。設定の構築は既存`config_for_condition`に委ねる。
- 固定条件、既定のbaseline、他世界の条件とT011実験の条件集合を維持する。別のpopulationオプションや未知条件の推測は追加しない。
- resume/branchはsnapshot内のpopulation_modeを使う。母集団を起動オプションで読み替えない。
- 進行・Policy・評価・保存schema・初期分布は維持。save16/T015ルール/T016評価のまま。package hashはCLIの変更でも変わるため、旧snapshotはT016凍結ソースで読む。hash分離や自動移行は今回行わない。

## 事前検証条件

1. 7つのsampled条件と7つのfixed条件をseed100、35日でCLIから起動し、同条件のAPIとsnapshot/events/summaryを照合。T016凍結APIとの全状態・履歴・評価はidentityとsnapshot由来hashのみを除外して照合する。
2. sampled open_solidarityの14日checkpointをCLI resumeで35日へ進め、直接35日と一致。14日から信頼を変えるCLI branch、分岐のresumeをAPIと照合。親データが不変であることを確認。
3. helpに全条件が載ること、非リーグsampled/未知名/重複接尾辞をexit2で拒否して出力を作らないことを検査。既定baselineと明示baselineを照合する。
4. T016の旧snapshotがsource hash違いとして拒否され、旧出力に変更がないことを確認。旧成果物inventoryも照合。
5. CLI統合テストと全unittestを実行。起動接続の検証なので新たな多seed頑健性や1000日試験は行わない。CLI以外のpackageファイルが凍結T016と同じであることを検査。
