# T005: 監督が有料の観察から方法の効果を学ぶ

状態: **実装・検証完了**。2026-11-05の「進めて」により着手。[事前プロトコル](../experiments/T005-PROTOCOL.md)に沿って60テスト、240run、保存再開、旧設定240本と観察のみ120本の旧版照合を完了。[結果](../experiments/T005-RESULTS.md) / [主担当確認](../experiments/T005-REVIEW.md)。

## 問題と最小仮説

選手の自己予測と信頼は経験で変化するが、監督の方法別主観率は0.10の固定値である。監督も時間を払って練習結果を観察し、誤りうる予測を更新できるようにする。目的は監督を常に正しくすることではなく、知識を得る機会とその使い方の違いが選手の経験へ戻る経路を作ること。

## 最小の実装範囲

- 1監督2選手、既存の2方法と日予算を維持。監督が観察に時間を割いた場合だけ、自分の前後の観測から方法と観測差の組を得る。選手の私的信号・自己G・真の成長・潜在率/上限を読み取らない。
- 監督の個体×方法の予測を小さく更新し、次の提案の予想gainへ使う。初回は方法選択の採点まで同時に変更せず、予測→選手の評価経験→信頼→後の選択という作用を分ける。
- 同じ観察費用と同じ情報取得を持つ「予測更新OFF/ON」を対照にする。観察機会を固定した機構検査と、監督が自分で観察対象を選ぶ閉ループ比較を区別する。
- 監督の予測の出所・事前値・観測・更新・提案への利用を記録し、保存再開する。

## Sol 6.1 Highへの作業契約

最初に既存コード・T004結果とREVIEW・本タスク・Protocolを読む。既存artifactと凍結ソースを変更しない。新しい設定と保存版を明示し、予測の基準値/補正/最終値と根拠を記録する。予測補正の学習関数には主観的な前後観測・観察した実施方法・行動前の基準予測/補正だけを渡す。Worldや選手の私的信念を渡さない。

通常の既定では前後観察/予測更新とも無効。比較用CLI条件で有効化する。監督の行動採点と選手の即時採点は変更せず、予測は従来の信頼更新を経由して後の行動へ作用する。夕方の学習を当日の提案へ遡って適用しない。実装・必要テスト・240run・保存再開・旧版照合・結果報告までを今回の範囲とする。

## 成功・失敗条件

成功は、費用と観察の経路を守り、同じ真値でも異なる観察経験で監督の予測が分かれ、その予測が次の提案に使われること。真値だけを変えて同じ観測を与えた時点では更新が変わらず、未来の未実施結果を使わない。更新停止で従来の予測を保持し、旧結果保全と保存再開を確認する。

予測精度、提案の採用、実施機会、信頼、選手の成長を別々に測る。精度やgainの増加は必須の合格条件にしない。全監督へ知識を自動配布する、観察無料化、拒否への自動罰、誤予測を真値から修正する設計になったら修正する。

複数監督、選考、契約/移籍、競技、C、教材生成は同時に作らない。この監督知識の経路を確認した後にM2の複数監督、M3の競技核、M4の小さなキャリア循環へ接続する。
