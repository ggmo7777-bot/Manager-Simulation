# T032 結果 — 練習日の観察を監督の試合評価推定へ反映する(T031の「観察されたのに先発しない」仮説の検証)

実装・実験: 2026-11-10。契約: [T032](../tasks/T032.md)、事前条件: [PROTOCOL](T032-PROTOCOL.md)、判断: [D047](../DECISIONS.md)。規則・係数(0.70/0.30)・条件・閾値は実装前にコミットし、結果後に変えていない。補正はA1の1件のみ(隔離ゲートの設計、実装時・結果前)。Python 3.13.3(uv)、macOS arm64。**0.70/0.30は偵察観察の直書き定数の再利用で未校正。**

## 結論

- `LeagueEconomyConfig.coach_practice_rating`(`"none"`既定、`"blend_v1"`)を追加した。有効時のみ、`_step_training_day`の監督のセッション観察が`match_rating_estimate ← clamp(0.70×旧 + 0.30×その日の観察された技能, 0.10, 0.98)`を行い、イベント`coach_session_observation`に更新後の値を記録する。入力は監督のB層の値とその日のノイズ込み観察値のみ。真値の直接参照・乱数・新しいworldフィールドはない。
- **仮説は反証された。** 「練習日の観察が試合評価推定を更新しないことが、観察された新人が先発しない原因」ではなかった。機構は働いた(P1支持)が、先発した新人の割合は**減った**(P2反証)。
  - P1(新人の試合評価推定誤差が減る)**支持**: 0.0894 → 0.0858、84セル中75セルで有効のほうが小さい。
  - P2(先発した新人 +0.03以上)**反証**: 0.640 → 0.619(**−0.021**)。S=29で0.611→0.567、S=33で0.669→0.671。
  - P3(真に上位2人の新人の先発 +0.03以上)**反証**: 0.740 → 0.707(−0.033)。才能の見逃し(上位2人で先発しなかった新人)は143人 → 163人に**増えた**。
  - P4(費用)事前登録の線(技能−0.005、信頼−0.010、満足度−0.010)は**超えなかった**。技能+0.0003(平均は正、ただし84セル中59が負で符号検定p=0.0003。小さい差で、平均を押し上げる少数の大きな正のセルがある)、信頼−0.0007(有意でない)、満足度**+0.031**(84中75セルで増)、先発の真の平均技能+0.0020、移籍−0.12件。
- 事前に懸念した副作用は出た: 先発の入れ替わり(試合日あたり、前試合日と異なる先発の人数)が0.219 → 0.285に増えた(68/78セルで増)。
- 解釈(**仮説。分解は未実施**): 新人の試合評価推定は0.5から始まるが、新人(アカデミー型の真の技能は約0.47〜)の観察された技能は多くの場合それより低く、混合で推定が下がる。つまり「推定が正しくなる」ことが新人の先発を減らす方向に働いた可能性がある。一方、先発の選手は試合の加点を含む評価を持ち、練習の観察(技能そのもの)との混合で引き寄せられ、入れ替わりが増えた可能性がある。いずれも検証していない。
- 注意: 練習日の観察は監督の枠が「観察」を選んだときだけ起きる(枠の約5.5%、1世界あたり約60回)。機構が及ぶ組は少なく、それでも先発・満足度に有意な差が出た。

## 限界

- 0.70/0.30は未校正。練習日の観察は技能そのもので、試合評価(得点・守備の加点を含む)とは意味が異なる。混合は尺度をそろえる近似に過ぎない。
- 技能の差は小さく、符号検定は多数のセルで負でも平均は正(分布が偏る)。「費用なし」とも「便益あり」とも書かない。満足度の増加(+0.031)と入れ替わりの増加の関係は未分解(出場機会が広がった可能性は検証していない)。
- 3seedはセル間で独立ではなく、符号検定は参考値。8年度は現実の期間ではない。信頼readerは設定改ざんを受理する(T022の既知の限界)。
- 新人以外の選手への効果は分離していない(練習日の観察は全選手に効く)。先発が増えない理由(新人の真の技能が低いか、推定の正確さが先発を減らすか)は検証していない。
