# T041 結果 — 選手側の自己観察の経路は利得を運ぶか(選手の意思決定の介入分解、分析のみ)

実施: 2026-11-11。契約: [T041](../tasks/T041.md)、事前条件: [PROTOCOL](T041-PROTOCOL.md)、判断: [D056](../DECISIONS.md)。`soccer_sim/`は凍結T037 source_bundleとバイト一致(config追加なし、既定は`legacy`のまま)。T037〜T040と同じ3設定×84セル×168日で、12腕(順方向6・逆方向6)を実行(3,024実行、ゲート用の素のcentered_v1を252加えた)。実行: `uv run --python 3.13.3 python -B experiments/t041.py --out artifacts/t041/run`(約17分、8プロセス、`artifacts/t041/run-log.txt`)。全実行は1回だけ(失敗した全実行はなし)。

## 結論(平易に)

1. **利得は選手の練習の選択(休養か練習か、どの方法か)が運ぶ。** centered_v1の先発一致の利得D = +8.68pt [+7.35, +9.95](T039・T040と同一)に対し、練習の選択の判断だけをもう一方の方式の自己観察に差し替えると、順方向(legacyの世界にcentered状態)で+9.83pt [+8.57, +10.98](f = 1.13)、逆方向(centered_v1の世界にlegacy状態)で+8.10pt [+6.86, +9.30](r = 0.93)。**十分でも必要でもある。** 登録の帰属規則の判定は **`single_route(practice)`**(3設定とも同じ)。選手の3つの判断を全部差し替えた`pall`はf = 1.05 [0.96, 1.16]、r = 0.98 [0.89, 1.07]。助言への応答(F = 0.00、R = −1.74)と移籍(−0.02、−0.09)は担い手ではない。
2. **T040の消去法の推論が測定で裏づけられた。** T040は監督の4つの意思決定を全部差し替えても利得は動かない(f = 0.02)と示し、残りは選手側と推論した。本taskの選手側の全3種の差し替えは利得のほぼ全部(f_pall = 1.05)を再現する。監督側を足しても上乗せは有意でない(J_F = −0.43pt [−1.26, +0.34]、J_R = +0.17pt [−0.57, +0.96])。
3. **何が変わるのか(判断と理由コード)。** legacyの世界の選手は、練習日の66.7%を休養し、centered_v1の世界の選手は51.8%しか休養しない(差 −14.9pt [−15.2, −14.7])。練習の選択だけの差し替えでこの差はほぼ全部再現・消去される(順方向−15.0pt、逆方向−14.9pt)。legacyの世界で選手にcentered状態を読ませると、練習の判断の40.7%が変わり、83%が休養と練習の入れ替わりで(うち79%が「休養→練習」)、遷移の大半(73%)は**理由が「休養の既定の選好(`rest:rest_preference`)」から「好きな方法の加点(`method:pref_bonus`)」へ**変わる。centered_v1の世界の選手が実行する理由の分布は、既定の選好による休養が53.2%→31.4%、疲労の知覚による休養が13.6%→20.4%、好みの方法の練習が9.9%→21.7%、期待利得による練習が13.1%→16.6%(legacy→centered)。つまりcenteredの世界の方が、休む理由が「疲れている」という状態に基づく割合が高い。(理由コードは研究者が内訳の最大の正の項に付けたラベルで、選手の内面の報告ではない。)
4. **助言への応答は、単独では先発一致に効かないが、判断と表明理由は大きく動く。** 応答の判断の16.0%が変わる(legacyの世界でcentered状態を読むと。部分従順→従う 44%、拒否→部分従順 16%)。変わった判断の主な理由は「信頼が自律より低い」(68%)から、「信頼が自律より高い」(29%)・「規律性が高い」(27%)・「出場時間への苛立ち」(15%)へ散る。監督が聞く表明理由は、`distrusts_coach` 60.6%→53.6%、`trusts_coach` 14.3%→17.5%、`personal` 25.1%→29.0%(legacy→centered、実行された判断)。ただし先発一致への効果は、順方向でF = 0.00pt、逆方向でR = −1.74pt [−2.43, −1.06](centeredの世界でlegacy状態を読ませると先発一致が**上がる**)で、`harm(response)`の旗が立った。
5. **移籍は動かない。** 移籍の判断(希望の有無・選ぶクラブ)が変わるのは2.1%(94/4,436)で、大半は理由ラベルの付け替えのみ(`stays`のまま`none`→`ambition_x_self_estimate` 70件)。実際に希望が出る割合は19.3%と19.2%で同じ。
6. **既定をcentered_v1にする提案の推奨は、登録の規則で「条件つき」。** Dは有意(下限+7.35pt)、最終技能の差も劣らない(+0.0057 [+0.0039, +0.0075])、最終信頼の差も(+0.0050 [+0.0041, +0.0060])、3設定ともD>0、帰属は`single_route(practice)`でf_pall・r_pallとも0.5を超える。**満たさなかった唯一の条件は`harm`の旗なし**(`harm(response)`: R_response = −1.74pt、区間の上限<0)。旗は設定別にも出る(t030・t031はharm(response)、t032はharm(transfer))。条件は、この旗の解消(応答の判断が、centered_v1の世界で先発一致に負の必要性を持つ理由の同定)。**利得の機構そのものは特定された**ので、残る問いは「それが望ましい振る舞いか」(下記の限界)。

## 既定を`centered_v1`にする提案の推奨(提案のみ。既定は変えない)

登録の判断規則: 「推奨」は、帰属が`single_route`・`multiple_routes`・`distributed`・`partial_single`のいずれか、かつf_pall ≥ 0.5かつr_pall ≥ 0.5、かつ3設定ともD>0、かつ最終技能・最終信頼の差の区間の下限がともに≥0、かつ`harm`なし。結果: Dの下限+7.35pt、最終技能の差の下限+0.0039、最終信頼の差の下限+0.0041、3設定ともD>0、帰属`single_route(practice)`、f_pall 1.05・r_pall 0.98。**`harm(response)`の旗があるため、規則では「条件つき」**。

読み方: 「条件つき」は「利得の担い手は特定できたが、応答の判断が負の必要性を持つ(centeredの世界で応答がlegacy状態を読むと先発一致が上がる)ことを説明できていない」。この旗は応答の判断が先発一致を下げるという意味ではなく、centered状態の応答が、centered状態の練習の選択と組み合わさったとき(I_R +2.24ptの交互作用)に先発一致への効果が下がるという意味に近いが、メカニズムは未検証。移行には凍結成果物(T018以降の基準)の置換・再基準化が伴う。

## 限界・正直な注記

- **何が望ましいかは測っていない。** 利得の担い手は練習の選択だが、legacyの選手は練習日の2/3を休み、centeredの選手は約半分しか休まない。centered_v1の方が先発一致も最終技能も高いが、先発一致の上昇が、より多く練習した結果の技能の広がり(真の上位2人が見分けやすい)を通っているのか、監督の推定の的確さを通っているのかは分けていない(最終技能の差+0.0057は小さい)。性格に基づく選手の判断の多様性を高める方向かどうかは、別の評価が要る。
- **練習の選択は3つの状態を同時に読む**(期待利得・疲労知覚・信頼)。どれが運ぶかは分解していない。legacyでは疲労知覚が平均で約0.025低く、期待利得が約0.006低いことが休養の既定の選好を勝たせている、というのが事前の推論だが、変数別の差し替えは行っていない(T042の候補)。
- 差し替えは判断の瞬間の状態だけで、状態の更新(信頼・期待利得の学習)は世界の方式のまま。altは同じ観察と行動の列を別の雑音で更新した再構成で、実走と同じ履歴ではない。`both`の腕がもう一方の世界と一致するという事後の観察は、判断の入力についてだけ。centered_v1は平均だけでなくばらつきも半分にする(T037)ので、本taskの「centered状態」は両方を含み、平均だけの帰属は対象外。
- 理由コードは記録された内訳の最大の正の項への研究者のラベル(`transfer`は研究者側の再計算)で、選手の内面の説明ではない。「休む理由が疲れているかどうか」という言い方は、このラベルの割合の話。
- 区間はセルの再標本で、世界は3seedを共有し独立でないため過小の可能性がある。Dの区間はT040(seed 40)と点推定は同一だがseedが違うので端がわずかに異なる(+7.35 vs +7.37)。単一の指標(先発一致)への帰属で、ロスターは3人(先発2人、控え1人)。
- 全実行は1回だけで、登録した統計はすべて報告した。事後の指標は上の「事後の観察」の1つのみ(`posthoc_*`)。
