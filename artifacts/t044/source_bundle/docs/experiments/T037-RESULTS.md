# T037 結果 — 平均とばらつきの切り分け(`observation_noise_mode`に対照`shifted_v1`)

実施: 2026-11-11。契約: [T037](../tasks/T037.md)、事前条件: [PROTOCOL](T037-PROTOCOL.md)、判断: [D052](../DECISIONS.md)。方法・定義・予測・分解の定義は実装前にコミットし(PR #20、最初のコミット)、結果後に変えていない。Python 3.13.3(uv)。T033〜T036と同じ3設定×84セル×168日を`legacy`/`centered_v1`/`shifted_v1`の3群で実行(756実行)。**既定は`legacy`のまま。乱数のキー・回数は同じ。**

`shifted_v1`は同じ引き`u`に対し`u×2×幅`(平均0、範囲[−2幅,+2幅]、標準偏差は`legacy`と同じ1.155幅)。厳密に `legacy = shifted_v1 − 幅`、`centered_v1 = shifted_v1 ÷ 2`。したがって legacy→shifted が「ばらつき一定で平均だけ」(B)、shifted→centered が「平均0のままばらつきだけ」(V)で、B+V=T(centered−legacy)。

## 結論(平易に)

1. **仕組みは設計どおり。** ゲート1〜5が通る(下)。`shifted_v1`の観察誤差は平均が0(練習日−0.0015、偵察−0.00002、自己−0.0001)、標準偏差は`legacy`と同じ(比0.998/0.998/1.000)。
2. **T036の改善の大半は「平均の補正」だった(事前の予測と逆)。** 先発が真の上位2人と一致する割合の改善+8.7ptのうち+7.0pt(81%)が、ばらつきを変えない`shifted_v1`で既に得られる(`legacy`62.3%→`shifted`69.3%→`centered`70.9%)。最終技能+0.0057のうち+0.0054(95%)、最終信頼+0.0050のうち+0.0041(82%)、新人の技能推定MAE 0.0606→0.0551のうち0.0049(89%)、新人の15〜21日の誤差−0.1008→−0.0915(`centered`は−0.0911)も同様。
3. **偵察イベントの+17%は平均の補正で説明できる。** 偵察は`legacy`465.5→`shifted`538.5(+15.7%)→`centered`544.1(+16.9%)で、増加の93%が平均側。偵察の選択に`0.16×技能推定`が入るため、推定の水準が上がると偵察が増える(事前の機構の予測どおり)。練習日の観察+8%も同様(平均側が過半で、ばらつきの寄与は区別できない)。
4. **新人以外の技能推定は「ばらつき」と「平均」の混合。** MAEの改善0.0638→0.0575のうち、平均側−0.0025(40%)、ばらつき側−0.0038(60%)。ばらつき一定のままの`shifted_v1`は0.0613で`legacy`よりやや良く、`centered_v1`が最良。平均の補正だけでは偏りが+0.0002→+0.0042に上がり(T035の予測+0.013の約3分の1)、ばらつきの半減が−0.0055戻す(相殺)。
5. **試合評価推定の偏りの悪化(+0.0152→+0.0182)は平均の補正による。** 平均側+0.0072(`shifted`+0.0224)、ばらつき側−0.0042。つまり`legacy`の負の雑音平均が、別の正の偏りを部分的に隠していた。ばらつきを半減すると悪化は縮むが、`legacy`よりは悪い。
6. **判断**: `shifted_v1`は版つきの対照として採用(試用)。**既定は変えない。** 既定の移行判断は別taskだが、材料は揃った: centered_v1は、MAE(新人以外・新人とも)・先発の的確さ・最終技能・信頼のすべてで3群中最良または最良と区別できず、悪化は新人以外の試合評価推定の偏り(+0.0030)に限られる。

## 未説明の点・正直な注記

- **偵察+17%**: 増加の大半(93%)は平均側で、`0.16×技能推定`のスコア項から説明がつく(因果の機構を直接検証したのではなく、3群の差と式の整合)。ばらつき側の+1.2%(5.6件/セル)は区別はできるが小さく、理由は調べていない。
- **先発の的確さが平均で上がる理由は検証していない。** 仮説: `legacy`では観察される選手の推定だけが約−幅下がり、観察されない(古い)選手との相対順位がゆがむ。観察頻度別の推定誤差を見れば検証できるが、本taskでは測っていない。
- **交互作用は同定していない。** 第4の隅(平均−幅でばらつき半分)は実行していないので、B/Vの分けは legacy→shifted→centered の経路依存。逆の経路(ばらつきを先に半減)での寄与は不明。新人以外のMAEのように混合の指標では、割合が経路で変わりうる。
- 試合の観察値`perf_raw`は記録されないので試合観察の誤差は推定の誤差で見た。clamp込みの疲労観察は`shifted_v1`で上限側のclampが増える。
- 行は新人×試合日で独立でなく、3seedも独立でない。ロスターは小さい。
