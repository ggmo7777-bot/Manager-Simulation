# T035 結果 — 観察雑音の中心のずれは設計か不具合か、推定誤差の説明量(分析のみ、simは不変)

実施: 2026-11-11。契約: [T035](../tasks/T035.md)、事前条件: [PROTOCOL](T035-PROTOCOL.md)、判断: [D050](../DECISIONS.md)。方法・定義・予測は実装前にコミットし、結果後に変えていない。Python 3.13.3(uv)。**規則・config・イベント・乱数の追加はなく、`soccer_sim/`はT032/T033と1バイトも違わない。** T034と同じ3設定(T030/T031/T032の有効設定)×84セル×168日。下の数値は特記なき限り3設定の合計(per設定は`artifacts/t035/run/summary.json`)。

## 結論(平易に)

1. **ずれは実在し、大きさは雑音の幅の1倍(平均−noise)。** 記録された全ての観察イベントから、simと同じキーで実現した雑音を再計算した。雑音/幅の平均は練習日−1.020、偵察−1.005、試合−1.013(標準偏差1.17/1.15/1.15)。つまり観察値は平均で練習日−0.024、偵察−0.030、試合−0.019だけ低く出ている。中心化(同じ引きを`u×幅`、[−幅,+幅]の対称一様)にすると平均はほぼ0(−0.010/−0.003/−0.006)。キーの検証は128,451件(練習日11,135・偵察117,316)で不一致0件。
2. **意図ではなく不具合(移植時の取り違え)と判断する。** `uniform_from_key`の既定範囲は[−1,+1]。旧モジュール(selection_loop 9箇所、transfer_loop 11箇所、match_2d)は全て`low=−幅, high=幅`と対称範囲を明示するのに対し、`league_economy.py`の4箇所(自己・監督・偵察・試合の観察)と`league_observation.py`の疲労観察の1箇所だけが、範囲を指定せず`(u−0.5)×2×幅`または`(2u−1)×幅`と書いている。この形は`u∈[0,1]`を前提にしたときだけ対称になる。DESIGN・OPEN-QUESTIONS・RESEARCH・CHARTER・GOVERNANCE・DECISIONS(D049/D050以外)に観察の偏りを意図する記述は無く、`league_observation.py`の注釈は「雑音の幅は仮説。0は完全測定の対照」とだけ書く。導入は全5箇所とも最初のコミット(7361ff3)で、以後変更も議論もされていない。同じ誤りが疲労観察(監督の幅0.045、偵察0.065、試合0.050、自己0.025)にもあるが、本taskでは効果を測っていない。
3. **ずれは新人の遅れの主因ではない。** 技能推定の誤差のうち、ずれで説明されるのは新人行で7.5%(入団後1〜7日0%、8〜14日9.9%、15〜21日8.0%)。全て観察が少ないので、ずれが積もる余地が小さい。15〜21日の誤差は−0.1008が中心化後も−0.0928で残る。**新人と新人以外の誤差の差(−0.059)のうち、ずれが説明する割合は−14%**(符号が逆: 新人は観察が少なく事前値0.5の近くにいるので、ずれの影響は新人のほうが小さく、中心化するとむしろ差が広がる)。
4. **新人以外の誤差はほぼゼロで、中心化すると悪くなる。** 新人以外の技能推定の平均誤差は+0.0002(T030 −0.0046、T031 +0.0027、T032 +0.0024)で、ずれの平均は+0.0127。中心化すると平均誤差は約+0.013(過大)になり、MAEは0.0638→0.0670に増える。つまり新人以外の推定には、雑音のずれ(−0.013分)と同程度の**別の正の偏り**が既にあり、2つが打ち消し合っている(試合評価推定の誤差は+0.0152)。その出どころは未分解。
5. **先発への効きは小さい。** 全ての推定を中心化しても、Top2が変わる`lineup_decision`は24,192件中2.06%、新人行の先発割合は38.83%→37.71%(−1.1pt)。ずれはほぼ全選手に共通で、順位を変えない。
6. **帰結**: 不具合だが、新人の遅れや先発を説明せず、直しても新人は改善しない。直す理由は「世界の観察が系統的に歪んでいる」ことそのもの(以後の全比較の土台)と、疲労観察・自己観察にも同じ歪みがあること。直すと全履歴が変わるので本taskでは直さず、版つきの別taskの候補(下)として記述する。T034の「初見の観察」候補は、事前登録した2条件(差のずれ説明率<50%、中心化後も15〜21日の誤差≤−0.05)を満たすので候補に残る。

## 限界・正直な注記

- 反実仮想は**線形伝播**(clampと丸めは無視、新人は再生で検証)。観察枠の競合・選考の変化が観察を変える再帰は含まない(中心化した世界では履歴が変わり、本当の効果は別の実験でないと分からない)。Top2の変更は他の項を固定したオフライン再計算。
- 新人以外の推定の伝播は世界の開始から(監督, 選手)ごとに0から。移籍で別のクラブの推定を引き継ぐ仕組みがあれば過小評価になりうる(連鎖の整合は、観察イベントに記録された推定の連続した再現で108,656件確認)。
- 試合の雑音の基準値(`perf_raw`)は記録されず、試合の観察のキー検証は練習日・偵察のキーと同形であることに依拠する。試合のclamp率は6.1%で、clampされた観察は補正後もclampの範囲に入れている。
- 新人以外の誤差が約0なのは、複数の偏り(雑音−0.013、別の正の偏り)の打ち消しで、後者は未分解。**ずれを直すとこの均衡が崩れる**。疲労観察と自己観察の効果は未測定。
- 行は新人×試合日で独立でなく、3seedも独立でない。ロスターは小さい。
