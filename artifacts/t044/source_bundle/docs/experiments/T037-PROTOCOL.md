# T037 事前実験条件

2026-11-11、実装前登録(結果を見る前)。契約: [T037](../tasks/T037.md)。結果を見て方法・定義・閾値・予測を変えない。外れた予測は結果として記録する。調整(幅・係数・設定)はしない。

## 固定する条件

Python 3.13.3(uv)。T033〜T036と同じ84セル(14世界×seed{100,101,102}×開始年齢{29,33}、168日、`season_length_days=21`)を3設定(`t033.SETTINGS`)で、`observation_noise_mode`の`legacy`/`centered_v1`/`shifted_v1`の3群で実行する(計756実行)。研究者だけが真の技能・疲労を使う。測定・集計はT036と同一(M1〜M5。`experiments/t036.py`のrun_cellを再利用し、3群に拡張)。

## 実装の約束

- `shifted_v1`: 技能観察は`u×2×幅`、疲労観察は`u×2×幅`(`u∈[−1,1]`、同じ単一の引き)。`legacy`/`centered_v1`の式は1バイトも変えない。恒等式(同じ`u`で厳密): `legacy = shifted − 幅`、`centered = shifted/2`。
- `uniform_from_key`の呼び出し(キー・回数・順序)は変えない(AST呼び出し数が凍結T036 bundleと同一)。configにキーが出るのは既定以外のときだけ、不明な値は拒否、保存・両reader・分岐・改変拒否が動く。
- 疲労観察は下限0・上限0.95でclampされる。`shifted_v1`の範囲[−2幅,+2幅]は`legacy`の[−3幅,+幅]より下側に当たりにくいが上側が増える。clamp込みの平均とclampなし集合(T036の事前の定義: 真の疲労≥幅 かつ真の疲労+幅≤0.95を、shiftedでは真の疲労≥2幅 かつ真の疲労+2幅≤0.95に読み替える)の両方を出す。

## 分解の定義(結果の前に固定)

指標Y(新人以外・新人の技能推定MAE、先発の真の上位2人一致率、最終の技能・信頼、偵察/練習日の観察イベント数、新人以外の試合評価推定の偏り)ごとに、セル対(同じ世界・seed・開始年齢、n=252)で、
- 全体 T = Y(centered) − Y(legacy)
- 平均の補正の寄与 B = Y(shifted) − Y(legacy)(ばらつきは一定)
- ばらつき減少の寄与 V = Y(centered) − Y(shifted)(平均0で一定)
- B + V = T(定義により厳密)。**割合 B/T と V/T は、|T|のセル対t≥3のときだけ報告**し、セルの再標本(bootstrap 1000回、固定seed)で95%区間を添える。
- 区分: V/T≥2/3なら「主にばらつき」、B/T≥2/3なら「主に平均」、それ以外は「混合」。BとVの符号が逆(一方がTと逆向き)のときは割合を出さず「相殺」と書く。
- 交互作用(平均−幅でばらつき半分の第4の隅)は実行しないので、B・Vの分けは「legacy→shifted→centered」の経路に依存する。他の経路の寄与は同定しない。

## 成功条件(ゲート。どれかが破れたら結果を出さずに原因を直す、または失敗として記録)

1. **legacy = 凍結、centered = T036**: legacy群が3設定×84セルでT030/T031/T032保存済みsummaryの最終値・イベント数と252/252一致。centered群の最終値・イベント数・M3〜M4のプール値がT036の保存済み`run/summary.json`と一致(同じコードでの再現)。
2. **RNG消費が同一**: AST上の呼び出し数が凍結T036 bundleと同じ。1日目のキー列が3群で同一。同じキーで`shifted − legacy = 幅`、`centered = shifted/2`が成り立つ(技能は最大偏差1e-15、疲労はround6の2e-6以内)。
3. **雑音の形**: `shifted_v1`の観察誤差(練習日・偵察・自己)の平均の絶対値が全設定で0.003以下、標準偏差が`legacy`の±10%以内(clamp含め)。
4. **save/reader**: 既定configにキーなし、`"shifted_v1"`が往復、不明・空・非文字列の拒否、保存・読込・分岐・段階実行の一致、`legacy`/`centered_v1`に書き換えた改変snapshotの拒否。`_validate_league_invariants`が全756実行で通る。
5. **凍結成果物**: 旧成果物inventory(`artifacts/t037/preflight/`、6,686ファイル)のhash不変、source_bundle保存、全unittest合格(3.13.3)。

## 予測(反証され得る。事前の信頼を併記)

数値は3設定合計のT036の値(legacy→centered)を基準にする。
- **P1(機構)**: ゲート1〜4が全て通る。信頼約90%。
- **P2(雑音の形)**: shiftedの観察誤差は平均0±0.003、標準偏差はlegacyと同じ(±10%)。信頼約85%。
- **P3(新人以外の技能推定MAE 0.0638→0.0575、差0.0063)**: 改善の大半はばらつき減少。V/T≥2/3(shiftedのMAEは0.0638から±0.0020以内)。信頼約60%。
- **P4(新人以外の技能推定の偏り +0.0002→−0.0013)**: T035の線形伝播どおり平均の補正でshiftedの偏りは正に上がる(+0.005〜+0.020)。信頼約55%。
- **P5(新人の技能推定MAE 0.0606→0.0551、差0.0055)**: 新人は観察が少なく雑音の平均の寄与が小さい。shiftedのMAEはlegacyとcenteredの間、B/Tは混合(1/3〜2/3)。信頼約45%(新人の遅れは入団時の定数が主因のため)。
- **P6(先発が真の上位2人と一致 62.3%→70.9%、+8.7pt)**: 大半はばらつき減少。shiftedはlegacyから+3pt以内。信頼約60%。

- **P9(新人以外の試合評価推定の偏り +0.0152→+0.0182、+0.0030で悪化)**: 平均の補正の寄与(B≥+0.002)。centeredとshiftedの差は±0.002以内。信頼約55%。
- **P10(新人の15〜21日の誤差 −0.1008→−0.0911)**: 3群とも−0.05以下で残る。信頼約85%。
