## 実装済み

- Python 3.13以上、標準ライブラリのみ。検証環境はCPython 3.13.3/macOS arm64、CPU。外部サービスの推論や課金は実装に不要。
- 選手2人、1技能、2練習方法、休息。旧1監督2枠/日と、新2監督各1枠/日。選手は各1枠/日。
- 真の技能・潜在学習率・上限・疲労と、選手/監督の主観を分離。
- 選手の方法/休息の選択、監督の有料観察/提案/休息の選択。提案の採用・拒否と候補得点を記録。
- A: 技能/疲労の更新。B: 自己評価/方法期待/監督評価/観察時点/助言予測への信頼/監督の個人別予測補正の更新。Cはなし。
- 事実・観測・意思決定・変化のイベントと原因参照。

- 方法期待の非負丸め/符号保持を切り替える比較。負の主観値と非負の真の技能を別々に検証。
- 監督の時間を使った前後観察、実施方法の経験、個体×方法の予測補正と根拠の保存。
- 監督が事前の予測順位を方法選択に使う比較モード。未選択の方法も予測/根拠を記録し、学習の効果と分ける。

- 2クラブ（`club_a`: 監督 `c1`, `club_b`: 監督 `c2`）・6選手（`p1..p6`、所属人数不変条件 `2 <= roster <= 4`）×84日の最小キャリア・相互合意移籍閉ループ（`world_kind='transfer_loop'`, `save=10`）。2クラブ直接2D対決、他クラブ選手への監督スカウト観察（`scout`）、および選手・放出側監督・獲得側監督の3者私的合意のみによる原子的所属変更（作成者: Antigravity / Gemini 4 Argon）。
