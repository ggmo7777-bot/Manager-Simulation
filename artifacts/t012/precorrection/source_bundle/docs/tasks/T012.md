# T012: 記録付き認識介入と分岐世界の保存・再開

2026-11-08。ユーザーの「次に進んでください」に対応する最小タスク。状態: 計画登録・実装前。

## 目的と選択理由

同じ過去から、監督の評価または選手の相手別信頼だけを変えた反実仮想を保存し、後日再開して比較できるようにする。T011-R1では記録外介入を拒否するため、因果比較は一時的なメモリ内実験に限られた。独立した個体の知識・経験がキャリアにどう作用するかを検査する基盤を、次の小さな単位とする。

初期集団拡張・経済ガード改善・直接検証readerも候補だが、今回は全再演を維持して介入記録だけを加える。通常世界の成長式・Policy・経済・日程は変更しない。研究者の操作を自律的な出来事や選手の実体験として偽装しない。

## 実装契約

- LeagueWorldStateのみ。日境界（day0含む）で親世界を検査し、複製して分岐するAPI `fork_league_world(world, *, kind, player_id, coach_id, value, reason)` を追加する。親世界は不変。
- kindは `coach_skill_estimate`（指定監督の指定選手評価、範囲0.10..0.98）と `player_trust`（指定選手から指定監督への信頼、0.05..0.95）の2つ。新しい値は有限・bool不可・小数6桁以内。ID・理由・型を厳格に検査する。A真値・技能・所属・台帳・configなど任意pathの変更は許可しない。
- 介入は現在日の終了後、翌日の判断前。指定したB値とその根拠参照だけを変える。監督のlast_seen_dayなど鮮度は変えない。値が同じno-opも記録する。
- 不変の介入レコードに順番、日、phase、kind、対象/観測者、前後値、理由、親checkpointのcanonical hash、変更前の根拠参照を保存する。世界イベントにも `research_intervention`（actor=researcher）を残す。イベントは通常の観測と区別する。
- snapshot/manifestには介入列と研究分岐であることを識別できる情報を保持。seed/configから再演し、指定日境界で記録順に介入を適用して全状態と履歴を照合する。親hashは介入前の再演状態から再計算し、外部ファイル不要で検査する。介入を信頼済みの任意state patchとして読み込まない。
- 同一境界での複数介入、分岐世界からの再分岐、分岐直後と途中保存からの再開を扱う。壊れた親・未来の介入・順序/型/参照/hash改変を拒否する。記録外変更を正当化する抜け道を作らない。
- CLI `branch` を追加。`--snapshot --kind --player --coach --value --reason --days --out`。元snapshotの上書きを拒否する。通常run/resumeも維持する。
- save13へ更新。通常rules/policyはT011-R1 v2を維持し、介入方式の版をidentityへ明記する。旧save12は凍結T011-R1で読む。
