# T036 — 観察雑音の中心化(`observation_noise_mode`、版つきの明示的な選択)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件を固定)。状態: 完了(結果: docs/experiments/T036-RESULTS.md)。ブランチt036はt035から積む(PR #18が先にマージされる前提)。[事前条件](../experiments/T036-PROTOCOL.md)、判断: D051。担当: Claude Sonnet 5.5。

## 問題

T035は、`league_economy.py`の4箇所の技能観察(自己・監督の練習日・偵察・試合)と疲労観察(`league_observation.observe_fatigue`、5箇所の呼び出し)の雑音が、既定範囲[−1,1]の一様乱数に`u∈[0,1]`前提の式を当てたため[−3,+1]×幅(平均−幅)になっていることを確認した。旧モジュールは全て`low=−幅, high=幅`の対称範囲で、設計意図の記述はなく、移植時の取り違えと判断された。ただし新人以外の推定には別の正の偏り(約+0.013)があり、ずれを直すと打ち消しが崩れて一部の誤差は悪化しうる。

## 最小の選択

config`observation_noise_mode`(既定`"legacy"`=現行の式をそのまま、`"centered_v1"`=同じ引き`u`に対し`u×幅`、すなわち[−幅,+幅]の対称一様)を追加する。**既定は変えない**ので凍結成果物は変わらない(configにキーが出るのは既定以外のときだけ)。乱数の呼び出し(キー・回数)は変えず、雑音の平均だけが変わる。

- 変更箇所: 技能観察4箇所(自己`self_obs`、監督`coach_obs`、偵察`scout_obs`、試合`match_obs`)と、疲労観察`observe_fatigue`(5呼び出し: 自己の練習・自己の試合・監督の練習・偵察・監督の試合)。新しいイベント・worldフィールド・乱数の呼び出しは無い。
- 比較: T030/T031/T032の凍結設定×84セル×168日を、legacy(凍結との一致を確認)とcentered_v1で実行する。
- 対象外: 既定の変更、雑音の幅や他の係数の調整、別の正の偏りの分解、初見の観察の規則(T037)、CLI/UI。戻し方: configの既定が`legacy`なので、該当コード・テスト・`artifacts/t036/`・文書の削除で戻る。
