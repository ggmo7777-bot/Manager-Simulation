# T046 — 遅れの除去の用量反応・対象別・残った傾きの原因: 先発選びの瞬間に、監督の推定の遅れを25/50/75/100%だけ除く、先発だけ・控えだけ・境界の2人だけ除く、疲労の推定の遅れも除く(研究者のみ)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件・規則を固定)。状態: 実装前登録済み。ブランチt046はt045から積む(PR #20 → #22 → #25 → #28 → #29 → #32 → #34 → #35 → #36 → 本PRの順にマージされる前提)。[事前条件](../experiments/T046-PROTOCOL.md)、判断: D061。担当: Claude Opus 5.5。

## 問題

T045は、先発選びの瞬間だけ監督の推定から遅れを全部除くと、先発一致のU字が約65〜67%縮むことを示した(提案T046の元)。残った問い: (1) 遅れを一部だけ除いたとき、U字の深さは除いた量に比例して縮むのか(用量反応の形)。(2) 遅れを除く対象は、先発だけか、控えだけか、境界の2人(先発の最下位と控えの最上位)だけか、どれが効きを運ぶのか。これは、遅れを減らす現実の方策(観察の頻度・対象)をどこへ向けるかの目安になる。(3) 遅れを全部除いたあとにも、休養が多いほど先発一致がわずかに高い傾きが残った(T045の事後の観察、原因は未検証)。事前登録した候補を1つだけ検証する: 疲労の推定(先発選びが引く`select_fatigue_weight × 疲労の推定`)の遅れ・誤差。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。既定は変えない。Policyへ真値は渡さない(渡るのは、T045と同じ、研究者が先発選びの入口で与える反事実の入力だけ)。**
- `experiments/t046.py`が、T045の差し替え(`le.decide_club_lineup`を包み、試合日の呼び出しだけ、読み取り用の写し)を一般化する: 各ロスター選手の2つの推定から遅れを割合`λ`だけ除く(`R − λ·lag`)、除く選手を絞る(先発・控え・境界の2人)、疲労の推定を決定の瞬間の真の疲労に置き換える(`nolagfat`)。
- 変種8(`none`は恒等)×掃引の点(`none`は5点、他は4点)×2方向=74腕を252セルで実行(168日)。T045の`none`・`nolag`の水準の再現と、恒等・読み取り専用の検査をゲートにする。
- 対象外: `soccer_sim/`の変更、新しいconfig、既定の変更、価値判断、観察の頻度を実際に増やす方策の実装、疲労の推定以外の原因の探索(1つだけ)、長期の再測定。戻し方: `experiments/t046.py`、`tests/test_t046.py`、`artifacts/t046/`、文書の削除のみ。
