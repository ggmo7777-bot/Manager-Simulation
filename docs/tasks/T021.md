# T021 — T020で拒否された3摂動の再実行

2026-11-10、実装前登録(結果を見る前に規則を固定)。状態: 登録済み・未実装。担当: Claude Sonnet 5.5。着手は継続指示に基づく。[事前条件](../experiments/T021-PROTOCOL.md)、判断: D036。

## 問題

T020は事前登録18摂動のうち3種(cap_w15、psych_w15、cap_cp)を、同じ事前登録の値域規則[0.05,0.95](クリップせず拒否)で拒否した。契約2(拒否)と契約3(19セル)が両立しなかったためで、成功条件3は16/19セルの部分充足となり、H1〜H3は3種を含まない。T021はこの不整合を、結果を見る前に固定する規則で解消し、3セルをT020の表に結合する。

## 規則(結果を見る前に固定)

R1 上限(cap)の天井: capの値域を[0.05,0.98]とする。理由: 既定の生成式が既に`min(0.98, max(trait)+0.05)`で上限を0.98まで許し、観測・満足度のclampも0.98で、0.98は本worldで既に使われている最大値である。trait・忠誠・野心・自律の値域は[0.05,0.95]のまま。

R2 幅摂動の対称な切り詰め: 幅摂動が(R1後の)値域をなお超えるとき、中心を固定したまま、値域内に収まる最大の倍率(要求倍率以下)で適用する。クリップ(片側だけ削る)はしない。中心移動の摂動が値域を超える場合は従来どおり拒否する。

規則は拒否の再解釈であって範囲の更新ではない。既定の範囲、T020の15実行セルとbaseline、既定14条件は変更しない。

## 3摂動の有効範囲(規則から導出、事前に手書き)

| 名前 | 要求 | 有効な範囲(育成 / 補強) |
|---|---|---|
| cap_w15_x | 上限幅×1.5 | cap 0.8875–0.9625 / 0.58–0.94(R1で受理、他は不変) |
| cap_cp_x | 上限+0.03 | cap 0.93–0.98 / 0.67–0.91(R1で受理、上端は天井ちょうど) |
| psych_w15_x | 忠誠・野心・自律の幅×1.5 | 忠誠は下端0.05が拘束して倍率1.0(0.05–0.30のまま)、野心0.25–0.85、自律0.305–0.395(R2。忠誠だけ広がらない) |

psych_w15_xは「忠誠を除く心理の幅×1.5」であり、要求どおりの3群同時×1.5ではない。この制約は結果の解釈で明記する。名前は既存名と区別するため`_x`を付け、T020の名前(cap_w15等)は従来どおり拒否のまま残す(T020のテスト・成果物と整合)。

## 仮説(T020のH1〜H3を19セルへ更新、確認前に固定)

- H1 全18摂動+baselineで還元効果の平均差>0(T020と同じ判定規則: 平均が0以下なら反証、区間が0を含めば判定不能、全て区間下限>0なら支持)。
- H2 群ごとの|摂動差|の最大が成長率群(T020と同じ規則)。新3セルが加わっても成長率群が最大のまま。

## 成功条件と失敗条件

1. 再現: T020のbaseline+15摂動の16セル×3制度×30seed(480行)が、T021の再実行とT020の`runs.json`でバイト対応(行の全フィールド一致)。既定14条件はT018と一致、null摂動はbaselineと一致(T020の検査を継続)。T020の全テストが合格(T020の拒否3名は従来どおり拒否)。
2. 妥当性: 新3名は上記有効範囲と全一致(手書き期待と別実装の再計算、seed300,301)。他の無効な摂動(未定義名、trait_w25、非sampled基底)は引き続き拒否。範囲の下限<上限、cap生成規則維持。
3. 報告: 19セル(baseline+18摂動)の表(T020の16セル+新3セル)、baseline差、探索的区間、正/負/ゼロ数、非空世界数。単一の感度得点・順位総合点にしない。H1・H2を19セルで再判定。
4. 失敗条件: 既定worldまたはT020の15セルが変わる、T020の16セルが再現しない、新3名の範囲が手書き期待と不一致、全unittest/高速ゲート失敗、凍結成果物の変更、結果を見てからの規則・天井・seedの変更。効果の大小・符号は仮説判定に使うが採否の条件にしない。
