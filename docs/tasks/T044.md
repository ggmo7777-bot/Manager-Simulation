# T044 — U字の機構: 監督の推定の誤差を「観察雑音・定義の差・遅れ(初期印象の残りを含む)」に分けて休養率の掃引に沿って測る(研究者のみ)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件・規則を固定)。状態: 実装前登録(結果: 未)。ブランチt044はt043から積む(PR #20 → #22 → #25 → #28 → #29 → #32 → #34 → 本PRの順にマージされる前提)。[事前条件](../experiments/T044-PROTOCOL.md)、判断: D059。担当: Claude Sonnet 5.5。

## 問題

T043は、休養率を連続的に動かした掃引で先発一致が休養率に対してU字になること(低休養側36〜44%で最大の約74%、72〜78%で最小の約60%、90%で約71%。現在の2点、legacy 66.7%・centered_v1 51.8%は最大の平坦域の外)、利得を運ぶのは期待利得の水準であること、先発一致の動きの78%は監督の評価の誤差`err`を介し、そのうち試合評価の推定87%・技能の推定52%・疲労の推定は関与しない、疲労は休養率45%を下回ると急増することを示した。T043の次の候補は『U字の機構』: 監督の推定の誤差のどの部分(観察の遅れ、観察雑音、推定が測るものと先発選びに要るものの定義の差)が、休養率とともに動くのか。休養が少なすぎると損をする(疲労 → 試合の出来 → 評価)という経路は本当にあるのか。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。既定は変えない。** T043の掃引の腕(`base`と`o(δ)` 9本、方向ごと10点、計20腕)を252セル×3設定で再実行する。腕の挙動はT043と同一(期待利得の読み替えだけ)で、`_append_event`を通り抜けで包む読み取り専用の記録器を足す。記録器は、各(監督, 選手)の技能の推定と試合評価の推定を、記録された観察イベントから厳密に再構成し(実際の推定と一致を検査)、同じ観察の列を入力が違う3本の「影の推定」(雑音を除いた入力、観察時点の真の技能を入力にしたもの、初期印象も真の技能にしたもの)で並走させる。これで各推定の誤差が、観察雑音・定義の差・初期印象の残り・遅れの4項に恒等式で分かれ、T043の`err`の`skill`項と`match`項が8項に分かれる。掃引に沿った項別の変化を3つの対比(低休養端−谷、高休養端−谷、膝の下)で測り、疲労 → 試合の出来 → 評価の経路を、先発の試合前疲労・試合評価に入る出来の加点・その傾きで測る。

- 対象外: `soccer_sim/`の変更、新しいconfig、既定の変更、価値判断(どの休養率が望ましいか)、休養率の168日を超える長期、個性に基づく休養の多様性の測定、疲労の怪我モデル(simに無い)、移籍・選手側の判断の差し替え。戻し方: `experiments/t044.py`、`tests/test_t044.py`、`artifacts/t044/`、文書の削除のみ。
