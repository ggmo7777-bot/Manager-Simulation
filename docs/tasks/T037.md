# T037 — 平均とばらつきの切り分け(`observation_noise_mode`に対照`shifted_v1`を追加)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件を固定)。状態: 完了(結果: docs/experiments/T037-RESULTS.md)。ブランチt037はt036から積む(PR #19が先にマージされる前提)。[事前条件](../experiments/T037-PROTOCOL.md)、判断: D052。担当: Claude Sonnet 5.5。

## 問題

T036は`centered_v1`(`u×幅`、範囲[−幅,+幅])が推定のMAE(新人以外0.0638→0.0575)・先発の的確さ(62.3%→70.9%)・最終技能(+0.0057)を改善することを示したが、`centered_v1`は旧式の平均(−幅)を0にすると同時に標準偏差を1.155幅→0.577幅に半減させる。改善が平均の補正によるのか、ばらつきの減少によるのかは分けられない。偵察イベントの+17%、新人以外の試合評価推定の偏りの悪化(+0.0152→+0.0182)も、どちらの効果か不明。

## 最小の選択

`observation_noise_mode`に第3の値`"shifted_v1"`を追加する: 同じ引き`u`に対し`u×2×幅`(範囲[−2幅,+2幅]、平均0、**標準偏差は`legacy`と同じ1.155幅**)。恒等式 `legacy = shifted_v1 − 幅`、`centered_v1 = shifted_v1 ÷ 2`(同じ`u`で厳密)により、legacy→shifted は「ばらつき一定で平均だけ」、shifted→centered は「平均0のままばらつきだけ」を表す。**既定は変えない**。乱数のキー・回数は不変。configにキーが出るのは既定以外のときだけ。

- 変更箇所: 技能観察4箇所の`observation_noise`と疲労観察`observe_fatigue`の係数だけ。新しいイベント・worldフィールド・乱数の呼び出しは無い。
- 比較: T030/T031/T032の凍結設定×84セル×168日を、legacy / centered_v1 / shifted_v1の3群で実行(756実行)し、各指標の差を「平均の補正の寄与」と「ばらつき減少の寄与」に分解する。
- 対象外: 既定の変更、幅や他の係数の調整、第4の隅(平均−幅でばらつき半分)の実行(交互作用は同定しない)、初見の観察の規則(T038)、CLI/UI。戻し方: configの既定が`legacy`なので、追加コード・テスト・`artifacts/t037/`・文書の削除で戻る。
