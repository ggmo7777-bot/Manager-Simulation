# T031 — 控え若手の発見: 監督の観察規則に「長く見ていない選手ほど観察の価値が増える」項を足す(未観察の不確かさの増加)

2026-11-10、実装前登録(結果を見る前に規則を固定)。状態: 実装前。T030(PR #13、未マージ)の上に積む(ブランチt031はt030から。PR #13が先にマージされる)。[事前条件](../experiments/T031-PROTOCOL.md)、判断: D046。担当: Claude Sonnet 5.5。

## 問題

T030のP3は反証された。入団後1年以上の新人のうち、入団クラブの監督に観察されたのは60.9%で、38.9%は最初の年度に一度も先発しなかった。原因は構造にある。(1)試合の観察は先発(2人)だけで、控えは試合では誰にも見られない(コード上「No paid/direct observation of this bench player: coach keeps prior」)。(2)監督の練習日の観察候補は`0.12 + 0.018*min(10,日数) + 0.22*need`で、未観察の日数の効果が10日で頭打ちになるため、最大でも約0.39で、提案候補(平均約0.31、最大約0.43)にほとんど勝てない(S=33、1世界の探索で観察が選ばれたのは576決定中6回)。控えは誰の目にも入らず、定数の初期印象(0.5)のまま置かれる。

## 最小の選択

**観察候補の日数の上限を10日から40日に広げる**(config任意キー`coach_exploration`、既定`"none"`、有効値`"unseen_bonus_v1"`)。有効時のみ、`decide_coach_training`の観察候補の「未観察日数の項」が`min(40, 日数)`(従来`min(10, 日数)`)になる。係数0.018は従来のまま。それ以外の項・候補・選択規則は不変。

- 入力は従来どおり監督のB層(各選手の`last_seen_day`=最後に見た日、現在日)だけ。真の技能・特性・年齢は入力にない。**新しい乱数もない**(決定的)。
- 試合で毎週見られる先発は日数が7を超えないので、規則は実質的に「長く見ていない控え」にだけ効く。控えは10日を超えると観察の価値が増え続け、約14日で提案候補を上回り、1回観察されると日数が0に戻る(ガチャ的な「確約された発見」はない。観察しても推定が真の技能に近づくだけで、先発に選ばれるかは監督の既存の選考規則(技能推定・試合評価推定・疲労推定)が決める)。
- 40日は事前に固定する。調整しない。式は不確かさが時間とともに増えるという最小の仮説で、校正していない。
- **別案と不採用の理由**: (a) 先発枠の一つを最も長く見ていない選手に回す探索的選考: 試合結果へ直接の費用がかかり、先発の意味(今の最良)を直接曲げる。観察規則の変更より大きい。(b) 乱数による探索(ε-greedy): 再現はできるが、乱数チャネルの追加と「運に頼る発見」になる。(c) 控えの試合評価の補正や技能の底上げ: 真の値を使うか、成長を直接変えるので禁止方向。(d) 現状維持。観察規則の1定数の拡張が最小で、費用は練習日の枠の消費(提案と偵察の減少)に限られ、測れる。
