# T040 — どの意思決定が推定の水準のずれを受け取って利得になるか(介入による分解、研究者のみ)

2026-11-11、実装前登録(結果を見る前に方法・予測・失敗条件・帰属規則を固定)。状態: 実装前登録。ブランチt040はt039から積む(PR #20 → #22 → #25 の順にマージされる前提)。[事前条件](../experiments/T040-PROTOCOL.md)、判断: D055。担当: Claude Sonnet 5.5。

## 問題

T039は、centered_v1の先発一致の利得(+8.7pt)が、同じ観察の列で雑音の平均だけを除く静的な効果(C_all −0.97pt)では説明されず、平均を直した世界で履歴が変わる動的な経路にあることを示した。事後の観察では、控えで真の上位2人に入る選手の昇格や、出場者の誤った残留の減少が見られたが、**どの意思決定が水準のずれの影響を受けて利得になるのか**は分かっていない。既定をcentered_v1へ移す提案の前に、これを介入で分解する。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。** 監督の推定を読む意思決定を4種に分ける: **先発選び**(lineup)、**移籍**(transfer: 売却の同意と獲得の評価)、**観察・偵察の配分**(allocation: 練習の観察と偵察の候補)、**助言**(advice: 方法の提案の候補)。研究者は、同じ観察イベントから、世界の雑音方式と**もう一方の方式**での推定を並行して持ち(追跡)、1つの意思決定が読む間だけ評価値を差し替える。

- 順方向: legacyの世界で、1種ずつcentered_v1の推定を渡す(+全4種)。
- 逆方向: centered_v1の世界で、1種ずつlegacyの推定を渡す(+全4種)。
- 比較: 各方向の素の世界(差し替えなし)。計12腕×84セル×3設定(3,024実行)に、ゲート用のcentered_v1の素の実行252を加える。

測るのは先発一致(主)、最終技能・信頼など(副)、昇格率と意思決定の選択件数(記述)。帰属は登録した規則(区間つき)で出す。最後に、centered_v1を既定にする提案の推奨を登録した規則で書く(推奨のみ。既定は変えない)。

- 対象外: `soccer_sim/`の変更、新しいconfig、既定の変更、幅の調整、選手側の自己観察(選手自身の自己推定・疲労知覚・信頼)を介する経路の差し替え(残差として報告)、第3の方式(shifted_v1)での差し替え、CLI/UI。戻し方: `experiments/t040.py`、`tests/test_t040.py`、`artifacts/t040/`、文書の削除のみ。
