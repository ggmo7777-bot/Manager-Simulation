# T018 — リーグの実行指紋とCLI・分析の来歴を分離

2026-11-09、実装前登録。状態: 完了(2026-11-10)。[結果](../experiments/T018-RESULTS.md)。継続指示に基づく次の最小タスク。実装Sol 6.1 High、設計・独立検証Codex。

## 仮説と範囲

T017はCLI一ファイルの変更だけで全snapshotを拒否した。リーグ実行依存のファイル集合を保守的に明示すれば、CLI/実験のみの変更で保存再開を妨げず、進行・観測・Policy・保存の変更を検出できる。

- リーグのみsave17へ。進行T015、Policy T013、評価T016、通貨、初期集団、A/B、全再演readerは維持する。旧世界のstorage.identity等は変更しない。
- snapshot identityの`source_sha256`は新しい`source_scope=league-runtime-files-v1`の実行ファイル集合の指紋とする。キーは既存分析利用者のため維持。scope/save/hashすべてが一致した場合だけ読む。旧save16以前の自動移行はしない。
- 最初の集合は`__init__.py`、新規fingerprints.py、league_economy.py、league_observation.py、money.py、match_2d.py、storage.py、advice.py、observation.py、policy.py、simulation.py、state.py。直接使用しない部分を含むファイルも保守的に全体をhashする。
- 静的な内部import依存を検査する。未登録依存、欠落ファイル、未対応の動的importは拒否し、集合を黙って狭くしない。唯一の分析import例外は`storage.write_run -> experiments`、`match_2d.write_run -> experiment_t008`（旧世界のwriterでありリーグが呼ばない）。例外はファイル/関数/モジュールの組で限定しテストする。汎用Pythonコードの安全解析ではない。
- manifestに実行ファイル別hash、package全体、CLI入口、分析コードの来歴を別記する。CLI入口hashはCLI全依存閉包と呼ばない。分析はpackageのexperiment*.pyとrootのexperiments/**/*.py。snapshotや親checkpoint hashに非実行来歴を混ぜない。
- 実行中のソース変更は未対応。検証用変更は隔離したコピーで行い、毎回新しいプロセスで起動する。外部データ/モデル依存を導入する時は互換契約を拡張してから利用する。

## 成功条件と失敗条件

1. CLIコメント修正、package/root分析コメント修正・分析ファイル追加で、新保存の読込・再開・分岐・分岐の再開が成功。snapshot/events/summaryが完全一致し、manifestの来歴だけが変わる。親hashも一致。
2. 実行集合の全ファイルの変更でhashが変わる。実ルール変更、欠落、未登録内部依存、旧schema/不明scope/改変hashは出力作成前に拒否。内部依存の見逃しやCLI変更での不必要な拒否は失敗。
3. fixed/sampled各7条件、seed100、35日で凍結T017と状態・履歴・評価が一致。比較から除くのはidentityとそこから派生するsnapshot hashだけ。実行規則に差が出たらこのタスクを拡張せず原因を解消する。
4. 標準ライブラリの自動テストと独立プロセスの比較。旧T017ソース/manifest確認済み。旧2,147ファイルを変更前後にhash照合。全unittestを完了時に実行する。

## 対象外・戻し方

全世界のkernel化、直接reader、係数調整、初期分布校正、C、世代交代、UI、Git、CLI出力上書き仕様は変更しない。保存フォルダ全体の原子性は保証しない。新成果物は`artifacts/t018/`、旧T017以下は保持。問題時は対応する凍結ソースを別環境で使い、旧保存の指紋を書き換えない。ファイル単位なので同居する評価/旧writerの変更でも再開を拒否する保守的な制約は残る。
