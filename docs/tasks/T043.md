# T043 — 期待利得の水準とばらつきの分離、`err`(監督の評価の誤差)の項別分解、休養率の掃引(研究者のみ)

## 問題

T042は、練習の選択が読む3つの状態のうち期待利得だけが利得を運ぶこと(順方向+10.90pt、逆方向+8.09pt、`single_variable(gain)`)、期待利得の差し替えで練習日の休養率が66.7% → 49.5%になること、休養率10pt当たり先発一致が−5.47ptで、その道筋の64%が監督の評価の誤差`err`を介することを示した。残った問いは3つ。(a) centered_v1の期待利得の何が効くのか(平均の水準か、決定ごとの散らばりか)。(b) `err`のどの項(監督のスコアのどの推定)が休養率で動くのか。(c) 休養率をどこに置くと先発一致・技能・疲労がどうなるか(既定の移行判断のための証拠)。

## 最小の選択

**分析のみ。`soccer_sim/`は1バイトも変えない。新しいconfigは足さない。既定は変えない。** 練習の選択が読む期待利得の2値(A、B)だけを判断の瞬間にずらして呼ぶ(呼出し後に必ず戻す)。腕は方向ごと(legacyの世界/centered_v1の世界)に13本: `base`、`g`(T042の`g`の再現)、`L`(本物の値に平均のずれ`c`を足す=水準)、`S`(もう一方の方式の値から`c`を引く=散らばり)、掃引`o(δ)` 9本(期待利得に一様にδを足す。解析専用の読み取りの差し替えで、simの設定ではない)。`c`はT042の保存値。`err`の項別分解は先発一致の分解を拡張して、研究者が`lineup_decision`のスコアの項(技能・試合評価・疲労)と真の技能から恒等式で5項(`sel`、`skill`、`match`、`fatigue`、`round`)に分ける。
