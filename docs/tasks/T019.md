# T019 — 初期分布の効果分解(分布・初期印象・旧p3,p9の満足度)

2026-11-10、実装前登録。状態: 登録のみ(未実装・未着手の指示ではない。実装にはユーザー指示が必要)。[事前条件](../experiments/T019-PROTOCOL.md)。T015で「sampledでは育成還元の効果が縮むが、原因(p3/p9の台本、成長率の分布、印象誤差)は未分離」、T016で初期育成6名の比較へ修正しfixed +0.015301 / sampled +0.007379(約48%)を得たが分解は未実施、と記録済み。

## 仮説と範囲

fixedとsampledの差は、互いに独立に切り替えられる3要因の合成である。

- F1 プロフィール: 選手の特徴3値・成長率A/B・上限・好み・忠誠・野心・自律・自己推定。fixed(固定fixture)/sampled(範囲抽出)。
- F2 初期印象: 各監督の選手への初期skill/match評価。fixed(p3のc1過小評価等の台本、他はself_est)/sampled(水準±0.06の独立誤差)。
- F3 p3,p9の初期満足度: fixedではp3,p9のみ0.42、他は0.50。sampledは全員0.50。F3は`playing_time_satisfaction`のみで、p3,p9のプロフィール・印象は含めない(それらはF1/F2に属する)。

仮説(確認前に固定): H1 sampledでの育成還元効果の縮小(T016: 48%)は3要因のうち一つが支配せず、複数要因に分かれる。H2 F1(成長率・上限の範囲が育成/補強で異なる入力)が最大の寄与を持つ。H3 F2とF3の寄与はF1より小さい。いずれも反証され得る。結果の符号を成功条件にしない。

最小実装(承認後): `LeagueEconomyConfig`へ3つの文字列フィールド(既定は現行の挙動を再現する値)と対応する条件名接尾辞を追加し、`_build_initial_world`が要因別に選ぶ。既定の`fixed`/`sampled`条件のworld stateは変更しない。進行・Policy・観測・移籍・通貨・評価・保存schemaは変更しない。F2/F3だけをfixedにしたsampledプロフィールの選手IDは、p3,p9が特別な才能であることを意味しない(スロット名)。

## 成功条件と失敗条件

1. 回帰: 既定の`fixed`と`sampled`の全14条件のworld(35日、seed100)が実装前(T018の`artifacts/t018/rerun-py313`)とsnapshot/events/summaryまで一致する。要因フィールドを既定にした時のみ。identityと派生hashだけ除外。
2. 要因の独立性: 8セル(F1,F2,F3それぞれの組)について、他要因の入力を変えても、その要因の生成値(プロフィール、印象、満足度)が変わらないことを初期状態で確認。F3だけ変えた場合はp3,p9の満足度以外のworld初期状態が一致。
3. 帰還: 角セル(fixed全て/sampled全て)がseed100..129の84日で、T016の初期育成6名の還元効果(+0.015301、+0.007379)を再現する。再現しなければ分解を報告せず実装を直す。
4. 分解の報告: 2^3=8セル×3制度(閉鎖・還元なし、開放・還元なし、開放・還元あり)×seed30で、主指標(初期育成6名の成長、開放市場の還元あり−なし)の対応差を報告。主効果と交互作用は2^3の平均対比、平均差・探索的区間・正負ゼロ数・非空世界数で示す。単一の「寄与率」に潰さず、分解が順序依存(要因を入れる順で割合が変わる)であることも8セルから示す。
5. 失敗条件: 角セルが再現しない、要因が独立でない、既定条件のworldが変わる、全unittestまたは高速ゲートが失敗、凍結成果物が変わる。効果の大小や符号は失敗条件にしない。

## 対象外・戻し方

範囲値の校正(現実分布への調整)、新要因の追加、世代交代、C、1000日、多seed以外の頑健性、評価器の変更、他の指標への一般化は対象外。結果から範囲やseedを選び直さない。新成果物は`artifacts/t019/`、旧成果物(T018以前)は上書きしない。戻し方: 要因フィールドの既定を使えば現行と同じworldで、問題時はT018のソース/成果物を凍結版として別環境で使う。ソースが変わるためT018以前のsaveは新版で読めず旧ソースで読む(`league-runtime-files-v1`の指紋に`league_economy.py`が含まれるため)。
