## 方策の車線(影の推定の追加)

T044の影の推定(`R`=実際の推定の再構成、`Z`=雑音・定義の差・初期印象を除いた推定。遅れ=`Z−T`)は、各監督×各選手の対に、実際の観察の入力で更新される。本taskは、対ごとに**車線**`L`ごとの2本`R:L`・`Z:L`を足す。車線は、(a)実際のすべての観察に、実際と同じ入力・同じ重み(T044の`update`)で更新され、(b)方策が決める**追加の観察**(下)でも更新される。追加の観察がなければ車線は`R`・`Z`と完全に等しい(検査する)。

**追加の観察**(影の練習型の観察。simのイベント・状態には書かない)は、実際の『観察』(練習日の`coach_session_observation`)と同じ式で車線を更新する: 技能は重み(1−α, α)(α=`coach_skill_alpha`)、試合評価の推定は`coach_practice_rating != 'none'`のときだけ重み(0.70, 0.30)。`R:L`の入力は`round6(clamp(T + 雑音, 0.10, 0.98))`、`T`は毎日の終わりの真の技能、雑音は`observation_noise(uniform_from_key(seed, day, 'ghost_<車線>', '<監督>:<選手>:<通し番号>'), coach_noise, observation_noise_mode)`(実際と同じ幅・方式。simのRNGは使わない)。`Z:L`の入力は`T`。疲労の推定は更新しない(限界に記す)。

**回数と割り当て**: 車線は倍率`K`と対象`x`(ロスター全員)または`b`(境界の2人)を持つ。各監督について、毎日の終わりに、その監督の自分のロスターへの実際の観察(練習の観察+試合の観察の自クラブの先発)の累計`C`と日数`day`から率`r = C/day`を出し、`credit += (K−1)·r`、`credit ≥ 1`の間、1回ずつ追加の観察を割り当てる。割り当て先は、対象の中で車線で**最も長く見ていない選手**(車線の最後の観察の日が最小、同じなら選手idの小さい方)。対象`x`=その時点のロスター全員、`b`=車線の推定でロスターを順位づけた(得点 = `select_skill_weight`×技能 + `select_match_weight`×試合評価 − `select_fatigue_weight`×実際の疲労の推定、降順)2位と3位(ロスター2人なら2位だけ)。倍率K=1は追加なし(恒等)。

車線: `x1`(恒等、ゲート用)、`x2`・`x4`・`x8`・`b2`・`b4`・`b8`。**影の車線**(`none`の腕で全6本を同時に走らせる)= `x2 x4 x8 b2 b4 b8`。**読ませる車線**(先発選びがその車線の`R:L`を読む)= `x2 x4 b2 b4`(と、ゲートだけ`x1`)。

## 実効λ(読み取りの測定)

先発選びの決定(試合日の呼び出し、`lineup_decision`イベントのあるもの)ごとに、ロスターの各選手 i の**得点の遅れ** `Lag_i^L = select_skill_weight·(Z^L_技能 − T) + select_match_weight·(Z^L_試合評価 − T)`(`L`=`none`は実際の`Z`)を求める。`T`は決定の瞬間の真の技能。選手の順位は**差し替えなしの実際の推定が先発選びの関数に与える順位**(T046と同じ)。群: `all`(ロスター全員)、`r1`・`r2`・`r3`(順位1・2・3位。ロスターに居なければ記録しない)、`bd`(`r2`と`r3`の平均。ロスター3人以上)、`pair`(|`Lag_r2` − `Lag_r3`|、ロスター3人以上)。水準 `A_{L,g}` = 全決定の `mean_{i∈g}|Lag_i^L|` の平均(`all`・`bd`は2乗の水準`Q_{L,g}`も)。

**実効λ** `λ_{L,g} = 1 − A_{L,g}/A_{none,g}`(同じ腕の中の比、群ごと)。主は `λ_all`(全員)と `λ_bd`(境界の2人)、掃引の4点(`o(±0.030)`・`o(±0.010)`)の平均、方向ごと。副次: `r1`・`r2`・`r3`・`pair`の`λ`、2乗の`λ`(`1 − sqrt(Q_L/Q_none)`)。遅れの出所の配分 `share_k = A_{none,r_k}/(A_{none,r1}+A_{none,r2}+A_{none,r3})`(掃引の4点の平均)。実現した追加の観察の回数: `ghost_L`(監督×日の平均)と`real`(同、実際の自クラブへの観察)の比 `ghost_L/real` が `K−1` に近いか。

## 先発一致の見積りと直接の確認

T046の保存値(同じ範囲=全体または設定別、方向ごと、`top2`の水準): `ref[v][p]`、v ∈ {`none`,`d25`,`d50`,`d75`,`nolag`,`bd`}、p ∈ 掃引の4点。`D(λ)`=λ ∈ {0, .25, .5, .75, 1} での `none`,`d25`,`d50`,`d75`,`nolag` を折れ線で結んだ水準(λは[0,1]に切る)。`m4(λ)`=`D(λ)`の4点平均、`g(λ) = (m4(λ) − m4(0))/(m4(1) − m4(0))`。

- **見積りA**(全員のλの換算): 点pの水準 = `D_p(λ_all)`、`λ_all`はその点・その方向の影の車線の値(`none`の腕の中)。
- **見積りB**(境界のλの換算): 点pの水準 = `ref[none][p] + (ref[bd][p] − ref[none][p])·g(λ_bd)`、`λ_bd`は同じく影の車線の値。
- **主の見積り**: 車線`x2`・`x4`には見積りA、`b2`・`b4`には見積りB。もう一方は副次(どちらが近いか)。
- **上がり** `gain4` = 4点の水準の平均 − `none`の4点の水準の平均(pt)。**U字の深さ** `U` = (`LO` + `HI`)/2、`LO` = `o(+0.030)` − `o(−0.010)`、`HI` = `o(−0.030)` − `o(−0.010)`(T046と同じ定義、`top2`)。見積りの`gain4`・`U`を、方策の腕の実測(`gain4`・`U`)と比べる: 誤差 `err4` = 実測`gain4` − 見積り`gain4`、`errU` = 実測`U` − 見積り`U`。
- **見積りが換算として合う**(方策ごと、点推定、両方向): `holds` = 両方向で |`err4`| ≤ 1.5pt。`over`(換算が過大) = 1方向以上で `err4` < −1.5pt かつ `err4` > +1.5pt の方向がない。`under`(換算が過小) = 1方向以上で `err4` > +1.5pt かつ `err4` < −1.5pt の方向がない。それ以外は `mixed`。
- 副次: 実測の上がりから逆算した換算λ(`m4(λ*) − m4(0)` = 実測`gain4`となる`λ*`、見積りAの曲線で。0〜1に収まらなければ`out_of_range`)、方策の腕の中で実現した`λ`(同じ腕の中の`none`車線との比)。

## 判断規則(結果の前に固定)

- 既定は**変えない**。T042〜T046の推奨も変更しない。本taskは、遅れを減らす現実の方策の対象と大きさの目安と、T046の用量反応が換算として使えるかを出すだけで、どの方策が望ましいかの価値判断はしない。
- 失敗条件: ゲートの破れ、`none`がT046の保存値と一致しない、恒等の車線が世界を変えること。予測の外れは失敗ではなく結果として記録。
- 解釈の規則: (i) **対象**: 問3が`same`なら『観察を境界の2人に絞っても、最も長く見ていない選手から全員へ回すのと変わらない(追加の観察は元々遅れの大きい控えへ向かう)』、`focus_helps`なら『境界の2人へ絞る』、`focus_hurts`なら『絞らない』と書く。(ii) **大きさ**: 問4の倍率を『実効λが0.5に届く観察の回数の目安』とし、換算(問5)が`holds`ならその倍率での先発一致の上がりをT046の用量反応から見積もる。`over`・`under`・`mixed`なら『換算は使えない/補正が要る』と書き、直接の実測の上がりを目安にする。(iii) 結論は本simの範囲(3人ロスターが大半、168日、練習型の観察の式、疲労の推定は更新しない)に限り、本物の方策の効果を主張しない。本物の設計(sim変更+再基準化)は別の後続task。

## 限界(結果を見る前に記す)

- 追加の観察は研究者が影の推定に与える反事実で、simには書かない。直接の確認は、先発選びが車線の推定を読み、世界がそのまま進む(T046と同じ構造)。実際に観察を増やすと、練習・助言・移籍の判断も変わるが、本taskでは変わらない。
- 追加の観察は技能・試合評価の推定だけを更新し、疲労の推定は更新しない。実際の観察は疲労の推定も更新する(T046では疲労の推定を真にすると4点平均が+0.4/+1.6pt)ので、これを含めない換算は保守側。
- 監督の2枠(観察・助言・偵察・休み)の取り合いや費用は無視する(追加の観察は無料)。『倍率K』は自クラブのロスターへの観察の回数の倍率で、監督の時間配分の現実の換算ではない。
- ロスターは3人が大半で、2人・4人の決定もある(`r3`は居なければ記録しない、`bd`・`pair`はロスター3人以上)。
- 見積りの入力(T046の保存値)の標本誤差は区間に入れない。区間はセルの再標本で、世界は3seedを共有し独立でないため過小の可能性がある。単一の主指標(先発一致)。
