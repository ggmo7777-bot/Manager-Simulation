## 結論(平易に)

1. **遅れを除くとU字は平らになる。** 先発選びの瞬間だけ、監督の推定から「遅れ」(観察が来たあとに真の技能が動いた分)を除いた推定(`nolag`)を読ませると、先発一致は全体に大きく上がる(谷で順方向+23.4pt [+21.9, +24.8]、逆方向+21.0pt [+19.7, +22.2]。5点の平均で+13.9pt・+11.6pt)。U字の深さは `LO`(低休養端−谷)が順方向+14.4ptから−2.0pt、逆方向+13.5ptから−0.2ptへ、`HI`(高休養端−谷)が+12.2ptから+2.2pt、+10.0ptから+2.3ptへ縮み、5点の曲線の幅(最大−最小)は14.4pt→5.1pt、13.5pt→4.5pt。谷はもう無い。**ただし登録した判定ラベルは`inverts`**(順方向の`LO`が−1.96pt [−2.81, −1.17]と区間の上限<0。逆方向の`LO`は区間が0を含む)。これは「谷が山になった」ではなく、遅れを除くと曲線が全体に約80〜85%の高さに上がり、休養が多いほどわずかに高い(順方向で90%の85.1%に対し36%の81.0%)という小さな傾きが残った、という意味。登録の解釈規則は`inverts`を想定しておらず、規則(i)をそのまま適用できない(下の「判断」)。
2. **観察雑音を除いても変わらない**(`nonoise`: `unchanged`、比0.92・0.94・1.01・0.97。谷での上昇は+0.4pt [−0.2, +1.1]・+0.8pt [+0.2, +1.4])。T044の「雑音は関与しない」は介入でも確認された。
3. **定義の差(出来の加点による先発の試合評価の上乗せ)は部分的な原因。** `nodef`は`partial`: 低休養側の枝(`LO`)を約34〜38%縮め(比0.66・0.63、`none`との差 −4.97pt [−6.22, −3.79]・−5.06pt)、高休養側の枝(`HI`)は変えない(比0.97・0.86)。谷は+4.7pt・+4.6pt上がる。遅れと定義の差を両方除く(`nolagdef`)と先発一致は谷で+27.0pt・+24.6pt上がるが、曲線は高休養で最も高く低休養へ下がる傾き(順方向88.0% → 79.9%)が残る(判定は`inverts`、`LO` −6.7pt [−7.4, −6.0]・−4.2pt [−5.0, −3.5])。
4. **T044の会計上の主因は、介入で確認された**(遅れを除くとU字の幅が約65〜67%縮み、雑音を除いても変わらない)。ただし(i)曲線は完全には平らにならず、遅れも定義の差も除いたあとにも休養が少ないほど先発一致が下がる小さな傾き(約2〜8pt)が残る(原因は未解明、下の事後の観察)、(ii)この介入は研究者が真の技能を推定に混ぜる反事実で、監督が実際に持てる情報の範囲の話ではない(限界)。
5. **長期(1,008日、48シーズン、世代交代あり)で、休養率36%に疲労の累積や技能の損は出ない。** 疲労は窓1(1〜168日)で最も高く、窓6では窓1の0.84倍(順方向0.842 [0.836, 0.848]、逆方向0.844)に下がる。最終技能は`base`より高く、`o(+0.030)`(36%)と`o(+0.010)`の差(`KN`)もlateで両方向とも小さく`helps`(+0.0032 [+0.0017, +0.0047]、+0.0031 [+0.0015, +0.0045]。技能は約0.77なので0.4%)。**ただし先発一致の小さな優位は長期では続かない**: 逆方向の`KN`の先発一致は窓1で+1.20pt(T044と同じ)、窓6で−0.75pt [−1.91, +0.40]、late(窓5〜6)で−0.57pt [−1.22, +0.07](有意でない)に落ち、`drift_contrast`が−1.96pt [−3.43, −0.44]で、登録の『growing cost』の旗が立った(設定t030の逆方向はlateの`KN`が`hurts`で−1.36pt [−2.2, −0.5])。登録の『遅れて出る損あり』(lateの`KN`で先発一致か技能が`hurts`)は全体では成立しない。

## 判断(登録の規則に照らして)

- 規則(i) 「`nolag`が`removes`か`flattens`で、かつ`nonoise`が`unchanged`なら『遅れがU字の因果的な原因で、雑音は原因でない』」: `nonoise`は`unchanged`で満たす。`nolag`の判定は`inverts`で、規則の字義どおりには適用できない(登録は`inverts`のあとの解釈を定めていなかった)。そこで、登録の「判定の事実」(U字の幅の縮み、`none`との対比の差の区間)をそのまま書く: `nolag`は4セルすべてで対比の差の区間の上限<0(幅が約65〜67%縮む)、比は0.18・0.23(`HI`)と−0.14・−0.02(`LO`)。遅れの除去でU字の谷が消えることは確認された。『遅れだけが原因』とまでは言わない: 遅れを除いたあとにも約2〜5ptの休養が多いほど高い傾きが残り、`LO`の−2pt(順方向)は有意。
- 規則(iv) 「`nodef`が`flattens`以上なら『定義の差も原因』」: `nodef`は`partial`で、`flattens`未満。低休養側の枝(`LO`)を約34〜38%縮めるが、高休養側の枝(`HI`)は変えない。『定義の差は低休養側の枝の部分的な原因』と書く。
- 規則(v) 『late costなし』は範囲内の主張: lateの`KN`が`hurts`にならず、技能は両方向で小さく`helps`。ただし先発一致の優位は逆方向で消え(−0.57pt、有意でない)、旗(`growing_cost`)が立ったので、「36%は長期でも先発一致を損なわない」とは言わず、「損なう証拠はないが、168日で見えた優位は長期では残らない」と書く。

## 限界・正直な注記

- 介入は、先発選びの瞬間に研究者が真の技能を推定へ混ぜる反事実で、監督が観察を増やして遅れを減らす現実の世界ではない。`nolag`の先発一致の上昇は、監督が持てる情報の範囲の話ではなく、遅れを減らす現実の方策(観察の頻度・対象)の効果の見積りでもない。差し替えた推定は[0.10, 0.98]への切り詰めをしていない。
- 先発選びの瞬間の真の技能と、集計に使う日の終わりの真の技能は、その日の試合後の成長の分だけ異なる(`top2_now`は`top2`と近い値で、結論は変わらない)。
- 4項の恒等式は項の入れ替えの順序(雑音 → 定義 → 初期印象 → 遅れ)に依存する。`nolagdef`と単独の変種の比較でしか相互作用を見ていない。
- 掃引δは期待利得への一様な加算で、個性や価値観の違いを表さない。休養率36%付近で飽和し、それより低い休養率は範囲外。疲労の害はsimの式(訓練の伸び`1−0.55×疲労`、試合の走力`1−0.18×疲労`、`0.10×疲労`の疲労の項)に限られ、怪我の仕組みは見当たらない。現実の疲労の害は測っていない。
- 長期は1,008日・3設定(`coach_belief='none'`、`generations`有効)の範囲。順方向の`o(+0.010)`は長期で45%を保たない(上記)ので、順方向の`KN`は36%対約65%の対比。選手ごとの最適休養率、個性に基づく休養の多様性(憲章1・2)は測っていない。
- 区間はセルの再標本で、世界は3seedを共有し独立でないため過小の可能性がある。単一の主指標(先発一致)。ロスターは3人。他の設定には一般化しない。
