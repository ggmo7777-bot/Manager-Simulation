## 判断規則(結果の前に固定)

- 既定は**変えない**。T042・T043・T044の推奨も変更しない。本taskは介入による因果の証拠と長期の測定を出すだけで、どの休養率が望ましいかの価値判断はしない(ユーザーの決定)。
- 失敗条件: ゲートの破れ、`none`の腕がT044の保存値と一致しない、介入が恒等でない(読み取りの写しだけでない)こと。予測の外れは失敗ではなく結果として記録。
- 解釈の規則: (i) `nolag`が`removes`か`flattens`で、かつ`nonoise`が`unchanged`なら『遅れがU字の因果的な原因で、雑音は原因でない』と書く(`nodef`の結果は別に述べる)。(ii) `nolag`が`partial`なら『遅れは寄与するが単独の原因でない』。(iii) `nolag`が`unchanged`なら『T044の会計上の主因は介入では確認されない』。(iv) `nodef`が`flattens`以上なら『定義の差も原因』。(v) 『late costなし』は、本taskの範囲(休養率36〜45%、1,008日、本simの疲労の式、怪我なし)の主張にとどめ、現実の疲労の害や個性に基づく休養の多様性には及ばない。

## 限界(結果を見る前に記す)

- 介入は、先発選びが読む推定だけを研究者が差し替える反事実で、監督が自分で観察を増やして遅れを減らす世界ではない。`nolag`は『遅れのない推定を先発選びに与えたとき』の因果であって、遅れを減らす現実の方策(観察の頻度を増やす、など)の効果ではない。遅れの除去は、真の技能そのもの(研究者だけが知る値)を推定に混ぜるので、`nolag`の先発一致の上昇は、監督が持ちうる情報の範囲の話ではない。
- 先発選びの瞬間の真の技能と、集計に使うその日の終わりの真の技能は、その日の試合後の成長(先発の試合経験)の分だけ異なる。`top2`(日の終わりの真値)に加えて`top2_now`(瞬間の真値)を報告する。
- 4項の恒等式は項の入れ替えの順序(雑音 → 定義 → 初期印象 → 遅れ)に依存する。各変種は項を1つずつ(または2つ)除く介入で、相互作用は`nolagdef`と各単独の変種の比較でしか見ない。
- 掃引δは期待利得への一様な加算で、個性や価値観の違いを表さず、simのconfigを変えた実験ではない。休養率は36%付近で飽和し、それより低い休養率は範囲外。疲労の害はsimの式(訓練の伸び`1−0.55×疲労`、試合の走力`1−0.18×疲労`、`0.10×疲労`の疲労の項)に限られ、怪我の仕組みは見当たらない。
- 長期は1,008日、3設定(`coach_belief='none'`、`generations`有効)の範囲。年度末の引退・新人で在籍の顔ぶれが入れ替わる中の測定で、技能は世代交代の平衡に引かれる。休養率は各腕の実現値で、選手ごとの最適休養率を測らない。個性に基づく休養の多様性(憲章1・2)は測らない。
- 区間はセルの再標本で、世界は3seedを共有し独立でないため過小の可能性がある。単一の主指標(先発一致)。ロスターは3人。他の設定には一般化しない。

- 差し替えは**試合日の先発選びの呼び出しだけ**に効く。`decide_club_lineup`は移籍の放出・獲得の判断(`decide_transfer_release`・`decide_transfer_acquisition`)も仮のロスターで呼ぶので、呼び出し元の関数名が`_step_matchday`でないときは実際の関数をそのまま呼ぶ(T038が先に使った区別)。移籍の判断は実際の推定を読む(登録の「先発選びだけに効く」と同じ意味)。
