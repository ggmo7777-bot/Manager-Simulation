## 監督の推定の再構成(影の推定)

監督c が選手p について持つ2つの推定 `s`(技能の推定)と `m`(試合評価の推定)は、シムの更新式 `x' = round6(clamp(w_old × x + w_new × 入力, 0.10, 0.98))` で更新される(式と重みはシム本体のもの。記録器は同じ式を研究者の側で再実装し、実際の推定との一致を検査する)。

| イベント | 技能の推定 `s`(w_old, w_new) | 試合評価の推定 `m` | 実際の入力 |
|---|---|---|---|
| `coach_session_observation` | (1−`coach_skill_alpha`, `coach_skill_alpha`) | `coach_practice_rating`が`none`でなければ (0.70, 0.30) | 記録の`obs_skill` |
| `coach_scout_observation` | (1−`coach_scout_alpha`, `coach_scout_alpha`) | (0.70, 0.30) | 記録の`obs_skill` |
| `coach_match_observation` | (1−`coach_match_skill_blend`, `coach_match_skill_blend`) | (1−`coach_match_alpha`, `coach_match_alpha`) | 記録の`rating_obs` |

初期値はシムの初期印象(`world.coaches[c].evaluations`)。新人は`season_youth_joined`のとき全監督で (0.5, 0.5)。

**4本の推定列**(各(監督, 選手)で、`s`と`m`のそれぞれ):
- `R`(実際): 記録された入力で更新。シム本体の推定と一致しなければならない。
- `A`(雑音なし): 入力を観察の目標に置き換える。練習・スカウトの観察では観察時点の真の技能 `T_obs`、試合の観察では `round6(clamp(perf_raw, 0.15, 0.98))`、`perf_raw = T_obs + 0.06×得点 + 0.015×パス成功 + 0.02×タックル勝ち + (チームが勝ちなら+0.03、他は−0.01)`(シムの式。得点・パス・タックルは`league_match_completed`の`player_stats`、勝敗は同イベントの得点)。
- `I`(定義の差もなし): 入力を全て観察時点の真の技能 `T_obs` に置き換える(初期値は`R`と同じ)。
- `Z`(初期印象もなし): `I`と同じ入力で、初期値を開始時(新人は加入時)の真の技能にする。

**誤差の項**(監督の推定 `E_R` と、`E_R`を作ったその日の終わりの真の技能 `T_now` の差。`T_now`はT043の`err`の分解と同じ「その日の終わりの真の技能」): `E_R − T_now = 雑音 + 定義 + 初期印象 + 遅れ`。
- 雑音 `noise` = `E_R − E_A`(観察雑音。legacyの世界では平均が負)
- 定義 `def` = `E_A − E_I`(推定が測るものと真の技能の差。試合評価の観察に入る出来の加点)
- 初期印象 `prior` = `E_I − E_Z`(初期印象の誤りの残り。観察の来ない選手で残る)
- 遅れ `lag` = `E_Z − T_now`(観察は来たが、その後に真の技能が動いた分。情報の古さ)

恒等式(望遠鏡): 4項の和 = `E_R − T_now`(全推定・全選手)。ユーザーの3原因の枠に合わせた**主分類は3原因**: `noise`、`def`、`stale = prior + lag`(観察の遅れ全体)。`prior`と`lag`の内訳は副分析。

**`err`の項への落とし込み**: T043の定義で、各`lineup_decision`(ロスター3人以上)の j(真の上位2人のうちスコア最小)と k(それ以外でスコア最大)を取る。w_s = `select_skill_weight`(0.55)、w_m = `select_match_weight`(0.48)。`skill`と`match`の項の誤差への寄与は `−w × (項_j − 項_k)`:
- 8項: `skill_noise`、`skill_def`、`skill_prior`、`skill_lag`、`match_noise`、`match_def`、`match_prior`、`match_lag`。
- `err = sel + fatigue + (8項の和) + round'`(T043の`sel`、`fatigue`をそのまま使い、`round' = err − sel − fatigue − 8項の和`。`skill`・`match`の項の6桁丸め由来の残り。恒等式は定義により厳密。`|round'| ≤ 5e-6` を検査)。
- 原因ごとの和: `noise = skill_noise + match_noise`、`def`、`stale = (skill_prior + skill_lag + match_prior + match_lag)`、`prior`、`lag`、`other = sel + fatigue + round'`。`err = noise + def + stale + other`。

## 記述の指標(休養率の掃引の各腕)

単位は`lineup_decision`(ロスター3人以上)と、試合の観察。T043の指標はそのまま同じ定義で再現する(先発一致 `top2`、休養率 `act_rest`、日ごとの在籍選手の真の疲労 `fatigue`、最終技能・信頼・満足度、`gap`、`err`、`signal`、T043の5項 `sel/skill/match/fatigue/round`)。T044で足すもの:
- 8項と`round'`(上記)。
- **疲労の経路**(試合の観察ごと。1回の試合で先発2人が両クラブの監督から観察される): `f`(その先発の試合前の疲労。`lineup_decision`の時点の真の疲労)、`b`(出来の加点 = `perf_raw − T_obs`)。腕ごとに平均 `E[f]`、`E[b]`、傾き `slope = Cov(f, b)/Var(f)`(腕内の先発の観察をまたぐ最小二乗)。
- **情報の古さ**: 各`lineup_decision`でロスター全員について、`s`・`m`が最後に更新されてからの日数の平均(`age_s`、`age_m`)。
- **曲線との関係**: 各方向10点で、`top2`の水準と`err`の水準の相関 `corr(top2, err)`。

## 統計(結果を見る前に固定)

- 不確かさ: セルの再標本(bootstrap 1000回、固定seed 41)による95%区間(パーセンタイル)。全腕・全統計・対比・傾き・相関が同じ再標本を共有する。設定別(各84セル)と全体(252セル)。世界は3seedを共有し独立でないので区間は過小の可能性がある。「有意」= 区間が0を含まない。
- 水準 = 腕の全決定(または全観察)の平均(セルの再標本ごとに比の形で再計算)。
- **3つの対比**(方向ごと。δは腕を指す): `LO` = `o(+0.030)` − `o(−0.010)`(低休養端 − 谷。休養率およそ36% − 75%)、`HI` = `o(−0.030)` − `o(−0.010)`(高休養端 − 谷。およそ90% − 75%)、`KN` = `o(+0.030)` − `o(+0.010)`(膝の下 − 膝。およそ36% − 42〜45%)。全指標について対比の差と区間を出す。谷の腕(δ=−0.010)と膝の腕(δ=+0.010)はT043の曲線からの前もっての指定で、本taskの値から選び直さない。
- **対比の分担**(`LO`・`HI`・`KN`ごと、方向ごと): `Δerr` と、各原因 `x ∈ {noise, def, stale, other}` の `Δx`、`share_x = Δx/Δerr`(和は厳密に1)。`stale`の内訳 `share_prior`、`share_lag`。推定ごと(`s`の4項の和、`m`の4項の和)の分担も出す。
- **原因の分類**(対比×方向の各点で、この順に最初に当てはまるもの): `no_err_change`: `Δerr`の区間が0を含む。適格 = `Δx`の区間が0を含まず、`Δerr`と同じ符号の原因 x ∈ {noise, def, stale}。主 = 適格かつ `share_x ≥ 0.5`(点推定)。`single(x)`: 主がちょうど1つ。`multiple(x…)`: 主が2つ以上。`distributed(x…)`: 主がなく適格が2つ以上。`partial(x)`: 主がなく適格が1つ。`none`: 適格がない。旗(分類を変えない): `opposed(x)` = `Δx`の区間が0を含まず`Δerr`と逆符号。`stale`の内訳の主(`prior`か`lag`か。`share ≥ 0.5 × share_stale`)。
- **疲労の経路の判定**: `KN`・`LO`で、`E[f]`・`E[b]`の対比と区間。傾き `slope` の水準の区間(各腕)。**『休養が少なすぎると損』の判定**(`KN`、方向ごと、`top2`と最終技能): 区間の上限<0 なら `hurts`、下限>0 なら `helps`、他は `flat`。
- 副分析: 設定別(t030、t031、t032)、掃引の全10点の水準の表。

## 予測(反証され得る。事前の信頼を併記。値は全体252セル、特記なければ両方向)

事前の考え方(T043と1セルの記述に基づく仮説): 監督は試合に出た先発だけ試合評価の観察を受ける(加点つきで、真の技能より約+0.06高い)。控えは自チームの監督からは試合の観察を受けず、練習の観察もほとんど無い(練習の観察はt030で4件)。控えの推定は古いまま残り(遅れ・初期印象)、先発の試合評価の推定は加点分だけ上に乗る(定義の差)。したがって先発の入れ替えは定義の差と遅れに逆らわれると考える。疲労は先発の試合の実効の能力(走力は疲労1につき18%、パスとシュートは10%減)を下げ、出来の加点を減らす。それが定義の差を小さくして入れ替えを助けるのか、先発一致を損なうのかは分からない。

- **P1(機構)**: ゲート1〜7が通る。信頼75%。
- **P2(再現)**: 20腕のT043の指標が1e-12で一致(ゲート3)。決定的で信頼95%。
- **P3(影の厳密性)**: ゲート4が破れない。信頼85%。
- **P4(`err`の変化)**: `LO`の`Δerr`の区間の上限<0(両方向)。信頼95%。`HI`の`Δerr`の区間の上限<0(両方向)。信頼85%。
- **P5(曲線との関係)**: `corr(top2, err)`≤ −0.9(両方向)。信頼85%。
- **P6(`LO`の主因)**: 両方向で同じ分類。`single(def)` 30%、`single(stale)` 20%、`multiple(...)` 15%、`distributed(...)` 10%、`partial(...)` 10%、`single(noise)` 5%、`no_err_change`または`none` 10%。
- **P7(`HI`の主因)**: 両方向で同じ分類。`single(stale)` 30%、`single(def)` 25%、`multiple(...)` 10%、`distributed(...)` 10%、`partial(...)` 10%、`single(noise)` 5%、`no_err_change`または`none` 10%。

- **P14(`KN`の`err`)**: `KN`の`Δerr`が両方向で0を含む(信頼55%)。
- **P15(古さ)**: `age_m`(試合評価の推定の更新からの日数)は、休養率が低いほど短くならない(`LO`で`Δage_m`の区間が0を含むか正。信頼55%)。観察の件数は休養率でほぼ決まらないと考える。

## 限界(結果を見る前に記す)

- 影の推定`A`・`I`・`Z`は、実際に起きた観察の列(実際の先発・実際の監督の行動)を保ったまま入力だけを置き換えた反事実の再構成で、置き換えた入力に応じて監督が別の判断をした世界ではない。項の分担は、更新式の線形な重みと丸め・端の切り詰めを通した恒等式であって、独立な効果の加法分解ではない(相互作用は4項の入れ替えの順序で割り振られる: 雑音 → 定義 → 初期印象 → 遅れ)。
- 『定義』の項は、出来の加点の系統的な平均と、試合ごとの運(得点・パスの偶然)を区別しない。『雑音』は観察雑音の平均(legacyの世界では負)と散らばりを区別しない(`j`と`k`の差を取る際、両者に共通の平均は打ち消される)。
- 真の技能は、T043と同じく、その日の終わりの値。試合日の終わりの試合経験の成長(先発だけに入る)が『遅れ』の項に入る(試合日の先発の成長は約0.03×伸びしろの小さな値)。
- 掃引δは期待利得への一様な加算で、人間の価値観・個性(休養選好)の違いを表さず、simのconfigを変えた実験ではない。休養率は36%付近で飽和し、それより低い休養率は掃引の範囲外。『休養が少なすぎる』は掃引の範囲(最低36%)での判定で、それより下は測れない。168日を超える長期の疲労の害は測らない(怪我の仕組みは本simに見当たらない)。
- 休養率は各方向の腕の平均の実現値で、選手ごとの最適休養率を測らない。望ましさの基準の重みは決めない。個性に基づく休養の多様性(憲章1・2)は測らない。
- 区間はセルの再標本で、世界は3seedを共有し独立でないため過小の可能性がある。単一の主指標(先発一致)。ロスターは3人。3設定は`coach_belief='none'`で、他の設定には一般化しない。
