## 差し替え(view)の定義

- 状態の4つの要素を `g`(期待利得A/B)、`f`(疲労知覚)、`t`(コーチ別の信頼)、`s`(自己推定)と呼ぶ。練習の選択の差し替えは、`g`・`f`・`t`の部分集合S ⊆ {g, f, t}をalt側の値に置き換えて関数を呼び、呼出し後に必ず戻す(例外でも)。応答の差し替え`R`は4要素全てを置き換える(関数が読むのは`t`だけなのでT041の応答の差し替えと同じ)。呼ぶ関数は乱数・副作用なしの純関数。
- 全ての腕で、練習の選択を**素の状態**、`{g}`、`{f}`、`{t}`、`{g,f,t}`、`{s}`の6通りの状態と、その腕が実行するSの状態(上と重なるもの以外)で呼び、判断と理由コードの違いを記録する。腕のSの結果を実行に返す(Sが空なら素の結果)。`R`を含む腕は応答も同様に素とaltで2回呼び、altの結果を実行に返す。2回目以降の呼出しは判断の記録を作らない。
- 世界の本物の状態(`real`)は常にsim本体が更新する。更新(信頼・期待利得の学習)は差し替えない。決定の記録(イベント)にはその決定が使った値が残る。

## 指標と統計(結果を見る前に固定)

- 単位は`lineup_decision`(24,192件/腕/設定。全設定72,576件)。**先発一致(主指標)** = 実際の先発が真の上位2人(真の技能、同点はid)と一致する割合(T037〜T041と同じ)。
- 効果(先発一致の差、pt。副指標も同じ形): **D** = `rev_base` − `fwd_base`。**F_X**(十分性) = `fwd_X` − `fwd_base`。**R_X**(必要性) = `rev_base` − `rev_X`。X ∈ {g, f, t, gf, gt, ft, gft, R, tR, gftR}。比 f_X = F_X/D、r_X = R_X/D。
- **変数間の非加法性**: I_F = F_gft − (F_g + F_f + F_t)、I_R = R_gft − (R_g + R_f + R_t)、i = I/D。2変数の相互作用 I_gf = F_gf − F_g − F_f(gt、ftも。FとR)。**Shapley配分**: 3変数の8つの部分集合の効果(F、R別)から、各変数の順序平均の寄与φ_vを出す(φ_g = (F_g)/3 + (F_gf − F_f)/6 + (F_gt − F_t)/6 + (F_gft − F_ft)/3 など。Σφ = F_gft)。φ_v/DとΦ_v/F_gft(配分の割合)を報告する。
- **応答×練習の相互作用**(Rは応答): 応答の効果を練習の状態ごとに出す。順方向 Fr(p) = fwd_{p+R} − fwd_p(p ∈ ∅, t, gft。∅のときは`R`、tは`tR`−`t`、gftは`gftR`−`gft`)、逆方向 Rr(p) = rev_p − rev_{p+R}。相互作用 Ir_F = Fr(gft) − Fr(∅)、Ir_R = Rr(gft) − Rr(∅)(= F_gftR − F_gft − F_R の形)。信頼の2つの用途の相互作用 It_F = F_tR − F_t − F_R、It_R = R_tR − R_t − R_R。
- **媒介**(記述的・統計的な分解。因果の同定ではない。下記)。
- 不確かさ: セルの再標本(bootstrap 1000回、固定seed 41)による95%区間(パーセンタイル)。全腕・全統計・媒介が同じ再標本を共有する。設定別(各84セル)と全体(252セル)を出す。世界は3seedを共有し独立でないので区間は過小の可能性がある。「有意」= 点の差の95%区間が0を含まない。
- 副指標(帰属規則には使わない): セル平均の最終技能・最終満足度・最終信頼・移籍数、昇格率4種、監督の練習枠の選択、判断・理由の指標(下記)、助言に従った割合`follow`、**従う判断の上書き**(`override_rest`: 助言に従う(follow)の判断が、自分のスコアでは休養を選んだ日に練習をさせた割合、`override_method`: 自分のスコアでは別の方法を選んだ日に提案された方法をさせた割合。分母は練習の判断の全件)。

### 媒介の定義

先発一致の分解のため、各`lineup_decision`(ロスター3人以上)で研究者が真の技能と監督のスコアを読み、次を記録する(真の値は何も戻さない)。真の上位2人 = `true_set`、`ranking`の`score`(監督の先発選びのスコア)。
- `gap` = 真の技能の2番手 − 3番手(**広がり**。技能の成長と差のつき方)。
- `signal` = min(true_setの選手のscore) − max(それ以外の選手のscore)。signal > 0 ⇔ 先発が真の上位2人(同点を除く)。
- `err` = (select_skill_weight + select_match_weight) × `gap` − `signal`(**観察の誤差**: 監督のスコアが真の差をどれだけ縮めた/ゆがめたか。`signal` = 係数×`gap` − `err`)。
- `rest` = 練習の判断の実行された休養の割合。

単位は「(セル, 腕)」。各セルで、方向ごとに`base`との差分 Δ(rest, gap, err, 先発一致)をとり、非基準の20腕(各方向10腕)を行とする(切片なしの回帰)。
- 総効果 c: Δ先発一致 ~ Δrest。a_gap, a_err: Δgap ~ Δrest、Δerr ~ Δrest。b: Δ先発一致 ~ Δrest + Δgap + Δerr(c' = Δrestの係数、b_gap、b_err)。間接効果 = a×b。恒等的に c = c' + a_gap·b_gap + a_err·b_err。
- 報告は「休養率10pt当たりの先発一致のpt」。**主分析 = 全20腕**。副分析 = 練習の状態の腕のみ(g, f, t, gf, gt, ft, gft。応答の腕を除く)、方向別、設定別。
- 媒介の判定(全体252セル、主分析の区間で、この順): `no_total`: cの区間が0を含む。それ以外は、cと同じ符号で区間が0を含まない間接効果の集合Mを求め、`unmediated`(Mが空)、そうでなければ `mediated(M)`(M ⊆ {gap, err})に、`complete`(Σ間接/c ≥ 0.8(点推定)かつc'の区間が0を含む)または`partial`を付ける。
- 限界: 腕は練習の判断の差し替えで、休養率だけを動かすのではない(方法の選択・助言への従いも変わる)ので、休養率は純粋な外生変数ではなく、除外制約は成り立たない。媒介は腕の間の変動に対する統計的な分解で、休養率の因果効果の同定ではない。

## 帰属規則(結果の前に固定。全体252セルで、この順に最初に当てはまるもの)

担い手(carrier) = 変数 v ∈ {g, f, t} で F_vの区間の下限>0 かつ R_vの区間の下限>0。主経路 = 担い手かつ f_v ≥ 0.5 かつ r_v ≥ 0.5(点推定)。

0. `no_practice_gain`: F_gftまたはR_gftの区間の下限 ≤ 0(T041の結果が再現しない)。
1. `single_variable(v)`: 主経路がちょうど1つ。
2. `multiple_variables(v, …)`: 主経路が2つ以上。
3. `distributed(v, …)`: 主経路がなく、担い手が2つ以上。
4. `partial_single(v)`: 主経路がなく、担い手がちょうど1つ。
5. `only_jointly`: 担い手がない(3変数が合わさって初めて効く、または2変数の組)。併記: 担い手の組(gf, gt, ft のうちF、Rの下限がともに>0のもの)`pair_carriers`。
旗(分類を変えない): `interaction_vars` = |i_F| ≥ 0.25 または |i_R| ≥ 0.25 かつ対応するI_F/I_Rの区間が0を含まない。`opposed(v)` = F_vまたはR_vの区間の上限<0(その変数だけの差し替えが先発一致を下げる)。設定別にも同じ規則を当てて報告する(判断規則には全体のみ使う)。

## 予測(反証され得る。事前の信頼を併記。値は3設定合計)

事前の考え方: 水準のずれだけを見ると、疲労知覚の低さ(legacy)は練習に有利、期待利得の低さは休養に有利に働き、互いに相殺しうる。したがってT041の差(legacyが練習日の約2/3を休む)は、水準でなく散らばり(観察雑音の幅。centered_v1は半分)や学習の経路依存(期待利得は練習した方法だけ更新される)に由来するかもしれない。信頼は助言が来た日の提案された方法にしか効かないので小さいと考える。応答は`follow`が休養を上書きする場合に先発一致へ効くと考えるが、符号は事前に定まらない。

- **P1(機構)**: ゲート1〜9が通る。信頼約80%。
- **P2(再現)**: F_gft、R_gft、F_R、R_R、Dがそれぞれ T041の値と一致(1e-12)。決定的なので信頼95%。
- **P3(担い手の存在)**: 3変数のうち少なくとも1つが担い手(F、Rの下限がともに>0)。信頼60%。
- **P4(期待利得が最大)**: F_gが3つの単独の中で最大、かつR_gも最大。信頼50%。
- **P5(信頼は小さい)**: |F_t|<1.0pt かつ |R_t|<1.0pt。信頼65%。
- **P6(疲労は逆向き)**: F_f<0 かつ R_f<0(点推定。水準のずれが疲労では逆向きに効く)。信頼40%。
- **P7(主経路)**: 帰属が`single_variable(g)`。信頼30%。他の分類の事前確率: `multiple_variables` 10%、`distributed` 20%、`partial_single` 15%、`only_jointly` 15%、`single_variable`(g以外) 10%。
- **P8(非加法)**: 旗`interaction_vars`が立つ。信頼55%。
- **P9(判断の変わる量)**: `fwd_base`で `flip_Pg` ≥ 10%、`flip_Pf` ≥ 10%、`flip_Pt` < 3%。信頼はそれぞれ55%、55%、65%。`flip_Ps` = 0は信頼99%(ゲート7)。
- **P10(理由の変わり方)**: `fwd_base`で、疲労だけの差し替えで判断が変わった決定のうち、変わる前後のいずれかの理由が`rest:fatigue_recovery_need`であるものが過半、かつ期待利得だけの差し替えで判断が変わった決定のうち、変わる前後のいずれかの理由が`method:expected_gain`であるものが過半。信頼35%(T041のP13は外れた)。
- **P11(媒介の総効果)**: 全体のcの区間が0を含まず負(休養が多いと先発一致が下がる)。信頼75%。
- **P12(媒介の経路)**: 間接効果が有意なのは gap 経由 50%、err 経由 30%、両方 15%。判定が`complete` 20%、`partial` 40%、`unmediated` 25%、`no_total` 15%。
- **P13(応答の害)**: Rr0の区間の上限<0(T041の害の再現)は信頼95%(決定的)。分類は `practice_dependent` 40%、`practice_independent` 30%、`partly_dependent` 25%、`not_reproduced` 5%。
- **P14(従うの上書き)**: 逆方向で`R`(応答だけをlegacyの信頼で)は`follow`を下げる(`rev_R`の`follow` < `rev_base`の`follow`)。信頼80%。
- **P15(設定間の一貫)**: 帰属の分類が3設定とも全体と同じ。信頼35%。
- **P16(推奨)**: 下の規則で「推奨」になる。信頼25%(P13が`practice_dependent`で、かつ媒介が`unmediated`でないことが要る)。

## 判断規則(結果の前に固定)

- 既定は**変えない**。推奨は提案のみ(別taskで、凍結成果物の基準の置換を伴う)。
- centered_v1を既定にする提案の推奨度(全体252セルで):
  - **推奨**: (a) Dの区間の下限>0、最終技能・最終信頼の差の区間の下限がともに≥0、3設定ともD>0、(b) f_gft ≥ 0.5 かつ r_gft ≥ 0.5(点推定)、(c) 帰属が`single_variable`・`multiple_variables`・`distributed`・`partial_single`のいずれか、(d) 応答の害の分類が`practice_dependent`または`not_reproduced`(害が練習の選択との相互作用として説明される)、(e) 媒介の判定が`unmediated`でも`no_total`でもない(休養率から先発一致への道筋が少なくとも1つ説明される)。
  - **条件つき**: (a)のDの下限>0と最終技能の下限≥0を満たすが、(b)〜(e)のどれかを満たさない。満たさなかった項目を列挙し、別taskで解消する課題とする。
  - **保留**: 上のどちらも満たさない。この場合も「centered_v1が悪い」ではなく「機構が未説明」。
- 失敗条件: ゲートの破れ、追跡や差し替えによるsim結果の変化、T041保存値との不一致。予測の外れは失敗ではなく結果として記録。

## 限界(結果を見る前に記す)

- 差し替えは判断の瞬間の状態だけで、状態の更新は世界の方式のまま。`alt`は同じ観察と行動の列を別の雑音で更新した再構成であり、実走の履歴とは同じでない。部分集合の差し替え(例: 疲労だけ)は、世界の方式の疲労と、altの期待利得・信頼の組合せという、実際には起こらない状態の組を判断に読ませる。
- centered_v1は平均だけでなくばらつきも半分にする(T037)。本taskの「alt」は両方を含み、水準かばらつきかは区別しない。変数ごとの`shift_*`は水準のずれと散らばりのずれの記述にとどまる。
- 媒介は統計的な分解で、休養率の因果効果の同定ではない(上記)。`gap`と`err`は先発一致を恒等的に決める(`signal` = 係数×`gap` − `err`)ので、b経路が有意になるのは構成による。問いは、a経路(休養率が`gap`と`err`を動かすか)である。
- 理由コードは記録された内訳の最大項に研究者が付けたラベルで、選手の内面の説明ではない。
- 単一の指標(先発一致)への帰属で、他の指標は記述にとどまる。ロスターは3人(先発2人、控え1人)で、世界は3seedを共有する。
- 3設定は`coach_belief='none'`なので、応答が監督の信念を介して先発一致に届く道は構造上ない。他の設定(`coach_belief`あり)には一般化しない。
