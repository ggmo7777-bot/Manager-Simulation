## 固定する条件

Python 3.13.3(uv)。T037と同じ84セル(14世界×seed{100,101,102}×開始年齢{29,33}、168日、`season_length_days=21`)を3設定(`t033.SETTINGS`)で、`observation_noise_mode`の`legacy`/`shifted_v1`/`centered_v1`の3群で実行(756実行)。`soccer_sim/`は凍結T037 source_bundleとバイト一致。研究者だけが真の技能を使い、何も戻さない。

設計の事実(コードを読んだだけ。結果は未確認): 試合は7日ごと(`match_interval_days=7`)。推定は観察のたびに指数平均で更新され、`last_seen_day`はその日付(新人は入団日、初期の選手は0)。先発は`decide_club_lineup`の`select_skill_weight×技能推定 + select_match_weight×試合評価推定 − select_fatigue_weight×疲労推定`の上位2人で、試合に出た選手は両監督に観察される。T037の一試合の1クラブ単位の`lineup_decision`(84セル×168日×4クラブ)を分析単位とする。

## 測定(記録は`decide_club_lineup`呼び出し時点の状態。真の技能は、T036/T037と同じく、その日の進行後の`composite_skill()`)

- **経過日数** a = 試合日 − `last_seen_day`(そのクラブの監督の、その選手についての値)。5区分(結果を見る前に固定): a≤6 / a=7 / 8≤a≤13 / 14≤a≤27 / a≥28。粗い3区分は 新しい(a≤7)/ 中(8〜13)/ 古い(a≥14)。
- **群**: 新人以外(T036の`inc`)/ 新人(自クラブの入団後1〜21日、T036の`new`)/ 全員(その他の新人を含む)。定義はT036と同一。
- **M1 推定誤差**: 群×経過日数区分ごとの技能推定−真の技能、試合評価推定−真の技能(平均、MAE、n)。勾配 G = 古い(a≥14)の平均誤差 − 新しい(a≤7)の平均誤差(新人以外の技能推定)。
- **M2 対の正答率**: 各`lineup_decision`の全ての選手対(真の技能の差≥0.02)で、スコア(先発の順位を決める総合点)の順序が真の順序と一致する割合。対を 真に上の選手が新しい(経過日数が7日以上小さい)/ 古い(7日以上大きい)/ 近い(差7日未満)に分ける。差 D = 新しい側が上の対の正答率 − 古い側が上の対の正答率。
- **M3 取り違え**: 真の上位2人(真の技能、同点はid)と先発の集合の差。「漏れた上位選手」(真の上位2人なのに先発でない)と「入った非上位選手」(先発なのに上位2人でない)の経過日数と技能推定誤差の平均を、先発の取り違えがあった`lineup_decision`だけで出す。差 E = 入った選手の経過日数 − 漏れた選手の経過日数。
- **M4 反実仮想(同じ状態の再順位付け、研究者のみ)**: 各群で経過日数区分 b の補正 δ_b = select_skill_weight×(b区分の技能推定誤差の平均 − 全区分の平均) + select_match_weight×(b区分の試合評価推定誤差の平均 − 全区分の平均)。**補正の推定は別の設定の全セルのプールだけから行う**(leave-one-setting-out。t030にはt031+t032、など)。各選手のスコアから δ_b を引いて上位2人を再選択し、先発一致率の変化 C = 一致率(補正後) − 一致率(実際)を出す。全員に同じ定数を引いても順位は変わらないので、効くのは区分の間の差だけ。
- 各統計の不確かさ: セルの再標本(bootstrap 1000回、固定seed 38)による95%区間(3群は同じ再標本を共有し、群間の差は対)。世界は3seedを共有し独立でないので区間は過小の可能性がある。

## 予測(反証され得る。事前の信頼を併記。値は新人以外・3設定合計)

仮説H: `legacy`では観察を受けた選手(新しい)の推定の方が、古い選手より多く下がる。平均を直すと「新しい」の推定が古い選手より多く上がり、相対順位が直る。
- **P1(機構)**: ゲート1〜4が通る。信頼約90%。
- **P2(平均の補正の効き方に新しさの差がある)**: 技能推定の誤差の変化(shifted−legacy)は、全区分で正で、新しい(a≤7)の方が古い(a≥14)より0.004以上大きい(つまりGがshiftedで0.004以上小さくなる: G_shifted − G_legacy ≤ −0.004)。信頼約60%。(観察の少ない選手ほど、平均補正のかからない初期値の重みが大きいため。)
- **P3(対の順位)**: legacyでは真に上の選手が新しい対の正答率が、古い対より低い(D_legacy ≤ −0.02)。shiftedではD_shiftedの絶対値がlegacyの半分以下。信頼約50%。
- **P4(取り違え)**: legacyでは先発に入った非上位選手の方が、漏れた上位選手より古い(E_legacy ≥ +1.5日)。shiftedでは|E|がlegacyの半分以下。信頼約45%。
- **P5(反実仮想、機構の本命)**: legacyの状態に区分補正(M4)を適用すると、先発一致率の上昇Cは、T037の平均側の寄与(+7.0pt)の半分以上(C_legacy ≥ +3.5pt)。信頼約40%。(外れた場合の読み: 利得は静的な順位のゆがみでなく、観察の配分が変わる動的な経路。)
- **P6(shifted/centeredでは補正が効かない)**: shiftedとcenteredでは同じ補正のCの絶対値が1.5pt以下。信頼約60%。
- **P7(観察の配分は主因でない)**: 先発の試合日の選手の平均経過日数は、3群で差が0.5日以内。信頼約60%。(観察の頻度が変わって利得を生む経路の対照。)
- **P8(新人)**: 新人では経過日数が入団日からなので区分間の差が小さく、新人の技能推定誤差の変化(shifted−legacy)は経過日数区分でほぼ一定(最大と最小の差0.01以内)。信頼約45%。
