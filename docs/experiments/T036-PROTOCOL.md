# T036 事前実験条件

2026-11-11、実装前登録(結果を見る前)。契約: [T036](../tasks/T036.md)。結果を見て方法・定義・閾値・予測を変えない。外れた予測は結果として記録する。調整(幅・係数・設定)はしない。

## 固定する条件

Python 3.13.3(uv)。T033〜T035と同じ84セル(14世界×seed{100,101,102}×開始年齢{29,33}、168日、`season_length_days=21`)を3設定(T030/T031/T032の有効設定、`t033.SETTINGS`)で、`observation_noise_mode`のlegacy/centered_v1の2群で実行する(計504実行)。研究者だけが真の技能・疲労を使う(simへ戻さない)。

## 実装の約束(変えるのは雑音の平均だけ)

- `observation_noise_mode`の既定は`"legacy"`で、現行の式を1バイトも変えずに使う: 技能観察は`(u−0.5)×2.0×幅`、疲労観察は`(2u−1)×幅`。`"centered_v1"`は両方とも`u×幅`(`u∈[−1,1]`の同じ引き、[−幅,+幅]の対称一様)。
- `uniform_from_key`の呼び出し(キー、回数、順序)は変えない。コードのAST上の呼び出し数がT035のbundleと同一で、同じ状態・同じキーなら`centered−legacy = 幅×(1−u)`であること(観察値は`round6(clamp(…))`で同じ後処理)。
- save: configにキー`observation_noise_mode`が出るのは既定以外のときだけ。`has_save_fields`の任意キーに追加し、不明な値は拒否。既定のconfig辞書・snapshot・指紋はキーが増えない(ただしsource hashは12実行ファイルの変更で変わり、旧snapshotは従来どおり拒否される)。
- 疲労観察は`observe_fatigue`の任意引数(既定は現行)、5つの呼び出しだけがconfigの値を渡す。他のモジュール(旧selection_loop/transfer_loop/match_2d)は触らない。

## 測定(各セル、legacy/centered別。全て記録されたイベントと研究者の真値から)

行の定義はT035と同じ: 新人行=入団翌日〜+21日の`lineup_decision`での新人(そのセルで`season_youth_joined`した選手)、新人以外の行=同じ`lineup_decision`の順位表の他の選手。`lineup_decision`ごとの真値はその日の終わり。
- **M1 観察誤差(イベント種別別)**: 練習日(`coach_session_observation`)・偵察(`coach_scout_observation`)の`obs_skill−真の技能`、自己観察(`player_self_observation`、試合の無い日のみ)の同じ誤差の平均(と標準偏差)。clampは含め割合も報告。試合観察は基準値`perf_raw`が記録されないため直接測らない(推定の誤差で見る)。
- **M2 疲労観察誤差**: `observe_fatigue`の戻り値−真の疲労の平均を、5つの呼び出し文脈(training_self、match_self、training_coach、scout、match_coach)別に、実行中の記録(関数の呼び出しを観測する)から。clamp(0または0.95)の割合も報告。
- **M3 推定誤差**: `lineup_decision`時点の技能推定(`skill_term/w_skill`)と試合評価推定(`match_term/w_match`)の真の技能との差の平均(偏り)とMAEを、新人行(窓全体、1〜7/8〜14/15〜21日)と新人以外の行で。
- **M4 先発**: 全`lineup_decision`で記録された先発が、順位表の選手の真のcomposite skill上位2人(同値はid順)と一致する割合。新人の先発割合(新人行のうち先発だった割合、T033の定義)。
- **M5 最終結果**: 168日後の技能・満足度・信頼・移籍数(`t030.final_metrics`)と、イベント総数、観察イベント数(種別別)。セルごとの対(centered−legacy)の平均・符号検定・t=平均/(標準偏差/√n)。
- 集計: 行は設定別と3設定合計、セル平均の差も報告。比較は同じセル(同じ世界・seed・開始年齢)の対。履歴は雑音の変化で分岐するため、セル内の差は因果効果の推定ではなく「雑音の平均を変えた世界での値」の比較。

## 成功条件(ゲート。どれかが破れたら結果を出さずに原因を直す、または失敗として記録)

1. **legacy = 凍結**: legacy群の3設定×84セルが、T030/T031/T032の保存済みsummaryの最終値・イベント数と全て一致(252/252)。さらに6セルで、凍結T035のsource_bundleを別プロセスで読み込んだ実行とイベント列の全体hashが一致(既定のconfigにキーが出ないことも)。
2. **RNG消費が同一**: AST上の`uniform_from_key`の呼び出し数が、変更したファイル(league_economy、league_observation)でT035のbundleと同じ。1日目(分岐前)のキーの列がlegacy/centeredで同一。同じキーでの雑音の差が`幅×(1−u)`(技能)・疲労でも同じ。
3. **中心化が効いている**: centered群のM1(練習日・偵察)の平均誤差の絶対値が、全設定で0.003以下。M2の疲労観察の平均誤差の絶対値が0.005以下(clamp除く、文脈別)。legacy群は練習日・偵察で−幅±0.003。
4. **save/reader**: 既定configの辞書にキーが無い、centeredでは`"observation_noise_mode":"centered_v1"`が出る、`from_dict`の往復、不明な値・空・非文字列の拒否、snapshotの保存・読込・分岐、改変の拒否が動く。`_validate_league_invariants`が全504実行で通る。
5. **凍結成果物**: 旧成果物のinventory(`artifacts/t036/preflight/`)のhash不変、source_bundle保存、全unittest合格(3.13.3)。

## 予測(反証され得る。事前の信頼を併記。T035の線形伝播に基づく)

- **P1(機構)**: ゲート1〜4が全て通る。信頼約90%。
- **P2(観察誤差)**: legacyの平均誤差は練習日−0.024、偵察−0.030、自己−0.018(各±0.003)、centeredは全て0±0.003。疲労観察の平均誤差の差(centered−legacy)は各文脈でほぼ幅(0.025/0.025/0.045/0.065/0.050、clamp分だけ小さい、±0.005)。信頼約85%。
- **P3(新人以外の偏り、悪化する)**: 新人以外の技能推定の平均誤差はlegacyで約0(|平均|<0.005)、centeredで正になり+0.008〜+0.018、MAEは増える(3設定のうち2設定以上)。T035の「別の正の偏りが約+0.013ある」の予測の再確認。信頼約65%。
- **P4(新人)**: 新人行(窓全体)の技能推定のMAEは下がる(centeredのほうが小さい、3設定のうち2設定以上)、平均誤差は負のまま(15〜21日で−0.10から約−0.09、−0.05以下)。信頼約65%。
- **P5(試合評価推定)**: 新人以外の試合評価推定の平均誤差(legacy約+0.015)はcenteredでさらに正に動く(+0.002以上)。信頼約60%。
- **P6(先発)**: M4の「真の上位2人との一致率」の変化は±2pt以内、新人の先発割合の変化は±3pt以内(符号は負が多い、−1pt前後)。信頼約60%。
- **P7(最終結果)**: 最終の技能・満足度・信頼は、3設定合計のセル対で|t|<3(0と区別できない)。移籍数は平均の差が±1以内。信頼約55%(履歴が分岐するので雑音が大きい)。
- **P8(観察数)**: 観察イベント総数の変化は±2%以内。信頼約75%。
- **P9(新人の遅れ)**: 新人の15〜21日の技能推定誤差は、centeredでも−0.05以下で残る(T035の判断規則(ii)の再確認)。信頼約80%。

## 判断規則(結果の前に固定)

- 既定は**変えない**(T036でlegacyのまま)。ゲート1〜5が通れば`centered_v1`は「版つきの選択として採用(試用)」。ゲートが破れれば撤回して原因を記録。
- 既定をcenteredへ移す判断は別のtask(D記録と凍結成果物の基準の置換)でのみ行う。T036の結果(P3の悪化を含む)は隠さず、悪化が確認されたら「中心化は不具合の修正だが、別の正の偏りが残るため推定が過大になる。その偏りの分解が先」と記録する。
- 失敗条件: 上のゲートの破れ、centered群の実行で例外・不変条件違反、legacy群が凍結と1セルでも違う。予測の外れは失敗ではなく結果として記録。
