### (a) 水準かばらつきか — 帰属規則(全体252セル、この順に最初に当てはまるもの)

0. `no_gain_effect`: F_gまたはR_gの区間の下限 ≤ 0(T042の結果が再現しない)。
1. `level`: Lのみが主経路。
2. `spread`: Sのみが主経路。
3. `level_and_spread`: 両方が主経路。
4. `partial(<名>)`: 主経路がなく、担い手が1つ以上(担い手の名前を列挙)。
5. `only_jointly`: 担い手がない(`g`は運ぶが、水準だけでも散らばりだけでも運ばない)。
旗(分類を変えない): `non_additive` = |I_F| ≥ 0.25×F_g または |I_R| ≥ 0.25×R_g かつ対応するIの区間が0を含まない。`opposed(<名>)` = F_XまたはR_Xの区間の上限<0。

### (b) `err`の項別分解

先発一致の分解(T042と同じ定義、研究者が真の技能とスコアを読む。真の値は何も戻さない)。各`lineup_decision`(ロスター3人以上)で、`true_set`(真の上位2人)、監督の`ranking`の`score`。
- `gap` = 真の技能の2番手 − 3番手。`signal` = min(true_setのscore) − max(それ以外のscore)。`err` = (select_skill_weight + select_match_weight)×`gap` − `signal`。
- **項別**: j = true_setのうちscoreが最小の選手、k = それ以外でscoreが最大の選手。T_j、T_kはその真の技能、`skill_term`/`match_term`/`fatigue_penalty`(≤0)は`ranking`の記録。w_s、w_mは`select_skill_weight`(0.55)・`select_match_weight`(0.48)、scale = w_s + w_m。
  - `sel` = scale×(`gap` − (T_j − T_k)) 〔選び方: 監督の並びで境目にいる2人の真の差が、真の2番手−3番手の差より大きい分(≤0)〕
  - `skill` = w_s×(T_j − T_k) − (j・kの`skill_term`の差) 〔技能の推定が真の差を縮めた/ゆがめた量〕
  - `match` = w_m×(T_j − T_k) − (j・kの`match_term`の差) 〔試合評価の推定の同様の量〕
  - `fatigue` = −(j・kの`fatigue_penalty`の差) 〔疲労の推定の項。真の技能の選抜には本来ない項なので全てを誤差とする〕
  - `round` = −(`signal` − (3つの項の差の和)) 〔`score`の丸めの残り〕
  - 恒等式: `sel + skill + match + fatigue + round = err`(全決定で1e-9以内。破れたら中止)。
- 媒介(T042と同じ定義の拡張): 単位は(セル, 腕)。各セルで、方向ごとに`base`との差分 Δ(休養率, `gap`, `err`, 先発一致, `sel`, `skill`, `match`, `fatigue`, `round`)をとり、非基準の腕を行とする(切片なしの回帰)。総効果 c(Δ先発一致 ~ Δ休養率)、a_gap、a_err、b(Δ先発一致 ~ Δ休養率 + Δgap + Δerr: c'、b_gap、b_err)、間接効果、割合(T042と同じ)。**項別**: a_part = (Δpart ~ Δ休養率の傾き)、間接効果 ind_part = a_part×b_err、`share_part` = a_part/a_err(Σ share = 1)。報告は休養率10pt当たり。
- 腕の集合: **主分析 = 全腕**(`g`、`L`、`S`、掃引9本の各方向、計24腕)。副分析 = 掃引のみ(18腕。休養率だけをほぼ一様に動かす操作に近い)、差し替え3種(6腕)、方向別、設定別。
- 判定: T042の媒介の判定(`no_total`、`unmediated`、`mediated(M):complete/partial`)をそのまま全体の主分析と副分析に当てる。
- **`err`の出所の分類**(全体、主分析と掃引のみで別々に): 適格 = 間接効果`ind_part`の区間が0を含まず、cと同じ符号の項。主 = 適格かつ`share_part` ≥ 0.5(点推定)。`single(<項>)`: 主がちょうど1つ。`distributed(<項…>)`: 主がなく適格が2つ以上。`partial(<項>)`: 主がなく適格が1つ。`none`: 適格がない。cの区間が0を含む場合は`no_total`。
- 限界: T042と同じ(腕の変動は休養率だけを動かさない、媒介は統計的な分解で因果の同定でない、`gap`・`err`・先発一致の関係は構成的)。掃引の腕は期待利得の一様なずれだけを動かすので、差し替えの腕より純粋な休養率の変動に近いが、方法の選択(A/B)や助言への従い方も変える。

### (c) 望ましい休養率 — 掃引(各方向10点: `base` + 掃引9本)

- 各点の**実現した休養率**を横軸(各方向の各点のセル平均)とし、縦軸に先発一致・最終技能・疲労(・最終信頼・満足度)をとる。方向ごとに曲線を出す。
- **傾き**: 各方向・各指標で、10点の水準を実現した休養率に回帰した傾き(休養率10pt当たり)と区間。
- **最適点**(先発一致と最終技能の2つで別々に、方向別): 点推定が最大の腕(`argmax`)の実現した休養率とδ、再標本ごとの`argmax`の腕の頻度(各腕が最大になった割合)、再標本ごとの`argmax`の腕の休養率の区間。`argmax`の腕が休養率の最小/最大の腕なら`boundary_low`/`boundary_high`、そうでなければ`interior`。
- **平坦域**(plateau): 点推定の`argmax`の腕との差の区間が0を含む腕の集合(= 最大と区別できない点)。疲労は休養率とともに単調に変わると予想されるので`argmax`ではなく曲線そのもので報告する。
- **現在の2つの休養率の位置**: legacyの`base`(順方向の`base`)とcentered_v1の`base`(逆方向の`base`)が、それぞれの世界の曲線上で先発一致と技能の平坦域に入るか(上の定義)を報告する。
- **曲線の一致**(collapse): 順方向の各点の先発一致 − 逆方向の曲線を同じ休養率へ線形補間した値、のうち逆方向の休養率の範囲に入る点の平均(`collapse_top2`、最終技能でも同じ)。0を含めば「休養率だけで先発一致が決まる」整合、含まなければ世界の方式が休養率以外の経路でも効く。
- **被覆**: 両方向の掃引が実現した休養率で [0.45, 0.80] を覆うか(最小≤0.45かつ最大≥0.80)。覆わなければ『最適点』を主張せず、限界として報告する(失敗ではない)。
- 価値判断は含めない: 「望ましい」は先発一致・技能・疲労のどれを重視するかに依存するので、本taskは曲線と最適点・平坦域・現在の2点の位置までを出す。既定の変更は別の判断(ユーザーの決定)。

## 判断規則(結果の前に固定)

- 既定は**変えない**。T042の推奨(登録の規則で『推奨』)も変更しない。本taskは、望ましい休養率を決めるための証拠(曲線・最適点・平坦域・現在の2点の位置)と、利得の担い手の水準/散らばりの区別、`err`の出所を出すだけ。
- 失敗条件: ゲートの破れ、追跡や差し替えによるsim結果の変化、T042保存値との不一致。予測の外れは失敗ではなく結果として記録。被覆の不成立は『最適点』を主張しない理由として記録する。

## 限界(結果を見る前に記す)

- 差し替えは判断の瞬間の期待利得だけで、状態の更新(期待利得の学習)は世界の方式のまま。`alt`は同じ観察と行動の列を別の雑音で更新した再構成であり、実走の履歴とは同じでない。`L`は本物の値の散らばりを保ったまま平均だけをずらす読み、`S`は`alt`の値の散らばりで平均を戻した読みで、どちらも実際には起こらない状態の組を判断に読ませる。水準の定数cは平均で、決定・方法・選手ごとのずれの違いは「散らばり」に含まれる。
- 掃引δは期待利得への一様な加算で、人間の価値観や個性(休養選好)の違いを表さない。実際に休養率を変える設計(simのconfig)とは別物で、掃引の曲線は、simに入れる前の読み取り専用の予備的な証拠にとどまる。曲線は最大の端(休養率36%付近の飽和)で打ち切られる。
- 休養率は各方向の腕の平均の実現値で、セルや選手の個性ごとの最適休養率を測らない。望ましさの基準(先発一致・技能・疲労・個性の多様性)の重みは決めていない。個性に基づく休養の多様性(憲章1・2)を、先発一致の最適化のために均すことは、本taskの評価対象外。
- 媒介・`err`の項別分解は統計的な分解で、休養率の因果効果の同定ではない(T042と同じ)。項は構成的な恒等式で、`skill`・`match`の推定誤差を真の技能に対して測る(`match_rating_estimate`は試合の評価値であり、真の技能そのものの推定ではないので、`match`項の「誤差」には評価の定義の違いも含まれる)。
- 単一の主指標(先発一致)。ロスターは3人(先発2人、控え1人)で、世界は3seedを共有する。3設定は`coach_belief='none'`で、他の設定には一般化しない。
