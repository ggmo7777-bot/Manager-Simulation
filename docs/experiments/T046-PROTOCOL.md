## 問(1) 用量反応の判定

`dev(f) = share(d_f) − f`、`f ∈ {0.25, 0.50, 0.75}`(`d25`・`d50`・`d75`)。方向ごとの判定(点推定):
- `linear`: 3つとも `|dev| ≤ 0.10`。
- `front_loaded`(最初の除去ほど効く): `linear`でなく、3つとも `dev ≥ −0.10` で、1つ以上が `dev > +0.10`。
- `back_loaded`: `linear`でなく、3つとも `dev ≤ +0.10` で、1つ以上が `dev < −0.10`。
- `mixed`: 上のどれでもない。
全体の判定: 2方向が同じ判定ならそれ、違えば`differs`。付随して、`U_f`が`f`について単調減少か(`U_none > U_d25 > U_d50 > U_d75 > U_nolag`、点推定、方向ごと)、`dev`の区間、`share_LO`・`share_HI`・`vshare`の曲線、5点(4点)の曲線の幅 `range4`(`o(±0.030)`・`o(±0.010)`の`top2`の最大 − 最小)。

## 問(2) 対象別の判定

`share(st)`、`share(be)`、`share(bd)`(`U`の割合)。方向ごとに最大の対象 `top_target`(`st`・`be`・`bd`)と、その`share`が 0.70以上なら`carrier = top_target`、未満なら`carrier = diffuse`。全体: 2方向で同じ`carrier`ならそれ、違えば`differs`。付随して、`share(st) + share(be) − 1`(加法性からのずれ。`st`と`be`は排反で全員を覆うので、相互作用が無ければ0)、`vshare`、`share(bd) − max(share(st), share(be))`の区間、`bd`の`share`が`be`より大きいか(`be ⊂ bd`なので、ほぼ構成上の帰結。読みでは割り引く)。

## 問(3) 残った傾きの判定(候補: 疲労の推定の遅れ・誤差)

前提: `SL_nolag`が両方向で区間の下限>0(解釈すべき傾きがある)。そうでなければ判定は`no_residual`。前提があるとき、`dSL = SL_nolagfat − SL_nolag`と`SLratio = SL_nolagfat / SL_nolag`(方向ごと)で:
- `explains`: 両方向で`dSL`の区間の上限<0 かつ `SLratio ≤ 0.5`。
- `partial`: 両方向で`dSL`の区間の上限<0(`explains`でないもの)。
- `grows`: 1方向以上で`dSL`の区間の下限>0。
- `unchanged`: 上のどれでもない。
操作の確認: `nolagfat`の`abs_f`は恒等的に0(全決定、検査で厳密に確認)。`none`の`abs_f`と`bias_f`を5点に沿って出す(疲労の推定が休養の少ない世界で本当に外れているか: 機構の前提)。『疲労の推定の遅れが残った傾きの原因』と言えるのは`explains`か`partial`だけ。`unchanged`・`grows`なら『この候補は原因でない(残った傾きの原因は未解明のまま)』と書き、次の候補を探すことはこのtaskでしない。

## 限界(結果を見る前に記す)

- 介入は、先発選びが読む推定へ研究者が真の技能・真の疲労を混ぜる反事実で、監督が観察を増やす世界ではない。用量`λ`は『遅れの何割を除くか』であって、観察の頻度の何割増しかへの換算は無い。
