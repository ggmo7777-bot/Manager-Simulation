# T020 結果 — 初期分布の範囲の感度掃引と校正目標の定義

実装・実験: 2026-11-10。契約: [T020](../tasks/T020.md)、事前条件: [PROTOCOL](T020-PROTOCOL.md)、判断: [D035](../DECISIONS.md)。**範囲は一切変更していない(既定値は不変)。**

**事前登録の18摂動のうち3種は、同じ事前登録の範囲検査(値域[0.05,0.95]、クリップせず拒否)で拒否され、実行できなかった。よって成功条件3の「19セル」は16セル(baseline+15摂動)でしか満たせず、条件3は部分的な充足である。** 結果を見て規則や摂動を変えていない。H1は実行した範囲で支持、H2は点推定で支持(ただし上位群の区間は重なる)、H3は判定不能。

## 実装

`LeagueEconomyConfig.range_perturbation`(既定`none`)を追加した。名前から固定辞書(`RANGE_PERTURBATIONS`)で範囲を引き、`_sample_profiles`/`_sample_impressions`が使う。実行時の任意数値は受けない。条件名は`<base>_sampled_population_range_<名前>`(例 `open_solidarity_sampled_population_range_rate_w15`)。`null`は摂動なしの明示名。既定ではconfigにキーを出さず、既定worldとsnapshotはバイト不変。範囲違反は`LeagueEconomyConfig`構築時に`ValueError`(クリップなし)。CLIの`--condition`は実行可能な16名×7制度の条件を受ける。進行・Policy・観測・移籍・通貨・評価・save17は不変。`league_economy.py`が指紋対象なのでruntime hashは変わった(`cfa421f9…1fbf`)。T019以前のsaveは旧ソースで読む。

## 仮説の判定

規則は実行前に`experiments/t020.py`へ固定した(Δ=摂動−baselineの還元効果、対応区間)。

| 仮説 | 判定 | 根拠 |
|---|---|---|
| H1 符号が全摂動で正 | 支持(実行した15種+baseline) | 16セルとも平均>0、区間の下限>0。拒否された3種は判定不能(未実行) |
| H2 最も効く群が成長率 | 点推定で支持 | 群ごとの|Δ|最大は rate 0.004226(rate_cp)、cap 0.001832、noise 0.001782、trait 0.001602、psych 0.000305。rateはbaselineの検出可能差を超える。ただしrate_cpのΔの区間[0.0009,0.0075]はcap_cmの|Δ|を含み、上位群間の順位は統計的に確定しない。self_biasは0 |
| H3 印象誤差幅の最大変化 < 0.003551(T019のF2対比) | 判定不能 | 最大はnoise_w05の|Δ|=0.001782、対応区間の半幅0.001789。上端0.003571が0.003551をわずかに超えるため区間全体では下回らない。点推定は閾値の約半分 |

感度が高かった範囲群: 成長率の中心(rate_cp/rate_cm)が明確。上限の中心(cap_cm)と印象誤差幅(noise_w05)は区間が0に接する程度。特徴の幅と中心、忠誠・野心・自律の幅は検出可能差より小さい。自己推定バイアス幅は影響なし。なお上限の幅と忠誠の幅×1.5は検査できていない。

内部基準の検査は「現行範囲が構造的に破綻していない」ことを示すだけで、現実の選手分布への妥当性は与えない。

## 実測と限界

- 全225テスト合格(241.7秒)、高速ゲート57件合格(5.2秒)、Python 3.13.3 arm64。実験は1,440本(16セル×3制度×30seed、84日)を192.4秒。旧成果物3,031ファイルはhash不変(`artifacts/t020/preflight/historical-inventory.json`に照合)。
- 範囲は未校正の仮説で、現実の選手分布の再現ではない。摂動の大きさは任意(×0.5/×1.5等)で、効果の大小は摂動の選び方に依存する。単独摂動のため交互作用は見ない。育成/補強の類型差は入力であり、範囲の変更は類型差の変更を含む。
- seed 300..329は今回が初使用。区間は探索的で、多重比較の調整もない。bootstrapや再実行による確認seedは設けていない。
- 事前登録の不整合により3摂動が未実行で、成功条件3は16/19セルの充足。未実行の3種(上限幅×1.5、上限+0.03、忠誠・野心・自律幅×1.5)の感度は未知。
