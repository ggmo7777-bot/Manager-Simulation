## 測定(仮説と予測)

generations有効の主格子(S=29, S=33の各42セル)と長期42セルについて。研究者のみが真値を使う。

- **P1 年齢分布は30年度でも安定しない(同期した創設世代の反響)**(長期、反証され得る予測): 各セルで、年度21〜30の現役の平均年齢の年度間標準偏差を求め、**>2.5歳のセルが21/42以上**と予測。外れたら、30年度で見かけの安定に達したという反証として記録する。全年度の年齢分布(平均・標準偏差・最小/最大・33歳以上の割合)を記述。
- **P2 技能の水準**(主格子のS=29とS=33、8年度末): 現役の平均composite skillの対照との対応差(生成有効−対照、セルごと)が**正のセル≥36/42**と予測(曲線の衰えが対照の高齢の創設世代を下げ、新人が補う)。両Sで片側でない厳密な符号検定(同値を除く)、有意水準0.05/2=0.025を記述に併記。外れたら反証。全年度の現役の平均技能の最小値(崩壊=0.30未満が1つでもあれば縮退として記録)。
- **P3 新人は観察される**(新人のうち入団後ちょうど1年度以上在籍した者): 入団クラブの監督の`last_seen_day`が入団日より後になった割合が**≥0.90**と予測。外れたら反証。
- **記述(合否外、方向を予測しない)**: 年度ごとの引退数と理由の内訳、補充数、創設選手の残存数、引退者の満足度・年齢、新人の最初の年度の先発率(試合ごとの割合)と出場0の新人の割合、新人の入団時と入団後最初の年度末の監督の技能推定の誤差(|推定−真の技能|)の平均、現役の平均満足度・平均trust・完了移籍件数の対照との差、イベント数、実行時間、年度間のロスター人数(4クラブの最小/最大)。
