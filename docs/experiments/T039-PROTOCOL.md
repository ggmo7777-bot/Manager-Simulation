2026-11-11、実装前登録(結果を見る前)。契約: [T039](../tasks/T039.md)。結果を見て方法・定義・閾値・予測を変えない。外れた予測は結果として記録する。新しいsim変更・config・調整はしない。T038の事後の観察(出場者+0.002、控え+0.010〜+0.012、対の正答率15.1%→21.8%)は、本taskでは仮説の出所であり証拠として使わない。

## 固定する条件

Python 3.13.3(uv)。T037/T038と同じ84セル(14世界×seed{100,101,102}×開始年齢{29,33}、168日、`season_length_days=21`)を3設定(`t033.SETTINGS`)で、`observation_noise_mode`の`legacy`/`shifted_v1`/`centered_v1`の3群で実行(756実行)。`soccer_sim/`は凍結T037 source_bundleとバイト一致。研究者だけが真の技能を使い、何も戻さない。真の技能は、T036〜T038と同じく、その日の進行後の`composite_skill()`。

設計の事実(コードを読んだだけ。結果は未確認):
- 監督の各選手についての推定は3つ(技能・試合評価・疲労)。先発は`select_skill_weight×技能 + select_match_weight×試合評価 − select_fatigue_weight×疲労`の上位2人。
- 推定を動かす観察は3チャネル。**練習**(`coach_session_observation`、監督が1日2枠で選んだ選手。技能は指数平均α=0.36、`coach_practice_rating=blend_v1`の設定(T032)だけ試合評価も0.70/0.30、雑音幅`coach_noise`=0.024)、**試合**(`coach_match_observation`、試合に出た選手のみ。試合評価は指数平均α=0.35、技能は0.18のブレンド、雑音幅`match_obs_noise`=0.020。クラブは自分の先発と相手の先発の両方を観察する)、**偵察**(`coach_scout_observation`、技能α=0.32、試合評価0.70/0.30、幅`scout_noise`=0.030)。疲労の推定は観察の置換(最後の観察の値)で、幅は練習0.045/試合0.050/偵察0.065。
- 控えの選手には試合の観察がない(コードのコメント「No paid/direct observation of this bench player」)。
- `legacy`の観察雑音は`(u−0.5)×2×幅`、`shifted_v1`は`u×2×幅`で、厳密に**shifted = legacy + 幅**(観察ごとの定数。疲労観察も同じ)。したがって「同じ観察列で平均だけ除く」は、各観察に+幅を足して(クランプつきで)推定を再生すれば得られる。`centered_v1 = shifted/2`は、定数オフセットではない(ばらつきも変わる)ので、この静的な反実仮想の対象外。

## 群・チャネル・変種の定義(結果を見る前に固定)

- **群**(クラブの`lineup_decision`ごと、同クラブの1つ前の試合日の`lineup_decision`に対して): `played`(1つ前の試合の先発)、`benched`(1つ前の試合の在籍者で先発でない)、`arrived`(1つ前の試合の在籍者でない: 新人・移籍入り・最初の試合)。
- **再生(replay)**: 研究者は、初期の推定(初期ワールドの値)から、イベントを順に読み、sim本体と同じ式(クランプ・round6込み)で各(監督, 選手)の推定を更新する。更新するのは練習・試合・偵察の観察イベントと、`season_youth_joined`(全監督で事前値0.5/0.5/0.10に戻る)。疲労は`observe_fatigue`の呼び出しを読み取り専用で記録し、イベントの順に対応づける。
- **並行する反実仮想の推定(shadow)**: `legacy`の実行だけ、実際の推定と並行して、観察に+幅(練習=`coach_noise`、試合=`match_obs_noise`、偵察=`scout_noise`)を足した推定を4通り持つ。`all`(3チャネルすべて)、`session`・`match`・`scout`(そのチャネルだけ)。観察値は`min(0.98, 観察+幅)`(上限のクランプは通過しない。下限側は同様に扱う)。疲労は、`observe_fatigue`を同じ引数・同じキーで`centered=True, shifted=True`で呼んだ値(= legacyの値+幅、クランプ込み)を、最後の観察のチャネルに応じて用いる。
- **変種**(先発の再順位付け。スコアは本体と同じ`round6(round6(w_s×技能)+round6(w_m×試合評価)−round6(w_f×疲労))`、同点はid順): `actual`(実際)、`all`、チャネル別`session`/`match`/`scout`(そのチャネルの反実仮想推定を全成分に使用)、成分別`comp_skill`/`comp_match`/`comp_fat`(`all`の反実仮想推定を、その成分だけに使用)、群別`grp_played`/`grp_benched`/`grp_arrived`(`all`の反実仮想推定を、その群の選手だけに使用)。
- 指標の単位は`lineup_decision`(84セル×168日÷7日×4クラブ、T038と同じ24,192件/群)。**先発一致** = 先発が真の上位2人(真の技能、同点はid)と一致する割合。
- **窓の観察件数**: 各`lineup_decision`について、1つ前の同クラブの`lineup_decision`から今回までに、その選手に対し自クラブの監督が受けた観察の件数(練習/試合/偵察)。`arrived`は在籍前の観察を含みうるので、件数は`played`と`benched`で報告する。
- **ずれ(shift)** = 反実仮想の推定 − 実際の推定(技能・試合評価・疲労・総合点)。群別の平均。
- **対の正答率**: 先発の並びを決めるスコアの順序が真の順序と一致する割合。対は真の技能の差≥0.02、一方が`played`で他方が`benched`のもの。`better_benched`(真に上なのが控え)と`better_played`に分け、`actual`と`all`で測る。
- **動的な利得** D = 実走の先発一致(shifted_v1またはcentered_v1の群) − legacyの群(セル対)。**静的な効果** C_v = 変種vの先発一致 − `actual`(legacyの状態のみ)。**説明率** F = C_all / D_shifted(centeredには C_all / D_centered も参考で報告)。
- 各統計の不確かさ: セルの再標本(bootstrap 1000回、固定seed 39)による95%区間(全指標とも同じ再標本を共有し、群間・変種間の差は対)。世界は3seedを共有し独立でないので区間は過小の可能性がある。設定別(t030/t031/t032)も出す。

## 予測(反証され得る。事前の信頼を併記。値は3設定合計、legacyの状態)

事前の考え方(結果を見る前の推論): 平均のずれは3チャネルのどれでも約+幅を各推定へ足すので、全選手の推定をほぼ同じ向き・大きさ(総合点で約+0.01、技能+、試合評価+、疲労の罰−で相殺し合う)に動かす。全員に同じ量なら順位は変わらない。群ごとに違うのは、チャネルごとの質量(控えは試合評価を更新しないが、前に出た時のずれを保持する)だけ。したがって静的な効果は小さく、T037の動的な利得の大半は別の経路(推定の水準に依存する意思決定: 練習の配分・偵察・移籍など)と予想する。

- **P1(機構)**: ゲート1〜5が通る。信頼約90%。
- **P2(チャネルの構造)**: `benched`の窓の試合観察は平均ちょうど0、`played`は平均ちょうど1(自クラブの1試合につき1回)。信頼約95%。(構造から決まる。)
- **P3(練習の配分)**: 練習の観察件数(窓あたり)は`benched`が`played`の1.2倍以上。信頼約55%。(古い選手ほど観察の価値が高いため。)
- **P4(群間のずれの差)**: 全チャネルを除いた総合点のずれ(`all`)の平均は、`benched`と`played`で0.004以上違う(|Δ_benched−Δ_played| ≥ 0.004)。信頼約30%。
- **P5(静的な効果の大きさ、本命)**: C_all ≥ +3.5pt(T037の動的利得+7.0ptの半分)。信頼約20%。(C_allが+1.5〜+3.5ptの確率約25%、+1.5pt未満約55%。)
- **P6(チャネル)**: 試合チャネルのC_match が練習チャネルのC_sessionより0.5pt以上大きい(C_match − C_session ≥ +0.5pt)。信頼約35%。
- **P7(成分)**: 疲労成分(`comp_fat`)の|C|が、技能・試合評価成分の|C|より大きい。信頼約30%。(疲労のずれは総合点で逆符号に働き、技能・試合評価のずれと打ち消し合うため。)
- **P8(群)**: 控えだけを補正した`grp_benched`のC が、出場者だけを補正した`grp_played`より1.0pt以上大きい。信頼約35%。
- **P9(加法性)**: 3チャネルのCの和とC_allの差が±1.0pt以内。信頼約70%。
- **P10(実現と静的の乖離)**: 本taskの群定義で測った、実走(shifted_v1群−legacy群)の技能推定の誤差の変化の群差(`benched`−`played`)に対し、静的な伝播(`all`の技能のずれの群差)は半分未満(静的な群差 < 0.5×実現した群差)。信頼約60%。(実現値は群の構成の変化を含むため。)

## 判断規則(結果の前に固定)

- 既定は**変えない**。推奨は提案のみ(別taskで、凍結成果物の基準の置換を伴う)。
- centered_v1を既定にする提案の推奨度:
  - **推奨**: C_all ≥ +3.5pt かつ95%区間の下限>0、かつ群別(P8)または群間のずれ(P4)が支持され(機構が出場/控えで説明できる)、かつT037の全指標でcenteredがlegacyに劣らない(先発一致・新人以外/新人のMAE・最終技能/信頼/満足度/移籍数。例外は新人以外の試合評価推定の偏りの小さな悪化と、既知の偵察+17%。本taskは同じ756実行を再現するのでT037の値をそのまま用いる)。
  - **条件つき**: C_allが+1.5〜+3.5ptで区間の下限>0、またはP4とP8がともに支持。条件は、利得の残りが動的経路(意思決定の水準依存)であることを別taskで確かめることと、偵察+17%の影響を新しい基準で再測定すること。
  - **保留**: 上のどちらも満たさない(静的な出場/控えの機構では利得を説明できない)。この場合も「centered_v1が悪い」ではなく「機構が未説明」。
- 失敗条件: ゲートの破れ、記録によるsim結果の変化、T037保存値の1つでも不一致。予測の外れは失敗ではなく結果として記録。
- 交互作用(第4の隅)と因果の同定はしない。静的な反実仮想は同じ観察の列・同じ状態の再順位付けで、監督の将来の行動の変化(観察の配分・移籍・偵察)を含まない。centered_v1のばらつき側の効果は静的な反実仮想では扱えない(T037の分解を引用する)。
